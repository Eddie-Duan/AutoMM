# 题面附件

本目录保存题目原始附件。Agent 只读这些文件；提取后的说明应写入活动题目的 `problem_understanding.md`。

同时保存竞赛官方规范，供论文与支撑材料交付时对照：

- `全国大学生数学建模竞赛论文格式规范.pdf`（2026 年修订稿）：承诺书/编号页进纸质版不进电子版；正文不要目录、不超过 30 页；附录须含支撑材料文件列表与全部可运行源程序；全文不得出现学校/赛区/身份信息。
- `全国大学生数学建模竞赛人工智能工具使用规定（2026年试行）.pdf`：**论文须在「参考文献」之前设置「AI 工具使用声明」**，两种表述二选一；使用 AI 工具的，支撑材料须包含 PDF《AI 工具使用详情.pdf》。落实位置见 `config/paper.yaml` 的 `ai_declaration`，生成命令见 `wiki/cli-reference.md`。
