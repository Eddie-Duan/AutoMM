### 1 问题描述与建模口径

问题 1 要求在电价、小区负载逐日相同且已知单日光伏预测的前提下，于每天 0:00 制定当天计划购电策略：微网提供的电能不得低于小区负载，储能设备 0:00 与 24:00 储电量相同，目标为全天购电费最小。

本问采用的建模口径逐条对应假设编号：

| 口径 | 取值 | 依据 |
|---|---|---|
| 时间离散与对齐 | $\Delta t = 1/6$ h，144 个时段；附件时间戳为区间**左端点**，计划窗 0:10→24:10 | AS01 / AS09（团队裁定 D1） |
| 功率平衡 | 等式 $b_t + PV_t\Delta t + q_t = L_t\Delta t + c_t + s_t$，$0 \le s_t \le PV_t\Delta t$ 为弃光量 | AS04 / AS08（D3 / D4） |
| 储能动态 | $E_t = E_{t-1} + \eta c_t - q_t/\eta$，$\eta = 0.9$（充放两侧，往返 0.81） | AS05（D2） |
| 容量与功率 | $1200 \le E_t \le 10800$ kWh；$c_t \le 833.33$ kWh；$q_t \le 750.00$ kWh | AS06（D10 取两侧更严者） |
| 日周期 | $E_0 = E_{144} = 6000$ kWh | AS10 / AS11（D5） |
| 目标口径 | $\min \sum_t p_t b_t$（元，**不乘** $\Delta t$） | AS03a（D9） |
| 模型族 | 单日确定性 LP（不引入互补二元变量） | AS07 / AS12（D6） |

「微网提供的电能不可低于小区负载」在等式平衡下自动成立：实际供给 $b_t + q_t + (PV_t\Delta t - s_t) = L_t\Delta t + c_t \ge L_t\Delta t$，即充电不挤占负载。该形式化与文献一致：微网并网储能系统的 24 小时成本最小 MILP 普遍显式包含 SOC 约束与充放电动态 [@ref-alguhi-2025-bess-operation]；分时电价下"低价充电、高价放电"的套利是光伏-储能经济优化的核心机制 [@ref-lin-2024-tou-industrial]；储能逐时段成本最小调度属成熟的标准优化问题族 [@ref-olivieri-2020-residential-bess]。目标函数按题面仅计购电费、不纳入电池折旧，属显式项目假设——日前微网调度文献常把折旧成本纳入目标，故该取舍必须显式声明而非默认事实 [@ref-zhang-2015-dayahead-degradation]。恒效率 0.9 为附录 1 给定的题面硬参数，文献仅说明效率随 SOC 与退化变化、恒效率属工程简化 [@ref-vykhodtsev-2022-bess-review]。

### 2 数学模型

完整推导见 `formulation_v001` §3.1–§3.10（§3.8 给出完整模型）。决策变量 $b_t, c_t, q_t, s_t$（kWh，不带时间因子）与状态量 $E_t$（时段末储电量，kWh）：

$$
\min \sum_{t=1}^{144} p_t\, b_t
$$

$$
\begin{aligned}
\text{s.t.}\quad & b_t + PV_t\Delta t + q_t = L_t\Delta t + c_t + s_t, & 0 \le s_t \le PV_t\Delta t \\
& E_t = E_{t-1} + \eta c_t - q_t/\eta, & \eta = 0.9 \\
& 1200 \le E_t \le 10800, & 0 \le c_t \le 5000\Delta t = 833.33 \\
& 0 \le q_t \le 5000\Delta t\,\eta = 750.00, & E_0 = E_{144} = 6000 \\
& b_t \ge 0 &
\end{aligned}
$$

模型规模：720 个变量、288 条等式、720 个变量界，$A_{eq}$ 非零元 1151、目标非零元 144（`formulation_v001` §3.8，sanity 阶段独立实测一致）。

**为什么不需要二元变量**（§3.10 互补性引理）：$\eta^2 = 0.81 < 1$ 且 $p_t > 0$，同一时段同时充放电被"少充少放"严格支配，故 LP 松弛无损；该结论由本问的 MILP 对照实测确认（见 §6）。求解采用 HiGHS 直接求解纯 LP（`scipy.optimize.linprog(method="highs")`），规模很小，无需分解或启发式（§5.3）。

### 5 鲁棒性分析

预注册方案与 948 个情景（947 可行，`stability_grade = 稳定`，判据 S1–S6 全部通过）见 `robustness/plan.md` 与 `robustness/report.md`：

三点结论：

1. **核心结论不依赖模型族**：MILP（显式互补二元）与 LP 目标值完全相同（`mip_gap = 0.0`，1 节点），说明 AS07 的 LP 松弛无损，无需付出 144 个二元变量与约 4.3 倍耗时的代价；SOC 离散化 DP 的四档粒度目标值恒不低于 $C^*$ 且随粒度加密单调收敛（h = 50 时 +0.791%，在预注册阈值 1% 以内），差异纯属离散化代价而非模型结构差异；
2. **日周期约束的经济价值为 2217.083333 元（$C^*$ 的 6.312%）**：去掉 $E_0 = E_{144}$ 后最优解在末时段放空至下界 1200 kWh，等价于把日初存量电能当日变现；**弃光变量本日贡献为 0**（$\sum_t s_t = 0$，其上界 $PV_t\Delta t$ 在最优解处不紧），但变量必须保留以在光伏盈余超出储能吸收能力时闭合功率平衡；
3. **口径敏感性**：accepted 的"两侧效率 0.9"是四种口径中最保守者，其余口径会低估费用 958.34–1710.42 元（$-2.728\% \sim -4.869\%$）。

### 7 结论

1. 问题 1 的最优计划购电策略对应全天购电费 $C^* = 35126.948589$ 元、全天购电量 59482.698998 kWh，策略呈"低价充电、高价放电"的典型 TOU 套利形态，全日无弃光、无同时充放电，日周期精确闭合；
2. 表 1、表 2 与交付文件 `result1.xlsx` 三者逐项一致，可直接作为论文表格与结果文件；
3. 模型族对照证明结论稳健：MILP 同解、DP 收敛至同一最优值附近（偏差 $\le 0.8\%$），本问无需引入二元变量或启发式；
4. 结论对效率参数最敏感（$\eta$ 由 0.9 降至 0.8 时费用 $+8.88\%$），对初值几乎不敏感；
5. 供后续小问承接的口径：单日功率平衡形式、储能状态转移与容量/功率约束、日购电费用目标结构（登记于 `dependency_graph.yaml` 的 `propagates` 字段）。
