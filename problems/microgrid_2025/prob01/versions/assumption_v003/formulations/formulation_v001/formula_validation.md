## 2. 量纲一致性（V1）

记 `[·]` 为量纲。`Δt = 1/6 h`，`p_t`：元/kWh，`L_t, PV_t`：kW，决策变量：kWh，`E_t`：kWh。

| 公式 | 左端量纲 | 右端量纲 | 结论 |
|---|---|---|---|
| `(R1) b_t + PV_t·Δt + q_dis_t = L_t·Δt + c_t + s_t` | kWh | kWh ×3 + kWh | 闭合（功率项已乘 Δt） |
| `(R2) E_t = E_{t−1} + η_ch·c_t − q_dis_t/η_dis` | kWh | kWh（`η`、`1/η` 无量纲） | 闭合 |
| `(R3) 0 ≤ s_t ≤ PV_t·Δt` | kWh | kWh | 闭合 |
| `(R5) C_plan = Σ p_t·b_t` | 元 | 元/kWh × kWh = 元 | 闭合；**无 `Δt` 因子（D9）** |
| `(R7a) c_t ≤ P_max·Δt` | kWh | kW × h = kWh | 闭合 |
| `(R7b) q_dis_t ≤ P_max·Δt·η_dis` | kWh | kW × h（无量纲因子） | 闭合 |
| 两侧功率写法 `c_t/Δt`、`η_ch·c_t/Δt`、`q_dis_t/Δt`、`q_dis_t/(η_dis·Δt)` | kW | kW | 闭合 |
| `(I1) Σq_dis = η_ch·η_dis·Σc` | kWh | kWh | 闭合 |
| `(I2) Σb = N + Σs + (1−η_ch·η_dis)·Σc` | kWh | kWh | 闭合 |
| `C_plan ≥ p_min·N` | 元 | 元/kWh × kWh = 元 | 闭合 |

**已知硬错误模式（必须失败）**：
- `F1`：目标写作 `Σ p_t·b_t·Δt` → 量纲为「元·h」，数值偏小 6 倍（D9 已裁定修正）；
- `F2`：把 5000 kW 直接当成电量上界（漏乘 Δt）→ 可行域放大 6 倍；
- `F3`：`(R1)` 中 `L_t`/`PV_t` 漏乘 Δt → 电力与电量混加。

探针断言：`AC_CAP = 5000·Δt = 833.3333 < DC_C_CAP = 925.9259`、`DC_Q_CAP = 750.0000 < AC_CAP`，
目标系数即 `p_t`（无 Δt 因子）；费用量级落在 10⁴ 元（§7）。

## 3. 边界与可行域（V2）

- `b_t ≥ 0` 无上界：目标系数 `p_t > 0`，故最优解不会无界增大 `b_t`（见 §7）。
- 充电/放电**各自**上界：`c_t ≤ 833.3333`、`q_dis_t ≤ 750.0000`（D10 口径丙，两侧取严）。
  探针实测：`max c = 833.3333`（并网点 5000.00 kW、电池侧 4500.00 kW）、
  `max q_dis = 715.6530`（电池侧 4771.02 kW、并网点 4293.92 kW），均 ≤ 5000 kW。
- `s_t` 上下界均有效：`0 ≤ s_t ≤ PV_t·Δt`（144 个界），最优解 `Σs_t = 0`（盈余全部被储能吸收）。
- SOC：`1200 ≤ E_t ≤ 10800`，探针实测 `E ∈ [1200.0000, 10800.0000]`（两端均被触及，说明容量约束在最优解活跃）；
  周期闭合 `E_144 = 6000.000000`（残差 < 1e-6）。
- 平衡等式残差：`max|(A_eq x − b_eq)| = 4.55e-13`（数值零）。
- 非负与不等式方向均已由 `(R1)–(R7)` 明确，不存在遗漏的边界条件：
  - 初值 `E_0 = 6000`（AS11）与终端 `E_144 = E_0`（AS10）同时写入；
  - 若缺周期约束，模型会放空/充满储能套利（`E_144 ≠ E_0`），属必须失败的边界缺失。

## 4. 守恒关系（V3）

由 `(R2)` 求和 + `(R4)`：

```
Σ_t q_dis_t − η_ch·η_dis·Σ_t c_t = 16799.9396 − 0.81 × 20740.6661 = −3.638e-12     （容差 1e-6）
```

由 `(R1)` 求和 + `(I1)`：

```
Σ_t b_t − [N + Σ_t s_t + (1 − η_ch·η_dis)·Σ_t c_t]
  = 59482.6990 − [55541.9724 + 0 + 0.19 × 20740.6661] = 2.183e-11                  （容差 1e-6）
```

推论 `Σb_t ≥ N` 实测成立（`59482.6990 − 55541.9724 = 3940.7266 kWh` 为往返损耗与弃光补偿）。
**物理解释**：储能不创造电量，只把低价时段电量搬到高价时段；每单位循环必然多购 `(1−η²)=0.19` 单位。

其它单调性论证（解析）：
- 目标系数非负 ⇒ `b_t` 增大不改进目标，最优解中 `b_t` 由平衡式决定而非无界增长；

## 7. 数值可解性与条件（V6）

- **可行性（构造性证明）**：`c = q_dis = 0`、`E_t ≡ 6000`、`b_t = max(0, L_t·Δt − PV_t·Δt)`、
  `s_t = max(0, PV_t·Δt − L_t·Δt)` 满足全部约束，对应 `C = 48052.0466 元`。故 `(P1)` 可行。
- **有界性**：`b_t ≥ 0` 且目标系数 `p_t ≥ p_min = 0.3713 > 0`；由 `(I2)`，任何可行解的 `Σb_t` 被
  `N + Σs + 0.19Σc` 约束，而 `Σc ≤ 144×833.3333`，故目标有有限下界 `p_min·N = 20622.7344 元`。
  最优值必落在 `[20622.73, 48052.05]` 元。
- **求解器实测**：HiGHS（`scipy.optimize.linprog(method="highs")`）`status=0 (Optimal)`，
  364 次迭代；等式残差 `4.55e-13`；MILP 对照（HiGHS MIP，`mip_gap = 0.0`，1 个节点）目标同值。
- **退化与多解**：SOC 上下界两端均活跃，可能存在多重最优（同一目标值对应不同调度）。
  因此实现阶段必须固定并记录求解器/容差，sanity 以**约束残差 + 恒等式 + 目标值**为准，
  不比对逐点解的唯一性；若报告逐时段数值，须与 `result1.xlsx` 同源同次求解。
- **条件数/尺度**：系数仅含 `1`、`0.9`、`1/0.9`、`1/6` 与 `p_t ∈ [0.3713, 1.3952]`，无非标度大数；
  无需缩放。若实现采用自研单纯形，建议保留 `E` 变量而非消元，以改善稀疏结构（非零元 1151）。

## 8. 解结构与互补性（V7）

- 引理（`formulation.md` §3.10）：`η_ch·η_dis = 0.81 < 1` 且 `p_t > 0` ⇒ 存在最优解满足
  `c_t·q_dis_t = 0 (∀t)`。
- 实测：`Σ_t c_t·q_dis_t = 0.000e+00`，同时充放时段数 `= 0`；LP 目标 `35126.9486 元`，
  MILP（显式二元互补，`M_c = 833.3333`、`M_q = 750.0000`）目标同为 `35126.9486 元`，差 `0.000e+00`。
- 结论：AS07 的「先解 LP 再验证」路径在本问成立；MILP 作为验证 oracle 通过，无需作为主路径。
