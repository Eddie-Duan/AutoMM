## 3. 逐步推导

### 3.1 时间离散与对齐（AS01/AS09）

由附件 1 的 10 分钟粒度与恰好 144 个数据点，

```
Δt = 24 h / 144 = 1/6 h = 0.166667 h
```

位置 `i` 代表区间 `[10(i−1), 10i)` 分钟，`t = i`。功率→电量的换算是 `X_t·Δt`（`X ∈ {L, PV}`）；
决策变量 `b_t, c_t, q_dis_t, s_t` 直接以 kWh 表示（即默认已含 Δt 因子），因此目标与平衡式中
**不再对决策变量乘 Δt**。

### 3.2 逐时段电量平衡（AS04 + AS08）

一个时段内进入系统的电量（外网购入 `b_t`、光伏可用 `PV_t·Δt`、储能放电 `q_dis_t`）等于离开系统的电量
（负载 `L_t·Δt`、储能充电 `c_t`、弃光 `s_t`）：

```
(R1)  b_t + PV_t·Δt + q_dis_t = L_t·Δt + c_t + s_t ,   ∀t
```

配套边界（AS08）：光伏盈余只可能被储能吸收或弃掉，不允许上网（AS15），故

```
(R3)  0 ≤ s_t ≤ PV_t·Δt
```

`(R1)` 是等式而非不等式：它同时给出「余额闭合」与「充电不与负载竞争」两个语义（D3 备选 A）。

### 3.3 「微网提供的电能不可低于小区负载」的蕴含（题面 H1）

微网实际提供给负载的电量为

```
b_t + q_dis_t + (PV_t·Δt − s_t) = [L_t·Δt + c_t + s_t] − s_t = L_t·Δt + c_t ≥ L_t·Δt      （用 (R1)）
```

因为 `c_t ≥ 0`。于是题面的可靠性要求被 `(R1)` 与 `c_t ≥ 0` **自动蕴含**，无需再独立添加不等式。
反之，若写成弱口径 `b_t + PV_t·Δt + q_dis_t − c_t ≥ L_t·Δt`（D3 备选 B，已否），把充电量算作供给，
会人为放宽可行域并制造账面套利，故不采用。

### 3.4 储能状态转移与日周期闭合（AS05/AS10/AS11）

充放电效率各作用于本侧（η_ch = η_dis = 0.9，往返 81%，D2 备选 A）：

```
(R2)  E_t = E_{t−1} + η_ch·c_t − q_dis_t/η_dis ,      t = 1..144，E_0 为给定初值
(R4)  E_0 = E_144 = E_init = 6000 kWh
(R6)  E_min = 1200 ≤ E_t ≤ 10800 = E_max ,            ∀t
```

`(R2)` 中 `η_ch·c_t` 为充入电池的电量，`q_dis_t/η_dis` 为为放出 `q_dis_t` 而从电池取用的电量，
三者单位均为 kWh。`(R4)` 即题面「储能在 0:00 和 24:00 的储电量相同」，在 AS01 左端点口径下计划窗恰为 24 h。

### 3.5 由周期约束导出的结构恒等式（供 sanity L1 与解析界使用）

对 `(R2)` 逐时段求和并用 `(R4)`：

```
E_144 − E_0 = η_ch·Σc_t − (1/η_dis)·Σq_dis_t = 0   ⇒   Σq_dis_t = η_ch·η_dis·Σc_t = 0.81·Σc_t      (I1)
```

记净负荷电量 `N = Σ_t (L_t − PV_t)·Δt = 55541.9724 kWh`。对 `(R1)` 求和并代入 `(I1)`：

```
Σb_t = N + Σs_t + (1 − η_ch·η_dis)·Σc_t = N + Σs_t + 0.19·Σc_t                                    (I2)
```

`(I2)` 说明：**购电量不可能低于净负荷**（`Σb_t ≥ N`），超出部分只能用于「补足往返损耗」或「弃光」。
这两条恒等式与 §3.10 的引理共同构成不依赖求解器的结构性检验。

### 3.6 目标函数与量纲（AS03a + D9 + AS09）

题面问题 1 要求「尽可能节省微网的购电费用」，且 `result1.xlsx` 的「购电量」列语义为 kWh，故

```
(R5)  min  C_plan = Σ_{t=1..144} p_t · b_t
```

量纲：`[元/kWh] × [kWh] = 元`。因 `b_t` 本身已是 kWh（§3.1），**全文禁止出现 `p_t·b_t·Δt`**
（v001 的旧写法，会使费用系统性偏小 6 倍，D9 已裁定修正）。

### 3.7 充放电功率上限的两侧交集（AS06 + D10 口径丙）

题面只给「最大充放电功率 5000 kW」，未指明加在并网点（交流）侧还是电池（直流）侧。按团队裁定 D10
取**两侧同时约束、取更严者**：

- 充电：并网点侧 `c_t/Δt ≤ P_max`；电池侧 `η_ch·c_t/Δt ≤ P_max`。

```
c_t ≤ min( P_max·Δt , P_max·Δt/η_ch ) = min(833.333 , 925.926) = 833.333 kWh                (R7a)
```

- 放电：并网点侧 `q_dis_t/Δt ≤ P_max`；电池侧 `q_dis_t/(η_dis·Δt) ≤ P_max`。

```
q_dis_t ≤ min( P_max·Δt , P_max·Δt·η_dis ) = min(833.333 , 750.000) = 750.000 kWh            (R7b)
```

`(R7a)/(R7b)` 的含义与偏差方向：若只用甲口径（`q ≤ 833.33`），电池侧放电功率最大可达
`833.33/0.9/Δt = 5555.56 kW`，超题面 11.1%；若只用乙口径（`c ≤ 925.93`），并网点充电功率同样超限。
取交集后两侧功率都不超 5000 kW，代价是放电上限由 833.33 收紧到 750.00。

### 3.8 完整模型

```
(P1)  min   Σ_t p_t · b_t
      s.t.  b_t + PV_t·Δt + q_dis_t = L_t·Δt + c_t + s_t            ∀t   (R1)
            0 ≤ c_t ≤ 833.333                                        ∀t   (R7a)
            0 ≤ q_dis_t ≤ 750.000                                    ∀t   (R7b)
            0 ≤ s_t ≤ PV_t·Δt                                         ∀t   (R3)
            E_t = E_{t−1} + 0.9·c_t − q_dis_t/0.9                    ∀t   (R2)
            1200 ≤ E_t ≤ 10800                                       ∀t   (R6)
            E_0 = E_144 = 6000                                            (R4)
            b_t ≥ 0                                                  ∀t   (AS15)
```

矩阵形式：`x = (b, c, q_dis, s, E) ∈ R^{720}`，`min pᵀx s.t. A_eq x = b_eq, l ≤ x ≤ u`，
其中 `A_eq` 含 144 行平衡等式与 144 行动态等式（共 288 行），变量界 720 个，非零元 1151（探针实测）。

**等价简化**：由 `(R2)` 可把 `E` 消去，得到只含 `(b, c, q_dis, s)` 的模型；周期约束化为 `(I1)`，
SOC 区间化为对部分和的箱式约束。该简化可用于自实现求解器或对偶检验，但标准建模路径保留 `E` 显式
（可解释性与 sanity 检查更直接）。

### 3.9 解析下界与构造可行解（数值可解性论证）

**(a) 下界。** 由 `(I2)` 与 `p_t ≥ p_min = 0.3713`：

```
C_plan = Σ p_t b_t ≥ p_min · Σ b_t ≥ p_min · N = 0.3713 × 55541.9724 = 20622.7344 元
```

**(b) 构造可行解（上界）。** 取 `c_t = q_dis_t = 0`、`E_t ≡ 6000`，
`s_t = max(0, PV_t·Δt − L_t·Δt)`、`b_t = max(0, L_t·Δt − PV_t·Δt)`：满足 `(R1)–(R7)`，
得 `C = 48052.0466 元`；另一可行解（光伏全弃、按负载购电）得 `C = 88319.3614 元`。
故 `(P1)` 可行且

```
C* ∈ [20622.73, 48052.05] 元，量级 10^4 元
```

若实现结果落在 10³ 元，即为误乘 Δt 的硬错误信号（D9 的量纲自检）。

### 3.10 互补性引理：为什么本问不需要二元变量（AS07）

**引理**：设 `p_t > 0`、`η_ch·η_dis < 1`。若 `(P1)` 的一个可行解在某时段同时有 `c_t > 0` 与 `q_dis_t > 0`，
则存在另一个可行解使目标严格更小；因此 `(P1)` 存在满足 `c_t·q_dis_t = 0 (∀t)` 的最优解。

**证明**：设该时段 `c_t > 0, q_dis_t > 0`，取 `δ > 0` 使 `δ ≤ c_t`，并令
`c_t' = c_t − δ`、`q_dis_t' = q_dis_t − η_ch·η_dis·δ`（取 `δ ≤ q_dis_t/(η_ch·η_dis)`）。
由 `(R2)`，储电量变化为 `η_ch·(−δ) − (−η_ch·η_dis·δ)/η_dis = −η_ch δ + η_ch δ = 0`，故 `E` 轨迹不变、
`(R4)/(R6)` 仍满足。由 `(R1)`，`b_t' = b_t − δ − η_ch·η_dis·δ = b_t − δ(1 + η_ch·η_dis) < b_t`，
而 `s_t` 不变、其余变量不变，目标下降 `p_t·δ(1+η_ch·η_dis) > 0`，与最优性矛盾。∎

对本题 `η_ch·η_dis = 0.81`、`p_t > 0` 恒成立，故纯 LP 的最优解（或至少一个最优解）自然互补，
候选 B 的 MILP 互补约束在最优值上是冗余的（§8 探针在 HiGHS 上验证 LP 与 MILP 目标值相同，差 0）。

## 4. 候选建模/求解方案

> 四条路线并列给出；规模量级、利弊与失效条件在**看到计算结果前**固定（§5 的比较标准同样预先声明）。
> 本问为 144 时段单日确定性线性问题（LP），候选 A 与 B 都属精确路线，C/D 属启发式与混合路线。

### 候选 A：单层完整 LP，直接用 HiGHS 求解（推荐）

- **核心思想**：按 `(P1)` 直接建连续 LP，调用成熟内点/单纯形实现求全局最优。
- **规模量级**：连续变量 720（`b,c,q_dis,s,E` 各 144）；等式约束 288；变量界 720；
  非零元 1151；无整数变量。单次求解 < 1 s、内存 < 50 MB。
- **优点**：全局最优与可证明的对偶界；无需 Big-M、无整数间隙；影子价格可解释（各时段电价的边际价值）；
  与 §3.5 的结构恒等式、§3.10 的引理相互印证；结果可复现（确定性 LP，无 seed 依赖）。
- **缺点**：要求线性建模纪律（`s_t` 必须显式、功率上限必须换算为电量）；若实际出现非凸要素
  （效率随 SOC 变化、启停成本）需改写模型。
- **失效条件**：若供应商/题意要求非凸效率或最小启停约束，则 LP 不再等价；或若后续小问引入二元决策。
- **适用/不适用**：prob01 完全适用；prob02 若仍为确定性 LP 亦适用（增加 `q_em` 变量）；
  prob03/04 的调整与电价可观测性口径若引入二元/分段结算，需重新评估。

### 候选 B：精确 MILP（显式互补二元变量）作为验证 oracle

- **核心思想**：在 `(P1)` 上加入 `u_t ∈ {0,1}` 与 `c_t ≤ M_c·u_t`、`q_dis_t ≤ M_q·(1−u_t)`，
  强制 `c_t·q_dis_t = 0`，用分支定界求最优。
- **规模量级**：变量 720 + 144 二元 = 864；不等式约束 288；`M_c = 833.333`、`M_q = 750.000`
  （**由 §3.7 的紧上界推导，不是「足够大的数」**）。
- **优点**：把 AS07 的互补性从「引理」变成「硬约束」，可作为 LP 解的独立复核；
  若未来出现退化最优面导致 LP 返回同时充放的解，MILP 可直接给出物理可实现解。
- **缺点**：引入 144 个整数变量与分支树，最坏情况时间不可预测（本问实测 1 个节点即证最优）；
  失去连续对偶信息；维护两套模型有额外成本。
- **失效条件**：Big-M 若取得过大（例如用 1e6）会削弱松弛、引入数值误差；若 `η` 或 `P_max` 变更
  而未同步 `M`，会误删可行解。
- **适用/不适用**：作为 prob01 的**验证 oracle**适用；不建议作为主计算路径（复杂度不是优点，
  `knowledge/optimization.md` 明确「能写成 MILP 不等于应无限期追求全局最优」）。

### 候选 C：价格分位规则式启发式（含可行性修复）

- **核心思想**：按电价分位阈值 `q_{1/3}`/`q_{2/3}` 划分低价/高价时段；低价段按 SOC 余量充电、
  高价段放电回落到 `E_init`，再用 `(R1)` 与 `q_dis_t ≤ L_t·Δt + c_t` 修复可行性与弃光。
- **规模量级**：无优化变量；单次 O(144 log 144) 排序 + O(144) 扫描，运行时间 < 10 ms。
- **优点**：不依赖求解器、可在无第三方库环境复现；给出**可解释的基线**与 regret 参考；
  可用作 MILP/LP 不可用时的降级路径。
- **缺点**：无最优性保证；对分位阈值与初值/效率敏感；无法给出对偶界。
- **失效条件**：价格曲线非 TOU 型（如 prob04 的实时波动电价）或 SOC 深度受限时，regret 会显著放大
  （本问探针实测 regret = 25.87%）。
- **适用/不适用**：作为基线/降级对照适用；**不适用于**需要最优性或最优性证明的交付口径。

### 候选 D：分解-协调混合（块坐标 / 滚动时域 + 精确子问题）

- **核心思想**：按 4 小时块（24 时段）或低价/高价窗把问题分解为 6 个 24 时段子问题，
  用边界 SOC 作为协调变量交替求解（块坐标/Gauss–Seidel 或拉格朗日松弛），外层循环直至周期闭合。
- **规模量级**：每子问题变量 120（24×5）、等式 48；外层迭代数十次；总规模与 A 同阶但单次更小。
- **优点**：为 prob02–prob04 的 334/365 天逐日与多阶段（0:00/6:00/12:00/18:00 调整）场景提供可扩展路径；
  单块失败可局部修复；便于并行（CPU 多核，但**若改用 GPU 必须单卡串行**）。
- **缺点**：协调循环无全局最优保证（对偶间隙需自行估计）；实现复杂度高；本问规模下相对 A 无收益。
- **失效条件**：块间耦合强（SOC 周期约束 + 单一价格曲线）时收敛慢或振荡；协调变量初值不当会不可行。
- **适用/不适用**：**本问不必要**；当 prob03/04 引入多发布时刻滚动调整、或逐日 365 天规模使单层 LP
  求解时间不可接受时，再作为混合路线评估。

### 4.1 精确/启发式/混合的适用性判断

- 本问具有**精确结构**（线性目标、线性约束、连续可行域、规模小），精确 LP 直接给出全局最优，
  故启发式与混合路线只作为**对照与降级**，不作为主路径；判据见 §5。
- 不使用随机优化/鲁棒优化/元启发式：题面 prob01 明确为确定性预测输入（AS16），
  引入场景或随机搜索只会增加运行预算而无证据收益（`knowledge/optimization.md` 要求必要性论证）。

## 6. 局限与不适用

1. **单日确定性**：输入视作精确预测（AS16），不处理预测误差与电价不确定性；prob03/04 另行建模。

7. **无自放电、无爬坡、无网络潮流约束**：附件 1 未给相关参数（AS14）。
8. **模板相位**：AS01 左端点口径使计划窗相对自然日前移 10 分钟，表 2 的 0:00/24:00 为「计划窗首/末状态」；

## 待团队选定的决策点

### D1 求解路线
- 备选 A：单层完整 LP（HiGHS），连续变量。规模：变量 720、等式 288、界 720、非零元 1151。优点：全局最优 + 对偶界、无 Big-M、可解释、可复现。缺点：要求严格线性口径，非凸要素需改写。适用条件：本问及一切确定性线性调度口径。
- 备选 B：互补 MILP（`u_t∈{0,1}`，`c_t ≤ M_c u_t`、`q_dis_t ≤ M_q(1−u_t)`）。规模：变量 864、不等式 288。优点：把 AS07 互补性变成硬约束，可作独立 oracle。缺点：整数分支时间不可预测、失去对偶、维护两套模型。适用条件：LP 解不互补或需硬性物理可实现性证明时。
- 备选 C：价格分位规则启发式（含修复）。规模：无变量，O(144 log 144)。优点：无依赖、毫秒级、可作降级基线。缺点：无最优性保证、对阈值/初值敏感（本问 regret 25.87%）。适用条件：求解器不可用时的降级或对照。
- 备选 D：分解-协调混合（6 块 × 24 时段 + SOC 协调）。规模：子问题 120 变量/48 等式。优点：易扩展到 365 天/多发布时刻。缺点：无全局最优保证、实现复杂、本问规模下无收益。适用条件：prob03/04 规模或滚动结构使单层 LP 不再合适时。
- 推荐：A，理由：本问小规模确定性线性、A 给出全局最优且 AS07 互补性可证；比较标准：最优性保证（对偶界/status）> 硬约束满足度 > 运行预算（≤60 s）> 解释性 > 鲁棒性。

### D2 时间窗相位与端点语义（表 2 的 0:00/24:00）
- 备选 A：沿用 AS01 左端点口径，计划窗 `0:10→24:10`，表 2 端点报「计划窗首/末状态」。规模：不变。优点：与模板 144 行精确对应、无需外推、与 AS13 一致。缺点：相对自然日整体前移 10 分钟，需在论文说明一次。适用条件：本问及 prob02–prob04 的同类对齐。
- 备选 B：强制严格自然日 `0:00→24:00`（把时间戳当右端点）。规模：不变。优点：时钟语义直观。缺点：模板末行 `0:00+1-0:10+1` 无对应数据、须外推或错位一格，与 D1 裁定冲突。适用条件：仅当团队决定改写表 2 语义并接受外推时。
- 备选 C：同时给出两套（左端点为主、右端点为附录对照）。规模：报告量翻倍。优点：信息最全。缺点：与模板结构不符、易在论文中造成两套数字混淆。适用条件：团队要求显式披露相位影响时。
- 推荐：A，理由：唯一无需外推且与模板标签、表 1 名称同时自洽；比较标准：与 `result1.xlsx` 模板的逐行一致性 > 时钟直觉 > 报告冗余度。

### D3 弃光变量的实现方式（AS08 的落地）
- 备选 A：显式 `s_t ∈ [0, PV_t·Δt]`，目标系数 0（本 formulation 采用）。规模：+144 变量与界。优点：余额严格闭合、可统计弃光、可证伪。缺点：变量数增加（本问代价可忽略）。适用条件：全部小问。
- 备选 B：不设 `s_t`，平衡式写成不等式 `b_t + PV_t·Δt + q_dis_t ≥ L_t·Δt + c_t`。规模：−144 变量。优点：模型更小。缺点：盈余去向不闭合、易被误读为隐性售电，费用可能被低估，无法统计弃光。适用条件：仅当团队接受不闭合的边界表述（不建议）。
- 备选 C：设 `s_t` 并加极小正惩罚（如 1e-6 元/kWh）。规模：同 A。优点：可打破退化最优面。缺点：引入题面未给的偏好、可能扰动最优解结构。适用条件：出现弃光量不唯一且影响报告时。
- 推荐：A，理由：题面未给售电渠道，系数 0 是最小假设且可闭合检验；比较标准：余额闭合与可证伪性 > 模型规模 > 数值便利。

### D4 目标是否扩展（折旧/弃光/购电上限情景）
- 备选 A：主目标只含购电费 `Σ p_t b_t`（AS03a/AS03b），折旧与效率扰动留待 robustness。规模：不变。优点：与题面「节省购电费用」一致、量纲清晰。缺点：充放电频次偏多、全寿命成本被低估。适用条件：主计算与交付结果。
- 备选 B：主目标加入折旧/吞吐成本项。规模：+1 组线性项。优点：更接近全寿命经济性。缺点：附录 1 无折旧系数与循环寿命，参数不可标定，会引入无依据假设。适用条件：仅当团队提供标定参数时。
- 备选 C：主目标保持 A，在 robustness 阶段量化折旧/效率情景（D7 备选 C）。规模：额外情景计算。优点：不污染主口径又能披露偏差方向。缺点：增加附加实验预算。适用条件：可选阶段 robustness 被判定需要时。
- 推荐：A + C（主目标 A、robustness 情景 C），理由：附录 1 无法标定折旧，主口径应与题面一致；比较标准：与题面的口径一致性 > 参数可标定性 > 模型完备性的边际收益。
