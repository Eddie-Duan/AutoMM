## 0. 适用性决定（先于实验）

| 扰动类别 | 是否适用 | 判定与依据 |
|---|---|---|
| 参数扰动（η、E_init、P_max、SOC 窗口） | **适用** | 单日确定性 LP，参数进入 `(R2)/(R6)/(R7a)/(R7b)`；AS05/AS06/AS11 显式声明常效率、功率上限口径与初值，须量化偏差 |
| 数据扰动 / 预测噪声（电价、负载、光伏） | **适用** | AS16 显式声明输入为确定性预测值；噪声即「预测误差」的情景传播，是 prob01 结论外推的主要风险 |
| 初值 / 随机初始化 | **部分不适用** | LP 无随机初始化、无 seed 依赖，不存在「偶然初始化」问题；`E_init` 作为**结构参数**扰动适用（AS11），"随机初始化"一类不适用并在此声明 |
| 求解器鲁棒性 | **适用** | LP 最优面可能非唯一（formulation/implementation/sanity 均记录 E 上下界两端活跃）；用 HiGHS 的三种设置对比**目标值与约束残差**，不比对逐点解 |
| 结构化情景（折旧、自放电、购电上限、售电、效率作用位置、D10 口径） | **适用** | AS03b（不计折旧）、AS14（无自放电）、AS15（无购电上限/无售电）、AS05（效率作用位置）、AS06/D10（作用侧）均为显式简化或口径选择，偏差方向已给出、数值未量化 |
| 元启发式 / 随机优化 / 全局敏感性（Sobol 等） | **不适用** | 本问为 144 时段确定性 LP，解析最优；题面未给误差分布与概率模型，Sobol 需要独立输入假设且无证据支撑；不做为展示算法而改造问题的实验 |

结论：**适用**。按团队要求执行实验并最终以 `record_optional_stage(decision="completed")` 收尾；
不存在需要整阶段跳过的理由。

## 1. 被检验的核心结论（实验前固定）

- **K1（主结果）**：accepted 口径下最优全天计划购电费 `C* = 35126.9486 元`（量级 10⁴ 元），
  全天购电量 `Σb = 59482.6990 kWh`，弃光 `Σs = 0`。
- **K2（套利有效性）**：储能套利相对「无储能、按净负荷购电」的上界 `C0 = 48052.0466 元` 降低约 26.9%；
  结论方向为「低价充电—高价放电可降低购电费」。
- **K3（简化与口径不改变方向）**：常效率、不计折旧、无自放电、无购电上限、功率作用侧取交集等显式简化
  与口径选择在合理扰动范围内**不反转 K2 的方向**，但会使 `C*` 发生可量化偏移。

## 2. 稳定性判据（实验前固定，事后不得修改）

| 判据 | 定义 | 通过阈值 | 不通过的处置 |
|---|---|---|---|
| **S1 可行率** | **核心族**（保持 accepted 目标 `Σp·b` 不放宽：baseline/eta/init/pmax/emin/emax/d10/eta_placement/self_discharge/solver/噪声）中求解 `status==0` 且等式/界残差 `≤1e-6` 的比例；失败样本保留计入分母，不得删除 | ≥ 95%（参数族 ≥ 99%） | 记「条件稳定/脆弱」，逐族定位 |
| **S2 参数扰动幅度** | OAT ±20% 内 `max|ΔC|/C*` | ≤ 25%（η=0.80 极端 ≤ 35%） | 记脆弱，报告边界 |
| **S3 噪声区间** | 联合 σ=20% 时 `C` 的 2.5–97.5 分位区间半宽 /C*、均值偏移 | 半宽 ≤ 20% 且均值偏移 ≤ 10% | 记脆弱 |
| **S4 排序稳定** | **核心族**每个情景 `C_opt < C_nostorage`（同一扰动数据下的无储能购电费） | 100% 核心族情景成立 | 记脆弱并报告反例 |
| **S5 敏感性符号** | `∂C/∂η ≤ 0`、`∂C/∂P_max ≤ 0`、`|弹性(E_init)| ≤ 1.5` | 三条同时成立 | 记符号异常项 |
| **S6 求解器一致性** | `highs` / `highs-ds` / `highs-ipm` 目标值相对差 | ≤ 1e-6 | 记数值退化 |

> **范围界定（预注册，运行前固定）**：结构族 `depreciation`（改变目标定义，加入吞吐成本）、
> `sell_price`（加入售电收益）、`buy_cap`（新增购电功率约束）会改变目标函数或可行域本身，
> 不属于「同一模型在扰动下是否稳定」的判据，故**不计入 S1/S4**，单列为 `structural_findings`
> 情景发现逐条报告（例如「吞吐成本 ≥ 某阈值时储能不再经济」「购电功率上限低于某值时原计划不可行」）。
> 这避免把有意的结构变化误判为模型脆弱，也避免用弱对照夸大鲁棒性。

分级：满足 S1–S6 ⇒ **稳定**；违反 1 条但方向不反转 ⇒ **条件稳定**（给边界）；方向反转或 S1/S4 违反 ⇒ **脆弱**。

## 3. 实验矩阵

### 3.1 基线复现（强制前置闸门）
`baseline`：accepted 口径（η=0.9 两侧、E_init=6000、E∈[1200,10800]、口径丙 `c≤833.3333`/`q≤750.0000`、
min Σp·b 不带 Δt）。必须与 run002 逐项一致（`C*`、`Σb`、`Σc`、`Σq`、`Σs` 相对差 ≤ 1e-6）；
不一致则**整批实验作废**，不得用扰动结果下结论。

### 3.2 参数扰动（OAT，一参一扰动）
| 族 | 取值 |
|---|---|
| `eta`（两侧同时） | 0.80 / 0.85 / **0.90** / 0.95 / 1.00 |
| `init`（E_init，周期末同值） | 3000 / 4500 / **6000** / 7500 / 9000 kWh |
| `pmax`（口径丙同步换算） | 4000 / **5000** / 6000 kW |
| `emin`（E_max=10800） | 600 / **1200** / 2400 kWh |
| `emax`（E_min=1200） | 9600 / **10800** kWh |

### 3.3 数据扰动 / 预测噪声（乘性，单源与联合）
- 因子 `f = max(0.02, 1 + σ·z)`，`z~N(0,1)`；电价因子下界 0.02 保证 `p_t>0`（互补性引理前提），
  负载/光伏因子允许取 0（物理非负）。
- 联合（电价+负载+光伏同时）：σ ∈ {0.05, 0.10, 0.20}，每档 **100 次**。
- 单源（仅电价 / 仅负载 / 仅光伏）：σ ∈ {0.10, 0.20}，每档 **100 次**。
- 固定种子 `20260910`（`numpy.random.default_rng`），样本序固定；每个样本记录扰动后输入的摘要指纹。
- 合计 300 + 600 = **900 次随机实验**（≥ 默认 100 次要求）。

### 3.4 结构化情景（离散情景，不作百分比编码）
| 族 | 情景 |
|---|---|
| `d10` | 甲（并网点侧）/ 乙（电池侧）/ **丙（交集，accepted）** |
| `eta_placement`（D2） | 两侧 0.9 / 仅充电侧 0.9 / 仅放电侧 0.9 / 往返整体 0.9（各侧 √0.9） |
| `depreciation`（AS03b/D7 备选 C） | 单位吞吐成本 0 / 0.05 / 0.10 / 0.20 / 0.50 元/kWh（作用于 `c_t+q_dis_t`） |
| `self_discharge`（AS14） | 自放电率 0 / 0.001 / 0.005 / 0.01 /h（`E_t = (1−ρΔt)E_{t−1} + ηc_t − q_t/η`） |
| `buy_cap`（AS15） | `b_t/Δt ≤` 3000 / 4000 / 5000 / 6000 kW（无上限为基线） |
| `sell_price`（AS15 情景） | 弃光/余电上网价 0 / 0.10 / 0.20 / 0.35 / 0.50 元/kWh（`s_t` 收益） |
| `solver`（S6） | `highs` / `highs-ds` / `highs-ipm`（同数据、同模型） |

### 3.5 报告指标
- 目标侧：`C`（元）、`Σp·b`、`Σb`、`Σc`、`Σq`、`Σs`、储能区间、等效循环次数、同时充放时段数。
- 稳定性侧：可行率、`ΔC/C*` 分布（均值/中位数/标准差/2.5–97.5 分位/自助 95% CI）、
  OAT 弹性 `(ΔC/C*)/(Δx/x)`、与无储能基线之差 `arbitrage_gain`。
- 原始与汇总分离：`raw_samples.jsonl`（每样本一行，含参数与指标）与 `summary.json`（分族统计）
  分文件保存；敏感性图单独落盘 `figures/`。

## 4. 失败处理

- 单情景 infeasible / 超时：计入可行率分母，记录 `status` 与残差，**不删除**、不进均值；
  若某族可行率 < 95%，在该族单独报告并触发 S1 失败。
- 基线复现失败：整批中止（exit 4），按 `needs_revision` 路由（robustness 代码与 accepted 模型不一致）。
- 输出含 NaN/Inf：`allow_nan=False` 直接失败，不落盘。
- 计算必须经隔离 task、独立输出目录与 supervised worker；本 Agent 不自行代跑或运行 `start_queued`。
