- 原网格 `{10,326, 8,459, 6,000, 5,000}` **全部不激活**（`Σq_em=0`），仅总费用随上限下降而上升。按
  `skills/ablation-study` 纪律，该「不激活」本身作为**一条消融记录**保留（附证据：本表 4 行 `Σq_em=0`），
  机制演示由 M6′ 承接。

## 4. 结构消融逐项解读

### 4.1 时域组织（M2a / M2b，D2）

- **M2a（精确分解）**：把耦合序列 `{E_{d,144}}` 外生固定为 M1 最优值后逐日求解，`Σ_d C_d` 与 `C_M1` **逐位相同**（相对差 `0.0`）。
- **M2b（日终自由纯递推）**：`ΔC_full = +26,894.740017 元`（+0.195482%）、`ΔC_delivery = +27,522.073350 元`（+0.224981%）。
  按 D2，该差额记为**「跨日携带价值」的结构性发现**，**不得判为实现错误**：M1 的最优解在 96 个不同日初状态水平上运营，
  M2b 把日终状态设为自由后，逐日局部最优无法复现跨日能量携带的边际价值。M2b 的 `Σb` 与 M1 相同（`22,657,938.157435 kWh`），
  但 `max 购电功率 = 10,023.9817 kW`、日初状态仅取 2 个水平——差异只在调度轨迹与成本，不在总量。

### 4.2 跨日口径（M4，D1-A/D3）与终端条件（M5，D2-B/D8-A）

- **M4（逐日独立，`E_{d,0}=E_{d,144}=6000`）**：`ΔC_full = +17,135.022542 元`（+0.124544%）、
  `ΔC_delivery = +17,803.272542 元`（+0.145534%），方向与 assumption/formulation 只读探针一致（相对差 ≤1.5e-07）。
  2/1 日起点：M1 为 `7950.00 kWh`（1/31 日末状态），M4 强制 `6000.00 kWh`——题面附录 1 只给 2025-01-01 0:00 的 6000 kWh，
  M4 把它外推到每一天，M1 则按滚动递推携带。
  **口径提醒**：M4 同时改变「跨日衔接」与「逐日终端」两件事（D1-A 的 `E_{d,0}=E_{d,144}=6000`），
  故 `ΔC` 是两者的**合并贡献**，不能在论文中单独归因于跨日连续性（见 §12 A-DR4）。
- **M5（`E_T = 6000`）**：`ΔC_full = +2,217.083333 元`（+0.016115%）、`ΔC_delivery = +2,217.083333 元`（+0.018124%），
  与探针 `+2,217.083334` 相对差 `3.0e-10`。能量账上等价于 M1 期末放空 `η_dis·(E_T − E_0) = −4320 kWh`（少购 4320 kWh）。
  **该效应必须与价格套利显式区分**：M1 的更省来自套利最优，而非「故意压库」。
- **R1（表 2 端点语义）**：prob01 为单日周期（0:00/24:00 恒 6000 kWh）；prob02 为**全年滚动逐日切片**，
  端点随日变化（例：2025-03-20 = `8550.00` / `4352.866148`；2025-06-21 = `2361.059963` / `8550.00`；
  2025-09-23 = `8550.00` / `8550.00`；2025-12-21 = `8550.00` / `8550.00`）。论文表 2 说明处须与 prob01 显式区分一次，
  且不得与 AS01 左端点相位（计划窗 0:10→24:10）说明混用。

### 4.3 购电上限与紧急购电机制（M6/M6′，R2/R5 + D4）

- 主口径（AS10 无上限）下 `Σq_em ≡ 0`，表 3 与 `result2.xlsx`「紧急购电量」全零——这是**定理 T1 的模型内推论**
  （完全信息 + 无上限 + `α_em=5>1`），不是实测断言，也**不是文献结论**。
- M6′ 首次把该机制**数值演示并验证**出来：`B` 从 4,375 降到 2,000 kW 时，`Σq_em` 由 0 单调升到 7,845,369.34 kWh、
  启用天数由 0 升到 365，费用由 +5.045% 升到 +138.183%。`β ∈ (4218.75, 4375.00] kW` 与 formulation §3.8 定理 T2、
  团队独立复跑、robustness L6 结构情景**三方一致**。
- 论文表述必须使用 `β`，**不得**再称「低于 10,326 kW 即强制 `q_em>0`」；`10,325.33 kW` 只是非绑定阈值。

### 4.4 弃光变量 `s`（结构项，目标系数 0）

`s` 在多日下**真实激活**（`Σs = 990,168.090312 kWh`，且 `990,168.09 / 365 ≈ 2,713 kWh/日`），但其目标系数为 0，
故对费用的**经济贡献为 0**——这是本阶段的一条消融记录（「保留变量、贡献为 0」），而不是跳过理由。
**外推边界**：该「无贡献」不能外推到 prob03/04；若引入售电或让 `s` 进入目标，必须先把上界收紧为物理盈余
（robustness 的 A-DR5 已记录 `sell_price ≥ 0.50 元/kWh` 时的非物理套利）。

### 5.2 双路线同解（B2 第 1 条）

### 5.3 `Σq_em = 0` 的可证性说明（B2 第 2 条 ④）

设 `p > 0`、`α_em = 5 > 1` 且 `b` 无上界，则任一含 `q_em,τ = δ > 0` 的可行解可令 `b'_τ = b_τ + δ`、`q'_em,τ = 0`：
可行域不变（平衡式两边同增 δ、`b` 无上界），而目标严格下降 `(α_em − 1)·p·δ > 0`。故最优解满足 `q_em ≡ 0`
（定理 T1；**依赖「完全信息 + 外网购电无功率上限 + `α_em > 1`」三前提同时成立**）。实测 `Σq_em = 0` 是这一推论的数值印证，而非独立断言。

## 9. 与 robustness 的边界（B5）与冲突登记

- **分工**：`robustness` 负责参数扰动与置信区间（η、E_init、α_em、负载/光伏噪声、`s` 的界、购电上限情景）；
  本节负责**模型族、口径与实现路线**对照。两者数值**不互相替代、不混写**。
- **M4/M5**：只在 `ablation` 出数（D8-A）；robustness 只可带出处引用，不得混写。
- **`b` 上限族**：robustness 的 `b_cap` 族与本文 M6/M6′ 属**独立计算**。**冲突检查结果：无冲突**——
  两者对 `β` 的夹逼一致（`β ∈ (4218.75, 4375.00] kW`），`B=4218.75 kW` 的 `Σq_em = 8,707.398542 kWh`、14 天
  与 formulation 定理 T2、团队独立复跑逐位一致；`10,326 kW` 均被判为非绑定阈值。
- **robustness 的已知弱/失败项不得被本节掩盖**：robustness L6 判 `criteria_failed=[S1,S5]`、`stability_grade=脆弱`。
  其中 S1 的唯一失败项 `complementarity_sum` 属返回解清洁度而非可行性（AS07 不禁止同充放、引理 L1 仅为存在性），
  本文 17/17 模型的同充放时段数均为 0，可作交叉印证；S5 为 η±10% 的日尺度双向敏感性。论文必须原样呈现这两项，
  不得改写为稳定或不可行；本节不重跑参数扰动，也不以其结论替代 robustness。
- `s` 的物理界、售电套利、`α_em=0.5` 等结构情景的数值归 robustness；本节只报告 M6/M6′ 的结构结论。

## 11. 结论段（`agents/ablation-analyst.md` 团队要求的三问）

### ① 核心结论是否依赖模型族？

**不依赖。** M1 的交付期费用 `12,233,050.830708 元`（全期 `13,758,182.573724 元`）被两类**独立路线**复现：

- **M2a**（逐日解耦 + 耦合序列外生固定）：相对差 `0.0`；
- **M7**（消去 `s`、等价不等式对、`highs-ds` + `presolve=False`）：相对差 `0.0`、平衡残差 `2.27e-13`；
- **M3**（互补 MILP）：全规模 `rel_diff = 3.17e-07`（容差内、且不低于 M1），4 个日规模 MILP oracle 精确同值
  （相对差 ≤3.98e-16、`mip_gap=0`、1 节点）。全规模 MILP 未在 300 s 内证明最优（技术债 A-DR1），
  但引理 L1 的解析无损性 + 4/4 oracle 已使 C3 结论不依赖该 MILP 是否跑到最优。

**结构性差额的来源**：M2b 与 M1 相差 `+26,894.74 元`（全期），来源是**跨日电能携带的边际价值**——
M1 的最优解在 96 个不同日初状态水平上运营，把日终状态设为自由后逐日局部最优无法复现该价值（D2 结构性发现）。
