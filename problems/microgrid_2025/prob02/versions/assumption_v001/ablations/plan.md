## 1. 被检验的核心结论（实验前固定）

- **K1（主结果不依赖模型族）**：M1 的交付期费用 `12,233,050.830708 元`（全期 `13,758,182.573724 元`）
  可被 **M2a**（精确分解）与 **M7**（独立第二实现）在 B2 容差内复现；**M3**（互补 MILP）按引理 L1
  应与 M1 同值（`MILP ⊂ LP`，且 LP 存在互补最优解）。
- **K2（跨日携带价值）**：M2b（日终自由纯递推）与 M1 的差额**非零且 ≥ 0**，其结构性来源是
  跨日电能携带的边际价值（M1 日初状态取多个不同水平）；该差额**不得**判为实现错误（D2）。
- **K3（跨日口径贡献）**：M4（逐日独立、`E_{d,0}=E_{d,144}=6000`）比 M1 **更贵**
  （formulation/assumption 只读探针：全期 +17,135.02 元、交付期 +17,803.27 元），方向不得反转。
- **K4（终端条件贡献）**：M5（`E_T = 6000`）比 M1 **更贵**（探针交付期 +2,217.083334 元，+0.0181%），
  即期末放空（`E_T = 1200`）在能量账上等价于少购 4320 kWh；该效应必须与价格套利显式区分。
- **K5（购电上限与紧急购电机制）**：M6 原网格 `{10,326, 8,459, 6,000, 5,000} kW` **全部不激活**
  （`Σq_em = 0`，仅总费用随上限下降而上升）；M6′ 网格 `{4,375, 4,218.75, 4,000, 3,750, 3,000, 2,000} kW`
  在 `β ∈ (4218.75, 4375.00] kW` 附近与以下激活，且随上限下降 `Σq_em` 单调不减、总费用单调不降。
- **K6（复杂方法的必要性）**：M3/M2/M7 相对 M1 不带来题目指标收益；M1 仍是唯一推荐交付口径（B0）。

> 上述数值来自 assumption/formulation 的**只读诊断探针**，此处仅作待验证的预测；本阶段必须以
> 隔离 task 的产物独立复算，探针值不得作为交付数值。

## 3. 对照集合与实验矩阵（B1 + D2–D5）

统一口径：365 天、`Δt = 1/6 h`、`η_ch = η_dis = 0.9`、`c ≤ 833.3333 kWh`、`q_dis ≤ 750.0000 kWh`、
`E ∈ [1200, 10800]`、`E_init = 6000 kWh`、`α_em = 5`、目标 `min Σ(p·b + 5p·q_em)`（元，**不乘 Δt**）、
CPU HiGHS、`seed = 20260910`（本实验确定性，无随机源）、输出隔离到 `ablations/results/prob02_v001_ablation_run001/`。

### 3.1 M1（基准，主模型）

`(P2)` 原样：365 天 × 144 时段单一 LP；`E_T` 自由；`b` 无上界；
`linprog(method="highs", presolve=True, time_limit=300)`。**C1 强制闸门**对象。

### 3.2 M7（实现级交叉验证）

M1 的**独立第二实现**：**消去弃光变量 `s`**，把逐时段平衡改写为等价的不等式对

```
(R1a)  b_τ + q_em,τ + q_dis,τ − c_τ ≥ (L_τ − PV_τ)·Δt
(R1b)  b_τ + q_em,τ + q_dis,τ − c_τ ≤ L_τ·Δt
```

（由 `s = b + q_em + q_dis + PV·Δt − L·Δt − c`、`0 ≤ s ≤ PV·Δt` 推出，与原式等价），
变量 `(b, q_em, c, q_dis, E)` 共 `5T + T = 6T`（列序不同、无 `s` 列），
求解器设置改为 `method="highs-ds"`、`presolve=False`。
求后由 `(R1a)` 回代重建 `s`，并独立核对 `0 ≤ s ≤ PV·Δt` 与逐时段平衡残差 ≤ 1e-8（B2 第 1 条）。

### 3.3 M2a / M2b（逐日解耦 + 跨日状态递推）

日规模子问题（每股 144 时段）：变量 `(b, q_em, c, q_dis, s, E)` 共 864、等式 288；`E_0` 为**参数**。

- **M2a（精确分解，C2 对象）**：把耦合序列 `{E_{d,144}}` **外生固定**为 M1 最优值
  （`E_{d,0}` 亦取 M1 轨迹，保证跨日连续性），逐日求解。理论上 `Σ_d C_d = C_M1`。
- **M2b（日终自由纯递推）**：`E_{d,0}` 取前一日递推结果（首日 6000），`E_{d,144}` 自由；
  `Σ_d C_d ≥ C_M1`，差额记为**跨日携带价值**（D2），不得判为实现错误。

### 3.4 M3（互补 MILP；模型族对照 + 数值 oracle，D5）

在 M1 上追加 `u_τ ∈ {0,1}`、`c_τ ≤ 833.3333·u_τ`、`q_dis,τ ≤ 750.0000·(1 − u_τ)`
（`M` 取 §3.7 的**紧上界**，非「足够大的数」）；`scipy.optimize.milp`，`time_limit = 300 s`、`mip_rel_gap = 0`。
记录 `mip_gap`、节点数、incumbent；超时未证最优按 C3 降级并登记技术债。

**独立数值 oracle（D5 第二句）**：对 4 个指定日期（2025-03-20 / 06-21 / 09-23 / 12-21），
以 M1 轨迹的 `E_{d,0}` 为初值、`E_{d,144}` 自由，各建一个**日规模 MILP**（`4 × 144 = 576` 个二元）
与对应日规模 LP 松弛；判据为两者目标值相对差 ≤ 1e-6 且 MILP 同充放时段数 = 0。

**内存隔离（工程纪律）**：全规模 MILP 在**独立子进程**中运行（`sys.executable` + 文件重定向，
不使用管道），父进程以墙钟上限守护；子进程因内存/超时退出时父进程记录降级，**不使整批失败**。

### 3.5 M4（跨日口径对照，D3）

逐日独立 LP：每日施加 `E_{d,0} = E_{d,144} = 6000 kWh`（D1 备选 A），365 天；**只改跨日口径**。
报告全期合计与交付期切片（334 天）两个数值。

### 3.6 M5（终端条件对照，D2 备选 B / D8-A）

在 M1 上追加 `E_T = 6000 kWh`（用变量界固定末状态），**只改终端条件**。
报告全期与交付期，并给出期末放空的能量账价值 `η_dis·(E_T − E_0) = −4320 kWh`。

### 3.7 M6 / M6′（外网购电上限情景族；勘误 R2 + R5 + D4）

在 M1 上追加 `b_τ ≤ B·Δt`，**只改 `b` 的上界一项**：

| 族 | `B` (kW) | 预期 |
|---|---|---|
| M6（原网格） | 10,326 / 8,459 / 6,000 / 5,000 | 全部非激活（`Σq_em = 0`），费用随 `B` 下降上升 |
| M6′（追加，非替换） | 4,375 / 4,218.75 / 4,000 / 3,750 / 3,000 / 2,000 | `β ∈ (4218.75, 4375.00]` 附近与以下出现 `Σq_em > 0`，且单调 |

### 3.8 B2 五维度/交叉验证的记录项

1. **约束满足度**：`equality_residual_max`、`bound_violation_max`、`|E_{d,0} − E_{d−1,144}|`、
   两侧换算功率 ≤ 5000 kW、同充放时段数、`checks_failed`。
2. **题目指标**：全期/交付期 `C`、`C_plan`、`C_em`、`Σb`、`Σq_em`、`Σc`、`Σq_dis`、`Σs`、`E_T`；
   4 个指定日期的 `表 1` 六时段（位置 60/72/84/96/108/120，1 基）购电量、`表 2` 六块充/放电量与
   0:00/24:00 储电量（**区分 prob01 单日周期语义**，R1）；以及 `Σq_em = 0` 的可证性说明。
3. **解析恒等式（B2 第 2 条）**：对每个模型算并登记
   `(I1) Σq_dis = η²Σc − η(E_T − E_0)`、
   `(I2) Σb = N + Σs + (1 − η²)Σc + η(E_T − E_0) − Σq_em` 的全期与交付期残差（含终端项），
   及逐日连续性 `|E_{d,0} − E_{d−1,144}| ≤ 1e-6`。
4. **复杂度**：变量数、等式/不等式约束数、二元数、非零元、求解时间（s）、迭代数、`mip_gap`、节点数。
5. **解释性**：充/放电时段电价均值（套利方向）、日初状态水平数、储能区间、等效满循环次数。
6. **鲁棒性维度**：**带出处引用** robustness `prob02_v001_robust_run001` 的 S1–S6 与 OAT 弹性，
   本阶段不重跑参数扰动（B5）。

### 3.10 均匀性与「每次只改一项」核对

M2a/M2b 只换时域组织；M3 只加互补二元；M4 只换跨日口径；M5 只换终端条件；
M6/M6′ 只加 `b` 上界；M7 只换实现路线（模型相同）。**数据、参数、目标、求解预算、随机种子全部一致**（B4）。

### 3.11 公平性纪律（B4，违反即结果作废）

- **同数据**：只用 `data/附件1.xlsx` 的**电价列**与 `data/附件2.xlsx` 的**实际负载/光伏**；
  禁用附件 1 的预测列、附件 3、附件 4。附件 md5 记入 `run_manifest.json`。
- **同参数**：§3 统一口径。
- **同预算**：同一 Python/包环境、同一 HiGHS 族、CPU（**不占 GPU**，`gpu_required=false`）、
  `seed = 20260910`；每个全年 LP `time_limit = 300 s`，MILP ≤ 300 s。
- **同口径**：目标不带 `Δt`；交付期费用量级 10^7 元（出现 10^6 即量纲/范围错误）。
- **不改动 / 输出隔离**：不修改 accepted `code/`、`formulation_v001/`、`assumptions.md`、`results/`；
  对照实现只存在于 `ablations/code/`，产物只写入 `ablations/results/prob02_v001_ablation_run001/`。

### 3.12 与 robustness 的边界（B5）

robustness（`prob02_v001_robust_run001`，task `f7a4e670b91ad469d771`）负责参数扰动与置信区间，
其 `b_cap` 族与本节 M6/M6′ 属**独立计算**，数值**不得互相替代或混写**。
本阶段报告 §7 将（a）引用其稳定性分级与 `β` 夹逼结论并注明出处，
（b）若 M6/M6′ 的 `β` 夹逼或 `Σq_em` 量级与 robustness 不一致，**显式列出冲突点与处理方式**。
M4/M5 的数值一律以本阶段为准，robustness 只可带出处引用（D8-A）。

## 5. 失败处理

- 单 case 不可行 / 超时 / 非零返回：保留在 `raw_cases.jsonl` 并计入失败计数，**不删除、不静默替换**；
  在 `comparison.json` 中写「不可行/未执行 + 原因」并按 `allow_pass_with_warning` 登记技术债。
- 全规模 MILP 超时/内存不足：父进程记录 `degraded=true` 与原因，以 4 个指定日期的日规模 MILP
  作为独立数值 oracle，C3 按技术债登记（D5）。
- C1 基线复现失败：**整批中止**（exit 4），按 `needs_revision` 路由，不引用任何对照数值。
- 输出含 NaN/Inf：`allow_nan=False` 直接失败，不落盘。
- 计算必须经隔离 task、独立输出目录与 supervised worker；本 Agent 不自行代跑、不调用 `start_queued`。
  代码修复只允许在新 attempt + 新 `output_directory` 下重跑，不覆盖既有结果。
