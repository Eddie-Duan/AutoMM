| 结构/约束情景（`s` 的界、售电收益、`b` 购电上限、`α_em<1` 边界） | **适用（单列）** | AS09（`s` 的界）、AS10（无上限）、AS07（`q_em` 机制）均为显式简化或制度口径；会改变目标或可行域本身，故**不计入** S1/S4 的「同模型稳定性」，单列 `structural_findings` 逐条报告 |
| M4（逐日独立）与 M5（终端 = 6000）情景 | **不适用（本阶段不跑）** | 团队裁定 B1/D8-A 明确 M4/M5 在 `ablation` 出数；B5 只禁止数值互替、允许带出处引用。本实验**不重复计算**，报告只引用并注明来源 |

## 1. 被检验的核心结论（实验前固定）

- **K1（主结果与交付口径）**：accepted M1 的全年总购电费 `C* = 13,758,182.573724 元`、交付期（2/1–12/31）
  `C*_req = 12,233,050.830708 元`、`Σb = 22,657,938.157435 kWh`、`Σq_em = 0`、
  `Σs = 990,168.090312 kWh`、`E_{12/31,144} = 1200.00 kWh`，以及 4 个指定日期的表 1/表 2 数值。
  鲁棒性实验须证明这些**交付数值**在合理扰动下不被推翻。
- **K2（紧急购电机制与激活阈值）**：无购电上限口径下最优 `Σq_em ≡ 0`（定理 T1 前提：完全信息 + 无上限 + `α_em>1`）；
  只有把 `b` 的功率上限压到激活阈值 `β` 以下才会出现 `Σq_em > 0`。本实验独立复算 `β` 的网格夹逼区间，
  与 `formulation_v001 §3.8` 定理 T2 / 团队勘误 R5 的 `β ∈ (4218.75, 4375.00] kW` 交叉验证。
- **K3（套利方向）**：在全部核心扰动情景下，含储能的 `C_opt` 严格小于同一扰动数据下的
  「无储能、按净负荷购电」费用 `C_nostorage`，即「低价充电—高价放电降低购电费」的方向不反转。
- **K4（参数与噪声稳健性）**：`η`、`E_init`、`α_em`、`P_max`、`E` 窗口在 ±5%/±10%/±20% 内、
  以及 100 次输入噪声实验下，费用相对变化有界（见 S2/S3），可行率 100%（S1），交付表（4 个指定日期的
  全天购电量/购电费与表 1 六时段）稳定（S5）。
- **K5（`s` 的界与售电边界）**：把 AS09 的 `0 ≤ s ≤ PV·Δt` 收紧为物理盈余 `max(0, PV·Δt − L·Δt)`（D5-B）
  **不改变**最优值（`s` 目标系数为 0）；若给 `s` 正收益（0.50 元/kWh）则出现「买入再卖」的非物理套利，
  说明松界只在引入售电时才会成为风险——该情景为**结构边界登记**，不进入主口径。
- **K6（实现与求解器一致性）**：本实验的参数化模型在 accepted 口径下逐位复现 run002（相对差 ≤ 1e-6），
  且目标值对 HiGHS 的求解设置（`highs`/`highs-ds`/`highs-ipm`/关闭 presolve）不敏感（≤1e-6）。

## 2. 稳定性判据（实验前固定，事后不得修改）

| 判据 | 定义 | 通过阈值 | 不通过处置 |
|---|---|---|---|
| **S1 可行率** | **核心族**（`baseline`、`eta`、`eta_asym`、`init`、`alpha`、`pmax`、`ewin`、`s_bound`、`solver` 及噪声族）中 `status==0`、等式/界残差 ≤1e-6 **且全部硬检查通过**的比例；失败样本保留计入分母 | 参数族 ≥ 99% 且整体 ≥ 95% | 记「条件稳定/脆弱」，逐族定位 |
| **S2 参数幅度与符号方向** | OAT ±20% 内 `max|ΔC|/C*`；并检验 `∂C/∂η ≤ 0`、`∂C/∂P_max ≤ 0`、`|弹性(E_init)| ≤ 1.5` | 幅度 ≤ 25%（`η` 极端档 ≤ 35%）且三条方向同时成立 | 记脆弱/符号异常并给边界 |
| **S3 噪声区间** | 100 个噪声样本 `C` 的 2.5–97.5 分位半宽 `/C*`、均值偏移；另按族分别报告自助 95% CI | 半宽 ≤ 20% 且 \|均值偏移\| ≤ 10% | 记脆弱并给分布 |
| **S4 套利方向** | 核心族每个情景 `C_opt < C_nostorage`（同一扰动数据） | 100% 成立 | 记脆弱并报告反例 |
| **S5 交付表稳定性** | 参数 OAT **±10%** 情景的 4 个指定日期「全天购电量」「全天购电费」相对基线偏差；表 1 六时段每个 slot 的绝对偏差 / 当日全天购电量 | 相对偏差 ≤ 10%；slot ≤ 15% | 记脆弱并定位日期/时段 |
| **S6 求解器一致性** | `highs`/`highs-ds`/`highs-ipm`/关闭 presolve 目标值两两相对差 | ≤ 1e-6 | 记数值退化 |

> **范围界定（预注册）**：结构族（`s_bound`、`s_sell`、`alpha_lt1`、`b_cap`）改变目标定义或可行域本身，
> 不属于「同一模型在扰动下是否稳定」，故**不计入 S1/S4**，单列为 `structural_findings` 逐条报告。
> 这避免把有意的结构变化误判为模型脆弱，也避免用弱对照夸大鲁棒性。

分级：满足 S1–S6 ⇒ **稳定**；违反 1 条且方向不反转 ⇒ **条件稳定**（给边界）；方向反转或 S1/S4 违反 ⇒ **脆弱**。

### 3.3 数据扰动 / 输入噪声（乘性；共 **100** 个随机样本）
- 因子 `f = max(下界, 1 + σ·z)`，`z~N(0,1)`；负载因子下界 0.2（保持正负载），光伏因子下界 0（物理非负），
  电价因子下界 0.05（保持 `p_t>0`，互补性引理前提）。
- 4 个族各 **25** 个样本（合计 100）：
  1. `noise_white_5`：负载+光伏**逐时段独立**白噪声，`σ=5%`；
  2. `noise_white_10`：负载+光伏**逐时段独立**白噪声，`σ=10%`；
  3. `noise_day_5`：负载+光伏**按日持续**（同一日内 144 时段共用因子），`σ=5%`；
  4. `noise_joint_day_5`：负载+光伏+电价**按日持续**，`σ=5%`。
- 固定种子 `20260910`；第 `i` 族第 `s` 个样本用 `numpy.random.default_rng(seed + i·100003 + s)`，
  样本序与结果可复现；每个样本记录扰动后输入的聚合指纹（`load_energy_ratio`、`pv_energy_ratio`、`price_sum_ratio`）。

## 5. 失败处理

- 基线复现失败：整批中止（exit 4），按 `needs_revision` 路由（本实验代码与 accepted 模型口径不一致）。
- 单情景 infeasible / 超时：计入可行率分母，保留 `status`、残差与标签，**不删除**、不进均值；
  若某核心族可行率 < 95%，在该族单独报告并触发 S1 失败。
- 输出含 NaN/Inf：`allow_nan=False` 直接失败，不落盘；不可行样本的目标值写 `null`。
- 图件生成失败不使数值结果作废，但须在 manifest 的 `figures` 与报告中登记。
- 计算必须经隔离 task、独立输出目录与 supervised worker；本 Agent 不自行代跑、不在短命 shell 内调用
  `start_queued`。

## 6. 预算与执行方式

- 规模：49 个矩阵情景 + 100 个噪声样本 = **149 次全年 LP 求解**（52,560 时段 / 315,360 变量 / 105,120 等式）。
- 实测：单次全年 LP **5.1–7.9 s**（本动作小探针，CPU HiGHS，见 §8）；含评估与产物写入预计 **20–45 min**。
- task 时限设 5,400 s（≈ 68× 实测单次耗时，留足极端档与超时重试余量）；`runner` 以
  `worker_launch_mode=supervised`（in-process）启动；单 worker 串行（本机可用内存偏低，不安排并发）。
- 设备：CPU（本问**无 GPU 需求**，单卡 GPU 串行约束不适用）；记录 `seed=20260910`。
