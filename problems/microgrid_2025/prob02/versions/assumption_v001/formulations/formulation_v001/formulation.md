## 3. 逐步推导

### 3.1 时间离散与全局索引（AS01/AS02）

附件 1/2 的 10 分钟粒度给出

```
(R0)  Δt = 24 h / 144 = 1/6 h = 0.166667 h ；T = 365 × 144 = 52560
      τ = 144(d − 1) + t ,  d = ⌈τ/144⌉ ,  t = ((τ − 1) mod 144) + 1
```

位置 `i` 代表区间 `[10(i−1), 10i)` 分钟（AS01 左端点口径，计划窗 `0:10 → 24:10`）。功率→电量换算为
`X_τ·Δt`（`X ∈ {L, PV}`）；决策变量 `b, q_em, c, q_dis, s` 直接以 kWh 表示（**已含 Δt 因子**），
故目标与平衡式中**不再对决策变量乘 Δt**。

### 3.2 逐时段电量平衡（AS06 + AS09）

一个时段内进入系统的电量（外网计划购入 `b_τ`、紧急购入 `q_em,τ`、光伏可用 `PV_τ·Δt`、储能放电 `q_dis,τ`）
等于离开系统的电量（负载 `L_τ·Δt`、储能充电 `c_τ`、弃光 `s_τ`）：

```
(R1)  b_τ + q_em,τ + PV_τ·Δt + q_dis,τ = L_τ·Δt + c_τ + s_τ          ∀τ
(R3s) 0 ≤ s_τ ≤ PV_τ·Δt                                               ∀τ（AS09）
```

`(R1)` 是**等式**：同时给出「余额闭合」与「充电不与负载竞争」两个语义（prob01 团队裁定 D3 = 本问 AS06 备选 A）。

### 3.3 「微网提供的电能不可低于小区负载」的蕴含（题面 H1）

微网实际提供给负载的电量为

```
b_τ + q_em,τ + q_dis,τ + (PV_τ·Δt − s_τ) = [L_τ·Δt + c_τ + s_τ] − s_τ = L_τ·Δt + c_τ ≥ L_τ·Δt   （用 (R1)）
```

因 `c_τ ≥ 0`。题面可靠性要求被 `(R1)` 与 `c_τ ≥ 0` **自动蕴含**，无需另加不等式。
弱口径「净供给 ≥ 负载」（AS06 备选 B，已否）把充电算作供给，会放松可行域并可能制造账面套利，不采用。

### 3.4 储能状态转移、跨日衔接与终端条件（AS03/AS04/AS08/AS13）

### 3.5 结构恒等式（含终端项；供 sanity L1/L2 与解析界使用）

对 `(R2)` 在全期求和并代入 `(R4)`：

`η_dis(E_T − E_0) = 0.9 × (1200 − 6000) = −4320 kWh`——即 **「期末放空」在能量账上等价于少购 4320 kWh**

**逐日切片**（对第 `d` 天求和，`N_d = Σ_t (L_{d,t} − PV_{d,t})·Δt`）：

```
(I1d) Σ_t q_dis,dt = η_ch·η_dis·Σ_t c_dt − η_dis·(E_{d,144} − E_{d,0})
(I2d) Σ_t b_dt = N_d + Σ_t s_dt + (1 − η_ch·η_dis)·Σ_t c_dt + η_dis·(E_{d,144} − E_{d,0}) − Σ_t q_em,dt
```

`(I1)/(I2)` 与 §3.8 的定理 T1 共同构成**不依赖求解器**的结构性检验（B2 第 2 条第 ①②、第 3 条）。

### 3.7 充放电功率上限的两侧交集（AS08 + D10 口径丙 + 勘误 E1）

  ⇒ `c_τ ≤ min(P_max·Δt, P_max·Δt/η_ch) = min(833.333, 925.926) = 833.333 kWh` **(R7a)**
- 放电：并网点侧 `q_dis,τ/Δt ≤ P_max`；电池侧 `q_dis,τ/(η_dis·Δt) ≤ P_max`
  ⇒ `q_dis,τ ≤ min(P_max·Δt, P_max·Δt·η_dis) = min(833.333, 750.000) = 750.000 kWh` **(R7b)**

「5000 kW 作用侧」是 `team_decision`，**现有两池文献均无一条涉及，不得包装为文献支持**（C4）。

### 3.8 紧急购电机制：`q_em ≡ 0` 的定理与购电上限族 P2(B)

#### 定理 T1（完全信息 + 无购电上限 ⇒ 最优 `q_em ≡ 0`）

设 `p_τ > 0`（附件 1 电价 ∈ [0.3713, 1.3952]，成立）、`α_em = 5 > 1`，且 **`b_τ` 无上界**。
则 `(P2)` 存在最优解使 `q_em,τ = 0 (∀τ)`。

**证明**：设可行解在某时段 `τ₀` 有 `q_em,τ₀ = δ > 0`。构造 `b'_{τ₀} = b_{τ₀} + δ`、`q'_{em,τ₀} = 0`，其余变量不变。
- 可行性：`(R1)` 左端变化 `+δ − δ = 0`，右端不变；`b' ≥ 0` 且**无上界**，`q'_em ≥ 0`；其余约束不受影响。
- 目标变化：`p_{τ₀}·(+δ) + α_em·p_{τ₀}·(−δ) = −(α_em − 1)·p_{τ₀}·δ < 0`，严格改进。
故任何含 `q_em > 0` 的可行解都不是最优解。∎

**推论 T1'**：`(P2)` 的最优值与「`q_em ≡ 0` 的受限模型」的最优值相同；主口径下
**表 3 与 `result2.xlsx`「紧急购电量」工作表全为 0**（填报写法见 §7）。
`q_em ≡ 0` 是**本题模型内的数学推论**（依赖 T1 的三个前提），**不是文献结论**（AS07 纪律），
论文不得包装为文献支持；`q_em` 仍**必须保留为决策变量与约束**（题面要求给出紧急购电结果，
`global_symbols.yaml` 亦明确「不得因预期恒零而删除」）。

#### 定理 T2（上限族 P2(B)：非绑定阈值 ≠ 激活阈值）

定义参数族 **(P2(B))**：在 `(P2)` 上追加 `b_τ ≤ B·Δt`（`B` 为外网购电功率上限，kW；M6 的模型形式），其余不变。
记 `F(B)` 为 `(P2(B))` 的可行集、`C(B)` 为最优值，并区分两个不同的「零紧急购电」量：

- `Q̃_em(B) := min{ Σ_τ q_em,τ : x ∈ F(B) }`（**任意可行点**上的最小紧急购电量；`Q̃_em(B) = 0 ⟺ F₀(B) := {x ∈ F(B) : q_em = 0} ≠ ∅`）；
- `Q_em(B) := min{ Σ_τ q_em,τ : x 是 (P2(B)) 的最优解 }`（**最优解**上的最小紧急购电量）。

则：

1. **可行性单调**：`B₁ ≤ B₂ ⇒ F(B₁) ⊆ F(B₂)`。故 `C(B)` 关于 `B` **单调不增**；
   `Q̃_em(B)`（在更大的集合上取 min）关于 `B` **单调不增**。这是 B3-C5 的判据来源。
2. **非绑定阈值**（旧登记所称的 10,326 kW）：`B ≥ B_peak := max_τ b*_τ` 时，无上限主模型的最优解 `x*` 满足加界，
   故 `C(B) = C(∞)`、`Q̃_em(B) = Q_em(B) = 0`。本数据 `B_peak = 10,325.33 kW`（探针 `max b_τ = 1720.8883 kWh`）。
3. **强制阈值** `θ := inf{B : Q̃_em(B) = 0}`：`B < θ ⇒ F₀(B) = ∅`，即**每一个**可行点（因而每一个最优解）都满足 `Σq_em > 0`——
   紧急购电在此区间内被**强制**。
4. **激活阈值** `β := inf{B : Q_em(B) = 0}`（即「最优解可以做到不紧急购电」的下确界）。由 1、2、3 得 `θ ≤ β ≤ B_peak`。
   `θ ≤ B < β` 是**中间区**：机制不被强制，但最优解仍可能启用它（因为此时 `b` 在紧急购电所在时段恰好顶到上限，
   定理 T1 的「等量改为计划购电」替换被上界阻断）。**`β ≤ B_peak` 且一般严格小于**——把 `B_peak` 当作激活阈值是错误的。
5. **解析必要下界**：`F₀(B) ≠ ∅` 需要存在满足 `(R1)–(R7b)` 且 `q_em = 0` 的可行点；
   由 `(R1)` 得 `b_τ + q_dis,τ = (L_τ − PV_τ)·Δt + c_τ + s_τ ≥ (L_τ − PV_τ)·Δt`，
   取 `τ* = argmax(L − PV)` 并用 `b ≤ B·Δt`、`q_dis ≤ 750.0000`：

```
       B·Δt + 750.0000 ≥ max_τ (L_τ − PV_τ)·Δt   ⇒   θ ≥ max_τ (L_τ − PV_τ) − 5000·η_dis
                                                      = 7978.8849 − 4500 = 3478.8849 kW
       （因而 β ≥ θ ≥ 3478.8849 kW）
```

6. **两个阈值都必须数值确定**：`θ` 是可行性 LP 的相变点、`β` 是最优值意义上的相变点，均无闭式解；

### 3.11 逐日决策与全期求解的等价性（命题 P1，§1 的可实施性依据）

**命题 P1**：设 `x*` 是 `(P2)` 的最优解。定义逐日策略：第 `d` 天在 `0:00` 以 `E_{d,0} = E*_{d,0}` 为初值、
执行 `x*` 的第 `d` 天切片 `(b*, q*_em, c*, q*_dis, s*)_d`。则每一天的切片在「已知当日与未来全部确定性输入」下
是**剩余时域最优策略**的限制，逐日执行可复现 `C*`，且每日末状态自动等于 `E*_{d,144}`（`(R2)` 在 `τ = 144d` 处）。

**证明要点**：`(P2)` 的可行域是若干块（按日）× 一条状态链的笛卡尔结构的线性交；目标按日可加。
把 `x*` 限制到第 `d` 天即得一个可行点，其目标等于分解中的第 `d` 项；若某日切片不是给定边界状态下的最优，
则替换为更优切片可改进全期目标，与 `x*` 最优矛盾。∎

**意义**：本问「每天 0:00 制定当天计划」与「对 365 天一次性求解」在完全信息下等价，
因此**不需要**引入滚动时域近似、预测误差模型或鲁棒优化（其必要性属 prob03 的信息结构变化，见 A7/A9）。
反之，若团队改取 AS07 备选 B/C（不完美信息或购电上限），该等价性失效，必须重新裁定。

### 3.12 互补性引理与模型间退化/等价条件（B2 第 3 条 + B3-C2/C3/C4）

#### 引理 L1（互补性；`(P2)` 的 LP 松弛无损）

设 `p_τ > 0`、`η_ch·η_dis = 0.81 < 1`。若 `(P2)` 的一个可行解在某时段同时有 `c_τ > 0` 与 `q_dis,τ > 0`，
则存在另一个可行解使目标严格更小；故 `(P2)` 存在满足 `c_τ·q_dis,τ = 0 (∀τ)` 的最优解。

**证明**：取 `δ > 0` 满足 `δ ≤ c_τ`、`η_ch·η_dis·δ ≤ q_dis,τ`，令 `c'_τ = c_τ − δ`、
`q'_{dis,τ} = q_dis,τ − η_ch·η_dis·δ`。由 `(R2)`，储电量变化为 `η_ch(−δ) − (−η_ch η_dis δ)/η_dis = 0`，
故 `E` 轨迹不变、`(R4)/(R5)` 仍满足。由 `(R1)`，`b'_τ = b_τ − δ(1 + η_ch η_dis) < b_τ`（其余变量不变），
目标下降 `p_τ·δ(1 + η_ch η_dis) > 0`，与最优性矛盾。∎

**推论 L1'**：M3（追加互补二元的 MILP）的最优值**等于** M1（LP）的最优值，
即 **B3-C3 的「M3 无损性」是解析结论而非仅经验观察**；`C_M3 < C_M1 − 1e-6` 不可能发生（MILP ⊂ LP 松弛的可行域，
且 L1 保证 LP 存在互补最优解）。单日 smoke test 实测 LP = MILP = 56,298.331511 元（相对差 1.29e-16，`mip_gap = 0`，§8）。

## 4. 候选建模/求解方案与 M1–M7 定义

### 4.1 候选方案（≥3，覆盖精确 / 启发式 / 混合；规模与利弊在**看到计算结果前**固定）

#### 候选 A：单层完整长时域 LP（M1，直接调用 HiGHS）——推荐主路径

- **核心思想**：按 `(P2)` 直接建连续 LP（315,360 变量 / 105,120 等式 / 473,039 非零元），调用成熟内点/单纯形实现求全局最优。
- **规模量级**：无整数变量；单次求解预算 ≤ 300 s、内存 ≤ 2 GB（实测 26.8 s、峰值 traced 113 MB，§8）。
- **优点**：全局最优 + 对偶界；无 Big-M、无整数间隙；跨日衔接天然成立（无需协调变量）；与 §3.5 恒等式、§3.12 引理互相印证；确定性 LP 无 seed 依赖。
- **缺点**：要求严格线性建模纪律（`s` 必须显式、功率上限必须换算为电量、目标不得乘 Δt）；`E` 显式时矩阵规模较大。
- **失效条件**：若团队改取不完美信息、非凸效率或启停约束，LP 不再等价；或内存/时限预算被纳入 8 GB 显存/2 GB 内存约束时需改用候选 B。
- **适用/不适用**：本问完全适用；prob03/04 若仍为线性（分段结算可线性化）亦适用。

#### 候选 B：逐日解耦 LP + 跨日状态递推（M2）

- **核心思想**：把 `(P2)` 按日分解为 365 个 144 时段子问题，用 `E_{d,144}` 作为协调量逐日传递。
  **两个变体**：**B1 = M2a**（耦合序列外生固定，等价于对 (P2) 的精确分块求解）、**B2 = M2b**（日终自由，纯贪婪递推）。
- **规模量级**：子问题 864 变量 / 288 等式；365 次求解或可并行；内存 < 50 MB。
- **优点**：单次求解极小、天然可并行（CPU）；可解释性强（逐日费用可分解）；M2a 可作为 M1 的实现级交叉验证。
- **缺点**：M2b 无全局最优保证（丢失跨日携带价值）；M2a 需要外生耦合序列，不能独立于 M1 使用。
- **失效条件**：电价曲线逐日不同（prob04）或引入日内调整（prob03）时，M2b 的偏差会放大。
- **适用/不适用**：M2a 作为 M1 的**分解验证**适用；M2b 作为**基线/降级路径**适用，不作为交付口径。

#### 候选 C：互补 MILP（M3，精确 oracle）

- **核心思想**：在 `(P2)` 上加 `u_τ ∈ {0,1}`、`c_τ ≤ M_c·u_τ`、`q_dis,τ ≤ M_q·(1−u_τ)`，
  `M_c = 833.3333`、`M_q = 750.0000`（**由 §3.7 推导的紧上界**，不是「足够大的数」），分支定界求最优。
- **规模量级**：变量 315,360 + 52,560 二元 = 367,920；追加不等式 105,120。
- **优点**：把 LP 互补性从引理变成硬约束，可作为 LP 解的独立复核；若出现退化最优面，MILP 直接给物理可实现解。
- **缺点**：52,560 个二元变量的分支树在 60 s 预算内**可能无法证明最优**（B1 已允许按 `allow_pass_with_warning` 登记技术债）。
- **失效条件**：Big-M 取大（如 1e6）会削弱松弛；`η`/`P_max` 变更而未同步 `M` 会误删可行解。
- **适用/不适用**：作验证 oracle 适用；**不建议**作为主计算路径。因引理 L1 已给出**解析**无损性，
  全规模 MILP 的必要性主要是「独立于引理的数值复核」（见 D5）。

#### 候选 D：时间聚合—降尺度启发式（aggregation / disaggregation）

- **核心思想**：把 144 个 10 分钟时段聚合为 24 个整点（或 6 个 4 小时块），在聚合粒度上求解 `(P2)` 的降维模型，
  再按组内功率比例/等分恢复 10 分钟决策，最后用 `(R1)` 与 `s` 的界做可行性修复（修复阶段不重解）。
- **规模量级**：聚合模型变量 `6 × 24 × 365 = 52,560`（降低 6 倍）；恢复与修复 O(T)。
- **优点**：求解更快、内存更省；可直接对照题面表 2 的 4 小时块口径；可解释（粗粒度策略 + 细粒度修复）。
- **缺点**：无最优性保证（先聚合后恢复会引入不可闭合的余额误差）；对光伏/负载的组内波动敏感（本数据 `PV ∈ [0, 10216.2] kW`，日内波动剧烈）。
- **失效条件**：组内净负荷符号翻转（`PV > L` 与 `PV < L` 混在同一组）时修复会破坏 SOC 轨迹或触发越界。
- **适用/不适用**：作为**降级/对照**适用；不适合需要最优性或最优性证明的交付口径。

#### 候选 E：拉格朗日/块坐标分解（hybrid）

- **核心思想**：以跨日状态 `E_{d,144}` 为耦合变量，对 `(P2)` 做拉格朗日松弛或 Gauss–Seidel 块坐标：
  交替求解 365 个日度子问题并用边界 SOC 的价格（乘子）协调，外层迭代直至耦合残差与对偶间隙收敛。
- **规模量级**：子问题 864 变量；外层数十次迭代；总规模与候选 A 同阶但单次更小。
- **优点**：为 prob03（日内多发布时刻调整）与 prob04（逐日不同电价）提供可扩展路径；单块失败可局部修复；易并行。
- **缺点**：无全局最优保证（对偶间隙需自估）；实现复杂度高；本问规模下相对候选 A 无收益。
- **失效条件**：日间耦合强（`E` 的携带价值高）时收敛慢或振荡；乘子初值不当会不可行。
- **适用/不适用**：**本问不必要**；当 prob03/04 使单层 LP 不再合适时再评估。

#### 候选 F：价格阈值规则式启发式（含可行性修复）

- **核心思想**：按电价分位阈值划分低价/高价时段，低价段按 SOC 余量充电、高价段放电，再用 `(R1)` 与
  `q_dis ≤ (L − PV)⁻·Δt + c` 修复可行性与弃光。
- **规模量级**：无优化变量；O(T log T) 排序 + O(T) 扫描，运行时间 ≪ 1 s。
- **优点**：不依赖求解器、可复现、给出可解释基线与 regret 参考。
- **缺点**：无最优性保证；对阈值、初值与效率敏感；无法给出对偶界。
- **失效条件**：价格曲线非 TOU 型（prob04 的实时电价）或 SOC 深度受限时 regret 显著放大。
- **适用/不适用**：作为**基线/降级**适用；不得作为交付口径。

## 6. 局限与不适用

1. **完全信息确定性（AS07）**：0:00 已知当日实际负载/光伏，不处理预测误差；`q_em ≡ 0`（定理 T1）**依赖**该前提与「无购电上限」「`α_em > 1`」三者同时成立。prob03 改变信息结构时必须重新裁定。
2. **终端自由（AS04）**：`E_T` 自由导致期末放空（`E_{12/31,144} = 1200 kWh`），在能量账上等价于少购 4320 kWh；
   论文必须显式披露该效应并与价格套利区分；`E_T = 6000` 情景只使交付期费用 +2,217.08 元（+0.018%，M5）。
3. **无购电上限（AS10）**：计划购电峰值 10,325.33 kW 属不可执行的尖峰（题面未给联络线容量）；
   引入上限会改变结论（见 C6 与 P2(B)），数值来源须由团队裁定（D4/D6）。
4. **常效率 90%（AS08）**：η 与 SOC 无关；真实效率是 SOC/温度/倍率的函数，偏差方向已由 `robustness` 量化（prob01 阶段结论）。

## 待团队选定的决策点

### D1 求解路线（主口径）
- 备选 A：单层完整长时域 LP（M1，HiGHS）。规模：变量 315,360、等式 105,120、界 315,360、非零元 473,039。优点：全局最优 + 对偶界、无 Big-M、跨日衔接天然成立、可复现。缺点：要求严格线性口径。适用条件：本问及一切确定性线性调度口径。
- 备选 B：逐日解耦 + 跨日递推（M2a 精确分解 / M2b 纯递推）。规模：子问题 864 变量 / 288 等式 × 365。优点：单次极小、可并行、易解释。缺点：M2b 无全局最优保证、M2a 需外生耦合序列。适用条件：作为分解验证或降级路径。
- 备选 C：互补 MILP（M3）。规模：367,920 变量（含 52,560 二元）、追加不等式 105,120。优点：把引理变成硬约束、可独立复核。缺点：分支树在 60 s 内可能无法证明最优、失去对偶。适用条件：仅作 oracle，不作主路径。
- 备选 D：时间聚合—降尺度启发式。规模：聚合模型 52,560 变量。优点：求解快、内存省、对接 4 小时块。缺点：无最优性保证、组内净负荷翻转时修复易破坏 SOC 轨迹。适用条件：求解器不可用时的降级或对照。
- 备选 E：拉格朗日/块坐标分解（hybrid）。规模：子问题 864 变量 + 外层迭代。优点：易扩展到 prob03/04。缺点：无全局最优保证、实现复杂、本问无收益。适用条件：prob03/04 规模或结构使单层 LP 不再合适时。
- 备选 F：价格阈值规则启发式。规模：无变量。优点：无依赖、毫秒级、基线。缺点：无最优性保证、对阈值敏感。适用条件：降级或对照。
- **推荐：A**。理由：本问小规模确定性线性、A 给出全局最优，且引理 L1 与命题 P1 分别消解了「需要二元变量」与「需要滚动近似」的疑虑。比较标准：最优性保证（对偶界/status）> 硬约束满足度 > 量级自检 > 运行预算（≤300 s）> 解释性 > 鲁棒性。
