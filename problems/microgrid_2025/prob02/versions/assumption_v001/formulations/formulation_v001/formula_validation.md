## 2. 量纲一致性（V1）

记 `[·]` 为量纲。`Δt = 1/6 h`；`p_τ`：元/kWh；`L_τ, PV_τ`：kW；决策变量与 `E_τ`：kWh。

| 公式 | 左端量纲 | 右端量纲 | 结论 |
|---|---|---|---|
| `(R1) b + q_em + PV·Δt + q_dis = L·Δt + c + s` | kWh | kWh（功率项已乘 Δt） | 闭合 |
| `(R2) E_τ = E_{τ−1} + η_ch·c − q_dis/η_dis` | kWh | kWh（`η`、`1/η` 无量纲） | 闭合 |
| `(R3s) 0 ≤ s ≤ PV·Δt` | kWh | kWh | 闭合 |
| `(R6) C_total = Σ(p·b + 5·p·q_em)` | 元 | 元/kWh × kWh = 元 | 闭合；**无 Δt 因子（D9）** |
| `(R7a) c ≤ P_max·Δt` | kWh | kW × h = kWh | 闭合 |
| `(R7b) q_dis ≤ P_max·Δt·η_dis` | kWh | kW × h（无量纲因子） | 闭合 |
| 两侧功率写法 `c/Δt`、`η_ch·c/Δt`、`q_dis/Δt`、`q_dis/(η_dis·Δt)` | kW | kW | 闭合 |
| `(I1) Σq_dis = η_ch·η_dis·Σc − η_dis·(E_T − E_0)` | kWh | kWh | 闭合 |
| `(I2) Σb = N + Σs + 0.19·Σc + η_dis·(E_T − E_0) − Σq_em` | kWh | kWh | 闭合 |
| `C_total ≥ p_min·[N + η_dis(E_min − E_0)]` | 元 | 元/kWh × kWh = 元 | 闭合 |
| `B·Δt ≥ (L_τ − PV_τ)·Δt − 750.0000`（T2 第 4 条） | kWh | kWh | 闭合（两侧同除 Δt 得 kW） |

**已知硬错误模式（必须失败）**：

- `F1`：目标写作 `Σ p·b·Δt` → 量纲为「元·h」，数值偏小 6 倍（D9 已裁定修正）；
- `F2`：把 5000 kW 直接当成电量上界（漏乘 Δt）→ 可行域放大 6 倍；
- `F3`：`(R1)` 中 `L`/`PV` 漏乘 Δt → 电力与电量混加；
- `F4`：把「非绑定阈值 10,325.33 kW」当成 `q_em` 的激活阈值 → 见 §10 的 C6。

探针断言：`AC_CAP = 5000·Δt = 833.3333 < DC_C_CAP = 925.9259`、`DC_Q_CAP = 750.0000 < AC_CAP`；
目标系数即 `p_τ`（无 Δt 因子）；`p_min·N_full = 7,527,295.15 元`（10^7 量级）。

- 非负与不等式方向由 `(R1)–(R7b)` 明确，不存在遗漏的边界条件：

## 7. 数值可解性与条件（V7）

- **可行性（构造性证明）**：§4.4 的「无储能解」与「全靠紧急购电解」都是可行点，且 `E ≡ 6000` 满足 `(R2)/(R5)`。
- **有界性**：目标系数 `p_τ ≥ p_min = 0.3713 > 0`；由 `(I2)`，任何可行解的 `Σb` 被
  `N + Σs + 0.19Σc + η_dis(E_T − E_0) − Σq_em` 约束，而 `Σc ≤ T·833.3333`、`Σs ≤ ΣPV·Δt`，
  且 `Σq_em` 的系数 `5p_τ > 0` 使其不会无界增大，故目标有有限下界 `p_min·[N + η_dis(E_min − E_0)]`。
- **求解器实测**：HiGHS（`scipy.optimize.linprog(method="highs")`）`status = 0 (Optimal)`，
  52560 时段用时 **26.8 s**、峰值 traced 内存 **113.16 MB**、等式残差 `1.819e-12`；
  在 CPU/内存预算（≤ 300 s / ≤ 2 GB）内。
- **退化与多解**：SOC 上下界两端均活跃、`c` 与 `q_dis` 上界均被顶到，可能存在多重最优。
  因此实现阶段必须固定并记录求解器/容差；sanity 以**约束残差 + `(I1)`/`(I2)` + 目标值 + 表 1/表 2** 为准，
  **不比对逐点解的唯一性**；报告逐时段数值时须与 `result2.xlsx` 同源同次求解。
- **条件数/尺度**：系数仅含 `1`、`0.9`、`1/0.9`、`1/6` 与 `p_τ ∈ [0.3713, 1.3952]`，无非标度大数，无需缩放。
  若实现采用自研单纯形，建议保留 `E` 变量而非消元，以保持稀疏结构（非零元 473,039）。

## 8. 解结构与互补性（V8）

- 引理 L1（`formulation.md` §3.12）：`η_ch·η_dis = 0.81 < 1` 且 `p_τ > 0` ⇒ 存在最优解满足 `c_τ·q_dis,τ = 0 (∀τ)`；
  证明中的替换不改变 `E` 轨迹（`η_ch(−δ) − (−η_chη_disδ)/η_dis = 0`），只降低 `b` 与目标。
- 实测：同充放时段数 `= 0`（全期 365 天）；等式残差 `1.819e-12`。
- **单日 smoke test（2025-12-21，144 个互补二元，`M_c = 833.3333`、`M_q = 750.0000`）**：
  LP `56,298.331511 元` = MILP `56,298.331511 元`，相对差 `1.292e-16`，`mip_gap = 0`。
- 结论：**B3-C3 的「M3 无损性」有解析依据（引理 L1），不必依赖全规模 MILP 是否跑到最优**；
  `C_M3 < C_M1 − 1e-6` 在数学上不可能（MILP ⊂ LP 松弛的可行集，且 L1 保证 LP 存在互补最优解）。

## 12. 失败类型与回退路由（供实现/计算阶段复用）

| `failure_type` | 触发条件 | 建议回退 |
|---|---|---|
| `dimension_error` | 目标含 Δt 因子（F1）、功率当电量（F2）、kW/kWh 混加（F3） | 回 `mathematical_formulation`（§2） |
| `boundary_error` | `E_0 ≠ 6000`、SOC 越界、`s` 越界、误加日周期或终端约束（口径越界） | 回 `implementation` 修约束；若属口径问题回 `assumption_definition` |
| `conservation_error` | `(I1)`/`(I2)`（含终端项）残差 > 1e-6 | 回 `implementation`（约束漏写/终端项漏写/单位错） |
| `monotonicity_error` | 放宽容量/功率后费用变差；`C(B)` 非单调不增；`Σq_em(B)` 非单调不减 | 回 `implementation` 或复核目标方向与 `b` 上限的施加方式 |
| `threshold_misuse` | 把 `B_peak = 10,325.33 kW` 当作 `q_em` 的激活阈值（F4 / C6） | 回 `mathematical_formulation`（§10），不得据此宣称机制已激活 |
| `infeasible` | solver status = infeasible | 依次检查单位、约束方向、`E_init`、上下界、时段索引；单次不可行按 `model_infeasible` 恢复，不人工阻塞 |
| `unbounded` | solver status = unbounded | 检查目标符号与 `b` 的下界 |
| `complementarity_violation` | 同充放时段 > 0 且经引理 L1 判定非退化 | 升级候选 C（MILP）复核 |
| `template_mapping_error` | 表 1/表 2/表 3 行号映射或工作表行序与模板不符（含 R3/R4） | 回 `implementation`；相位问题回 `assumption_definition`（AS01） |
| `scale_confusion` | 交付期与全期统计混用（B2 第 4 条） | 回 `sanity_check`/`visualization`，按 §4.3 分别列示 |

Harness invariant（task/输出/hash 不一致、非法迁移等）严格失败；上述均属模型计算类故障，
按 `PROJECT.md`/`RESEARCH_LOOP.md` 的 failure class 恢复或降级审查，不触发人工阻塞。
