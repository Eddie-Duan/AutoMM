### AS08 主价格预测器 `PF-PERSIST` 与滚动回测协议（**key**，criticality=high，适用 4-2/4-3）

- **精确陈述**：**主预测器 = 前一日同时段（persistence）**：`\hat p_{d,i} = p^{act}_{d−1,i}`（`i = 1..144`），即 0:00 用**前一日全天 144 点实际价**作为当天 144 点的点预测；`d = 2025-01-01` 无前一日 ⇒ 该日不参与回测（`D_full` 计数 364 天）。**强制基准对照**：`PF-DUAL`（水平 × 时段双因子：`\hat p_{d,i} = \mu_d · s_i`，`s_i` = 归一化历史同时段均值形状、`\mu_d` = 最近 7 个可用历史日的日均价均值）与 `PF-HIST`（历史同时段扩张窗均值）。**滚动回测协议（跑数前冻结）**：只用 `t` 日之前的信息；评估窗口主口径 `D_req` = 2025-02-01…12-31（334 天），`D_full`（364 天）作诊断；指标 **MAE 为主判据**，同时报 MAPE、RMSE、偏置与绝对误差分位数 P50/P90/P99；**选择规则**：`D_req` MAE 最小者；MAE 相对差 < 1% 视为并列、取更简者。`PF-AR`（逐时段 AR(1)/惩罚回归）登记为 `ablation` 强制对照（不参与主口径选择）。
- **类型**：数值近似（预测）；**证据类型**：`literature_fact`（框架级）+ 本动作只读探针（诊断）；**文献**：`ref-chitsaz-2018-price-forecast-btm-storage`、`ref-lago-2018-spot-price-deep-learning`（27 种预测器的公平基准比较，简单模型常不劣于复杂模型）、`ref-kapoor-2023-nz-price-forecasting`（统计 vs 机器学习 + 基准对照 + sMAPE/MASE）、`ref-ibebuchi-2025-daep-endogenous-predictors`（**滚动窗口交叉验证 + 只用预测时点可得信息**）、`ref-myttenaere-2016-mape-regression`（MAPE 有偏 ⇒ 必须同时报绝对误差指标）。
- **依据（本动作只读探针，`D_req` 口径；**诊断用，非交付数值**）**：`PF-PERSIST` MAE `0.084326` 元/kWh、MAPE `13.780%`、RMSE `0.123837`、bias `−0.000595`、P50/P90/P99 = `0.0500/0.2294/0.3773`；`PF-DUAL` MAE `0.093183`、MAPE `15.181%`、RMSE `0.120951`、bias `−0.000328`、P90/P99 = `0.2052/0.3334`；`PF-HIST` MAE `0.100231`、MAPE `16.330%`、RMSE `0.136878`、bias `+0.013161`。逐日 MAE 夺冠次数（334 天）：`PF-PERSIST` 218 / `PF-HIST` 67 / `PF-DUAL` 49。⇒ 按预注册规则取 `PF-PERSIST` 为主口径，`PF-DUAL`/`PF-HIST` 为强制基准（见 D1）。
- **适用边界**：两链**共用**（`A8-(b)` 派生 ⑥）；`4-3` 的调整层在此基础上的滚动更新见 AS11。**失效条件**：若实现使用了任何 `t` 日当天信息（含用当天实际价做形状/水平估计）即越界；若形式回测的 `D_req` MAE 与探针相对差 > 5%，须先怀疑实现口径（前向填充、相位、日期切片）而不是改预测器。
- **预期偏差方向**：`PF-PERSIST` 的 MAE 最低但**尾部较重**（P90/P99 高于 `PF-DUAL`）；若决策对高价时段误差更敏感，更换预测器可能降低费用——这正是 D1 与「预测器选择敏感性」判据要量化的对象。
- **验证方式**：`implementation` 必须在隔离 task 中复现同一滚动回测并落盘三者的全部分位数；`sanity` L3 复核「预测器输入不含 `t` 日信息」；论文报告三者的完整指标表并把预测器选择敏感性（换用 `PF-DUAL` 的 `ΔC_total`）放入 `ablation`。
- **关系**：AS07（信息集）的落地；AS09（误差代价）与 AS11（滚动更新）的前提；AS22（接口）。
- **状态**：`accepted`。

### AS09 决策—结算分离与「价格预报误差的代价」双口径（**key**，criticality=high，适用 4-2/4-3）

- **精确陈述**：**决策层**（`4-2` 计划层；`4-3` 计划层与调整层）的目标函数与偏差/紧急项**使用该层信息集下的预测价** `\hat p`；**结算层**的**全部**费用分项（`C_plan`、`C_em`、`C_adj` 的两分段）一律**按附件 4 实际价** `p^{act}` 计。对**同一组已提交决策**（`b`、`q`、`c`、`q_dis`、`s`、`q_em`）分别按两套价格计价，得到 `C^{act}`（**主口径，真实支出**）与 `C^{fc}`（决策层信念下的账面费用），并给出
  `ΔC_price = C^{act} − C^{fc}`，**按分项分解**（`ΔC_plan`、`ΔC_em`、`ΔC_adj`）与全年/交付期两窗口 **同时**报告。论文必须把 `ΔC_price` 命名为「**价格预报误差的代价**」并给出其相对量级。
- **类型**：报告口径（成本）；**证据类型**：`literature_fact`；**文献**：`ref-khani-2015-online-adaptive-rtod`（预测价决策 / 事后价结算；预测不准显著降低收益）、`ref-staffell-2016-maximising-storage-value`（无预知 vs 完美预知的对照设计）、`ref-mathaba-2014-price-forecast-benefit`（以调度成本增量度量价格预测的经济价值）、`ref-hodge-2018-forecast-value-storage`（预测改进的价值须与储能联合评估）、`ref-antweiler-2021-storage-microeconomics`。
- **适用边界**：两链全部费用；**失效条件**：若出现「部分分项用预测价、部分用实际价」而**未逐项写明**，即口径含糊（`shared/literature.md` §4 P3 的裁定要点）；两套口径的**决策量必须完全相同**（只换计价价格，不重解模型），否则不是误差代价而是方案对比。
- **预期偏差方向**：若只用预测价报总费用 ⇒ 系统性低估/高估真实支出；若只用实际价而不给 `C^{fc}`，则无法回答「预测误差值多少钱」。
- **验证方式**：`sanity` L3 复核费用分解恒等式 `|C^{act} − (C_plan^{act} + C_em^{act} + C_adj^{act})| ≤ 1e-6`（4-2 无 `C_adj` 项）；同时复核 `C^{fc}` 各分项按预测价可逐项复算；论文与 `ablation` 同时给出 `ΔC_price` 与「预测器选择敏感性」。
- **关系**：AS08（误差大小）的经济映射；AS15/AS17（分项定义）；AS11（调整层的预测价）。
- **状态**：`accepted`。

### AS10 `4-2` 的逐日计划与跨日向前递推（**key**，criticality=high，适用 **4-2**）

- **精确陈述**：`4-2` 的决策节奏为**每天 0:00 制定一次当天计划、当天不再调整**。实现为**逐日向前递推**：对每个 `d ∈ D_full`，用 `\hat p_{d,·}`（AS08，只用 `d−1` 及之前的价格）与**当天已知的附件 2 实际负载/光伏**解一个**单日**确定性 LP（计划层），提交该日的 `(b, c, q_dis, s)`；状态按 `E_{d,0} = E_{d−1,144}` 传递（`E_{1/1,0} = 6000`，终端自由）。**不存在**跨日的价格完全预知：`4-2` **不得**写成单一长时域 LP（那需要全年电价信息，违反 AS07）。可行性由计划层的等式平衡保证（`s ≥ 0` 自由处置），故结算层无能量缺口 ⇒ `q_em ≡ 0`（AS16）。
- **类型**：机理（决策时序）；**证据类型**：`literature_fact`；**文献**：`ref-krishnamurthy-2018-arbitrage-da-rt`（日前—实时两阶段结构）、`ref-yang-2023-da-rt-shared-storage`（日前计划 + 实时偏差）、`ref-staffell-2016-maximising-storage-value`（无预知可用信息下的调度上界对照）。
- **适用边界**：仅 `4-2`；**失效条件**：若写成「单一长时域 LP + 预测价」（假设未来日价格已知）或「每天复位 `E=6000`」，即分别违反 AS07 与 AS03。**与 prob02 的差异**：prob02 的 `D8-A`（单一长时域、价格完全已知）在 `A8-(b)` 下**不可用**（P4-D1），故本假设是对承接口径的**强制派生修正**，须在论文显式说明。
- **预期偏差方向**：若误用单一长时域 LP（预测价）会把跨日价格信息「提前」给计划层 ⇒ 费用被低估；若误用完全信息实际价 ⇒ `4-2` 退化为 prob02 的同构问题（被禁止）。
- **验证方式**：`implementation` 落盘逐日求解日志（每日一个 LP、状态传递、目标值），`sanity` L1 检查「计划层输入指纹中不存在任何 `≥ d` 日的价格」；与 `4-3` 的结构对照：`4-3` 在「无调整、预报=实际、预测价=实际价」的退化条件下应与 `4-2` 同构（结构检查，**不是**数值相等理由）。
- **关系**：AS03（状态传递）、AS07（信息集）、AS15（目标）、决策点 D2/D3。
- **状态**：`accepted`。

### AS11 `4-3` 调整层的滚动价格预测与逐层信息集（**key**，criticality=high，适用 **4-3**）

- **精确陈述**：`4-3` 有 4 个决策时刻 `m ∈ {0, 6, 12, 18}`（小时）。**逐层信息集**：
  - **计划层（`m = 0`，0:00）**：价格 `= \hat p^{(0)}_{d,i} = p^{act}_{d−1,i}`（AS08 主预测器）；光伏 = 附件 3 的 `0:00` 发布预报降尺度（AS19）；初始状态 `E_{d−1,144}`。
  - **调整层（`m ∈ {6,12,18}`）**：价格 = **已实现部分用实际价、未实现部分用滚动更新的预测价**：
    `\hat p^{(m)}_{d,i} = p^{act}_{d,i}`（`i ≤ 6m`，已提交/已实现），
    `\hat p^{(m)}_{d,i} = κ_m · p^{act}_{d−1,i}`（`i > 6m`），其中水平校正因子
    `κ_m = A_m / B_m`，`A_m` = 当日 `i ≤ 6m` 的实际均价、`B_m` = **前一日同时段** `i ≤ 6m` 的实际均价；
    防御性截断 `κ_m ∈ [0.5, 2.0]`（预期不触发，触发须登记）；`κ_0 ≡ 1`（使 `m = 0` 层与两链共用预测器一致）。
    光伏 = 附件 3 的该时刻（`m`）发布预报降尺度；锁定 `i ≤ 6m`（不回溯）；剩余时段 `R_m = {i : 6m < i ≤ 144}`。
- **类型**：信息结构；**证据类型**：`literature_fact`；**文献**：`ref-chitsaz-2018-price-forecast-btm-storage`（小时内滚动更新）、`ref-jiang-2015-hour-ahead-bidding-adp`（信息逐步揭示时的序贯决策 + 完全信息基准）、`ref-khani-2015-online-adaptive-rtod`（用滚动可得历史在线修正）。
- **适用边界**：仅 `4-3`；**失效条件**：调整层使用 `i > 6m` 的**实际价**（越界）、或使用全天实际价（违反 AS07）、或对已提交时段回溯修改（违反 AS18）。
- **预期偏差方向**：不给水平校正（即 `κ_m ≡ 1`）会把当日已实现的价格信息浪费掉 ⇒ 调整层预测偏旧；过度校正（不截断）会在异常日放大误差。
- **验证方式**：`implementation` 落盘每层 `κ_m`、每层使用的价格/光伏来源与被锁定时段；`sanity` L1 逐层对照本表；`robustness`/`ablation` 给出「`κ_m ≡ 1`（不更新）」与「`PF-DUAL` 滚动更新」的对照费用。
- **关系**：AS07（信息集）、AS08（基础预测器）、AS17/AS18（调整层的结算与三层结构）；决策点 D6。
- **状态**：`accepted`。

### AS12 主口径 = 价格点预测 + 确定性 LP；不确定性对照仅 `ablation`（**key**，criticality=high，适用 4-2/4-3）

- **精确陈述**：两链的**主结果只出自**「价格点预测（AS08/AS11）+ **确定性线性规划**」；随机规划、鲁棒优化、概率/区间预测、在线/ADP 策略**只能**作为 `ablation` 对照出现，并必须标注口径差异；**不得**用任何对照模型的数值替换主结果（承 prob03 `B0`）。若改为「场景随机」或「鲁棒」为主口径，**必须先由团队裁定**并新建假设版本。
- **类型**：数值近似（模型族）；**证据类型**：`literature_fact`；**文献**：`ref-akbari-2019-stochastic-robust-arbitrage`（随机—鲁棒混合）、`ref-oconnor-2025-conformal-price-forecast`（概率/区间价格预测）、`ref-jiang-2015-hour-ahead-bidding-adp`（无分布策略 vs 完全信息基准）。
- **适用边界**：两链；**失效条件**：把鲁棒/随机结果写进主表或结论；或反过来，用「点预测主口径」否认不确定性的存在（须由 `ablation` 量化）。
- **预期偏差方向**：点预测主口径对尾部风险不设防（`PF-PERSIST` 的 P99 达 `0.3773` 元/kWh）⇒ 论文必须披露该局限并给出对照量级。
- **验证方式**：`ablation` 必须给出「完全信息上界」（价格完全预知 + 光伏完全信息，**仅 4-3 需要**光伏完全信息，见 P4-D4）、「场景/鲁棒对照」、「预测器选择敏感性」三组；`sanity` L1 核对主表数值只来自主口径 run。
- **关系**：AS07/AS08；决策点 D8。
- **状态**：`accepted`。

### AS13 两链共用同一预测器与同一结算口径（`A21 = (a)`，criticality=high，key=false，适用 4-2/4-3）

### D1 主价格预测器（`A8-(b)` 派生①，高优先）
- 备选 A：**`PF-PERSIST`（前一日同时段）**（本版推荐）。定义：`\hat p_{d,i} = p^{act}_{d−1,i}`；`4-3` 调整层按 AS11 的 `κ_m` 做水平校正。依据：本动作滚动回测 `D_req` MAE `0.084326` 元/kWh、MAPE `13.780%`，为三者最低，逐日夺冠 218/334；`ref-lago-2018` 支持「简单模型常不劣于复杂模型」。影响：实现与审计最简、易复现；尾部较重（P90/P99 = 0.2294/0.3773）。优点：MAE 最优、口径最少、回测最稳。缺点：牺牲尾部精度（`PF-DUAL` 的 P90/P99 更低），对高价时段的决策风险略高。
- 备选 B：**`PF-DUAL`（水平 × 时段双因子）**。定义：`\hat p_{d,i} = \mu_d · s_i`（`s_i` = 归一化历史同时段形状、`\mu_d` = 最近 7 日日均价均值）。依据：与附件 4 的「日因子 × 形状」（`R²` 均值 `0.939`）结构一致；探针 RMSE `0.120951`、P90 `0.2052`、P99 `0.3334`、bias `−0.000328` 均优于 A。影响：MAE 比 A 高 `10.5%`；多两个估计超参数（窗口 7 天、形状归一化）。优点：尾部更稳、偏置更小。缺点：MAE 更差，且与「按 MAE 预注册」不一致（替换须重跑回测并披露）。
- 备选 C：**`PF-HIST`（历史同时段扩张窗均值）**。依据：最稳健的长期均值估计。影响：MAE `0.100231`、MAPE `16.330%`、bias `+0.013161`（受 1 月高价位影响），三者最差。优点：几乎无参数。缺点：对水平漂移反应慢、偏置明显。
- **推荐：A**。理由：预注册选择规则（`D_req` MAE 最小、并列取更简）在其自身证据下唯一指向 A；B/C 作为**强制基准对照**必须在论文与 `ablation` 中给出完整指标与「预测器选择敏感性（`ΔC_total`）」；`PF-AR` 登记为 `ablation` 强制对照但不参与主口径选择。

## R-1 `S-VAR`（价格场景两阶段随机对照）— 批准

- **模型**：两阶段随机 LP。**第一阶段** = 计划购电量 `b`（**全场景共用**，here-and-now）；**第二阶段** = 场景内调整/结算（`c, q_dis, q_em, E, q`）。
  目标 `min_b Σ_s p_s [ Σ_t c_t^(s)·b_t·Δt + Q_s(b) ]`。
- **必须的改写（漏则数字错）**：**不得**把首阶段费用写成 `c^base·P_plan`。`A8-(b)` 下 0:00 电价未知、**结算一律用附件 4 实际价**
  （`A22`），故**计划购电的账单本身是场景相关的**，必须落在 `Q_s` 内（**数量共用、费用进场景**）。
- **场景数 = 24**，**必须用附件 4 的历史实际价格构造经验场景**（对第 `d` 天取此前同型日的 144 点实际价向量、等概率；
  或同时段残差 bootstrap）。**不得凭空设分布**（承 prob03 `E4` 证据纪律、本文件 §4 的文献边界）。
- **规模裁剪**：**代表性日**（12 个，或 4 个指定日 + 月度代表日）× 24 场景，写成**确定性等价**大 LP（`linprog` 直接解）。
  第二阶段线性 ⇒ 追索函数 `Q_s(b)` 凸分片线性 ⇒ **确定性等价与 Benders/L-shaped 同解** ⇒ **不实现 Benders**（省代码、易独立复算）。
- **报告四项**：(a) 期望费用相对主口径「点预测 + 确定性」的**下降幅度**；(b) 首阶段 `b` 的**形状差异**（对冲发生在哪些时段）；
  (c) **计算成本**（证明裁剪必要）；(d) 与「价格预报误差的代价」（§5.5/`AS09`）**并置披露**。
- **计算量标定（实测）**：单日链路 LP ≈ **0.104 s**（prob03 `M1` 全年 37.9 s ÷ 365）⇒ 12 代表日 × 24 场景 ≈ **30 s**。
