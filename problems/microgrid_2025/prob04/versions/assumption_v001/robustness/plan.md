## 1. 与团队裁定/勘误的接口（效力高于本文默认做法）

1. **`A8-(b)` 派生⑤（信息集，最高优先）**：任何情景**不得**让决策层看到当天实际价或未来价。实现纪律：
   ① 扰动的是**价格序列本身**（历史与结算同一序列），`decision_price` **一律由扰动后的序列经 `PF-PERSIST` 重算**，
   而不是对 `decision_price` 单独加噪；② `4-3` 调整层的 `κ_m` 同样只用扰动后序列的「当日已实现 + 前一日同时段」；
   ③ `sanity` 的置乱探针结论（置乱未来日 ⇒ 预测逐位不变）在本阶段**逐样本复核一次**（抽样 3 个价格类情景）。
2. **`E-F5`（预测器报告纪律）**：凡报告预测误差，**必须同时给出 `MAE`/`MAPE` 与 `P90`（或 `P99`）**，`PF-PERSIST` 与 `PF-DUAL`/`PF-HIST`
   **成对给出 `RMSE`/`P90`/`P99`**；**禁止**只报单一指标、**禁止**据单一指标宣称任一预测器「更优」（两预测器优劣方向相反）。
3. **`E-F2`（极端低价披露）**：附件 4 存在 `min = 0.0076` 元/kWh 的极端低价（`< 0.10` 仅 28 格）⇒ 以 `p_min` 构造的解析下界极松，

## 2. 预注册核心结论 K1–K8（跑数前冻结）

> 主结果只出自 `M4-2`/`M4-3` 主口径（`AS12`）；robustness 不改变任何主结果，只判定「结论是否依赖脆弱参数、输入噪声或偶然初始化」。

- **K1（费用量级与恒等式）**：
  - 交付期 `C_total^{act}` 两链均落在 `[3e6, 5e7]` 元（承 `AS12`/`B3-5` 量级带）；单链基准分别为
    `4-2 = 13,006,411.041148` 元（无 `C_adj`）、`4-3 = 15,289,050.714738` 元（`13,106,641.487373 + 522,512.788776 + 1,659,896.438588`）。
  - `C_total^{act} = C_plan^{act} + C_adj^{act} + C_em^{act}` 恒等式残差 ≤ `1e-6`（`4-2` 的 `C_adj ≡ 0`）。
  - 全期 `D_full` 与交付期 `D_req` **两窗口同时报告**。
- **K2（紧急购电机制，分链）**：
  - `4-2`：`Σq_em ≡ 0`（**定理级**）⇒ 全部受判样本 `max|Σq_em|(D_full) ≤ 1e-9` kWh、`days_with_emergency = 0`；
    表 3/`紧急购电量` 全零，须给机制说明（承 prob02 `D7-A`）。
  - `4-3`：`Σq_em > 0`（基准 `D_req = 394,026.040750` kWh、`D_full = 410,453.995927` kWh）；
    `q_em > 0 且 c > 0` 的时段数与同充放时段数只作**统计与机制归因**，**不判失败**（承 prob03 `C7`/`C8`）。
- **K3（参数方向，OAT 端点不反转）**：`η↑` 不增费；`α_em↑` 不降费；`P_max↑`（`c/q_dis` 上限同步）不增费；
  `E_min↑`（收紧）不降费；`E_max↑`（放松）不增费；`β_def/β_over↑`（仅 `4-3`）不降费；`κ_m` 截断界放宽不降费（仅 `4-3`）。
  相对容差 `1e-6`；**违反则按 `T7-4` 如实登记反例，禁止强凑单调性**。
- **K4（输入噪声）**：5 族噪声（逐时段白噪声 σ=5%/10%、按日持续 σ=5%、按日持续含电价 σ=5%、**仅 `4-3` 的预报噪声**）
  下交付期 `C_total` 的 95% 置信区间半宽 ≤ 5%，且族间均值差 ≤ 3%。
- **K5（求解器与实现）**：`highs-ds`/`highs-ipm`/`presolve=False` 三种设置下两链仍可行、恒等式在容差内；
  链级费用差异**如实登记**为「LP 最优面选择 + 跨日初值传播」的口径敏感性（与 `T7-6` 同机制），相对量级 ≤ 1%。
- **K6（结构情景，分链）**：`buy_cap` 扫掠**分链**给出决策层可行/不可行分界（或无分界）；`terminal_e_6000` 情景的差额如实登记为结构性发现（`AS03`），
  **不判为实现缺陷**；静置损耗情景按 §0 的适用性决定**不做**并显式登记。
- **K7（价格预报误差是主口径的第一不确定性源，`A8-(b)` 核心）**：预测机制族（`PF-DUAL`/`PF-HIST`）与价格类输入扰动
  （水平 ±10%、白噪声 5%/10%）引起的 `|ΔC_total^{act}|(D_req)` **量级不低于**设备参数族（`η`、`E` 界、`P_max`）的对应量级；
  预期方向：价格类扰动 ⇒ `ΔC_total` 与 `ΔC_price` 同向且 `ΔC_price` 的**分项符号按实测报告**（承 `P3`：**不得预先断言为正**）。
- **K8（两链一致性与敏感度排序）**：同一扰动下两链的 `ΔC_total` **同号**（方向一致）；且 `4-3` 的
  `|ΔC_total|/C_baseline` **不低于** `4-2`（`4-3` 多出偏差结算与紧急购电两个放大器）；
  若出现反例，按 `T7-4` 登记并给出机制解释（可能是 `4-3` 的 `κ_m` 与 `q_em` 补偿）。

## 3. 预注册稳定性判据 S1–S7（跑数前冻结，事后不得修改）

> **受判子集**：`{baseline, param, solver, noise}`（结构族由 S6 判定、预测机制族由 S7 判定，**不计入** S1/S4 的可行率与 CI，承 prob03 同级纪律）。
> **容差来源**：沿用 accepted 代码的 `TOL = LAYER_TOL = 1e-6`、`LAYER_TOL_RELATIVE = 1e-8`、`BALANCE_TOL = 1e-8`、`T7_INVARIANCE_TOL = 1e-9`。

| 判据 | 内容（阈值） | 失败后果 |
|---|---|---|
| **S1** | 受判样本**可行率 = 100%**：每层 LP `status=0`、层等式/不等式残差 ≤ `1e-6`（相对 ≤ `1e-8`）、变量界越界 ≤ `1e-6`、结算平衡/状态转移/跨日连续残差 ≤ `1e-6`、费用分解残差 ≤ `1e-6`。失败样本**保留并计入可行率**。 | 硬失败 → 稳定性分级「脆弱」，必须缩小适用范围或回退口径 |
| **S2** | 受判样本全部满足 `4-2` 的 `max\|Σq_em\| ≤ 1e-9` kWh 且 `days_with_emergency = 0`；`4-3` 的 `Σq_em > 0` 且落在基准的 `[0.25×, 4×]` **机制完好带**内（窄带 `[0.5×, 2×]` 的越界**逐样本披露**但**不判失败**，见 `CF-10`）；两链的 `q_em&c` 与同充放只作统计，不设 0 阈值 | `4-2` 出现 `q_em > 0` ⇒ 先按「信息集越界或平衡式写错」排查（`AS16`）；`4-3` 超出宽带须给机制解释，否则该对照作废并降级 |
| **S3** | K3 的七组单调方向在 OAT 端点对上**不反转**（相对容差 `1e-6`） | 记录反转对并降级；不得为凑单调调整 `ε`、tie-break 或求解器设置（`T7-4` 纪律） |
| **S4** | 每个噪声族 `n ≥ 25`、交付期 `C_total` 的**相对标准差 ≤ 5%**、**95% CI 半宽 ≤ 5%**、`max\|z\| ≤ 4`、**无失败样本**；**每族均值相对基线 ≤ 5%**；**同一 σ 档内**族间均值差 ≤ 3%（跨 σ 档的族间差只**披露**，见 `CF-10`） | 超阈值即登记该族为「不稳健」，分级降级；不得删除不利样本 |
| **S5** | 三种求解器设置**全部可行**且残差合格；链级费用最大相对差 **≤ 1%**（`> 1e-3` 时登记 warning 并与 `T7-6` 的 `1e-4` 口径敏感性对照） | 任一设置不可行或 > 1% → 判脆弱并建议回退默认设置 |
| **S6** | `buy_cap` 全档均产出状态（可行或不可行）并给出**分链**分界（或「全域可行/不可行」结论）；`terminal_e_6000` 产出数值；与 prob02/prob03 的阈值不重叠时**只登记冲突点** | 缺项 → 判未完成并降级；**不得**引用 prob02/prob03 的阈值 |
| **S7** | 预测机制族（`PF-DUAL`/`PF-HIST`）各自跑通并给出 `ΔC_total^{act}`；预测器回测**同时**给出 `MAE`/`MAPE`/`RMSE`/`bias`/`P50`/`P90`/`P99`（`E-F5`）；`ΔC_price` 的分项与符号按实测报告 | 缺任一指标 → 判未完成；据单一指标宣称「更优」→ 该结论作废并降级 |

**分级规则（预注册）**：S1–S7 全 PASS → **稳定**；恰有 1 项非 PASS 且 S1 PASS → **条件稳定（需给出适用边界）**；
S1 非 PASS 或 ≥ 2 项非 PASS → **脆弱（须缩小适用范围或回退）**；样本/计算不足（预算耗尽）→ **未决**。
