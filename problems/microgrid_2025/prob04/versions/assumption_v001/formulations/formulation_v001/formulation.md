### 1.3 价格预测器（公式级；AS08 / AS11）

#### 1.3.1 主口径与强制基准的精确公式

```
(PF-PERSIST)  主口径： \hat p_{d,i} = p^{act}_{d−1,i}，i = 1..144
              d = 2025-01-01 无前一日 ⇒ 该日不参与回测（D_full 计数 364 天；其决策价按 §1.3.4 的回退规则）
(PF-HIST)     基准： \hat p_{d,i} = \bar p^{(H_d)}_i := (1/|H_d|) Σ_{d'∈H_d} p^{act}_{d',i}
(PF-DUAL)     基准（水平 × 时段双因子）：
              \bar p^{(H_d)}_i 同上；形状 s_i := \bar p^{(H_d)}_i / mean_i(\bar p^{(H_d)})（归一化使 mean_i(s_i) = 1）
              μ_d := mean_{d' ∈ L_d} ( mean_i( p^{act}_{d',i} ) )，L_d = H_d 中**最近 7 个可用日**
              \hat p_{d,i} = μ_d · s_i
(PF-AR)       ablation 强制对照（不参与主口径选择）：逐时段 AR(1) 或惩罚回归，
              以 \hat p_{d,i} = a_i + φ_i·p^{act}_{d−1,i}（系数只用 H_d 估计）为最小实现；
              若采用带外生变量的变体（季节/时段哑变量）须在 ablation 报告逐项披露
```

- **两链共用**：`4-2` 与 `4-3` 的计划层都用 `PF-PERSIST`（`A8-(b)` 派生 ⑥ / AS13）；`4-3` 的调整层在 `PF-PERSIST` 基础上按 §1.3.3 做水平校正。**禁止**一条链用 `PF-DUAL`、另一条用 `PF-PERSIST`。

## 2. 链 `4-2` 的数学模型（≙ 在波动电价下重算**问题 2**）

### 2.1 建模对象、决策节奏与信息结构

- **建模对象**：`4-2` 链在 `D_full`（365 天）× 144 个 10 分钟时段上的**购电与储能充放电计划**，节奏为**每天 0:00 制定一次当天计划、当天不再调整**（题面问题 2 的「当天购电策略」）。
- **价格可观测性口径（AS07，`A8-(b)`）**：d 日 0:00 时 **d 日 144 点实时电价未知**，只能用 `H_d = {d' < d}` 的实际价构造的预测价 `\hat p_{d,·}`（§1.3）；d 日实际价只在**事后结算**时进入计价。
- **负载/光伏信息集（D3-A）**：问题 2 无预报机制 ⇒ 计划层使用附件 2 的**实际**负载与光伏（`L_{d,·}`、`PV^{act}_{d,·}`）。
- **模型类别**：确定性**逐日向前递推 LP** + 事后线性闭式结算；跨日由 `E` 连续衔接（AS10 / P4-D1）。
- **交付**：`result4-2.xlsx`（三工作表）与表 1/表 2/表 3（分链口径见 §8.3）。

### 2.2 逐日计划层 `(PL2_d)`

对每个 `d ∈ D_full` 顺序求解（`\hat p = \hat p_{d,·}`，`PV = PV^{act}_{d,·}`，`L = L_{d,·}`）：

```
(PL2-0) min_{b, c, q_dis, s, E, q_em}  Σ_{i=1..144} \hat p_{d,i}·b_{d,i}
                                     + Σ_{i=1..144} α_em · \hat p_{d,i} · q_em_{d,i}
(PL2-1) b_{d,i} + q_em_{d,i} + PV^{act}_{d,i}·Δt + q_dis_{d,i}
            = L_{d,i}·Δt + c_{d,i} + s_{d,i}                                    ∀ i = 1..144
(PL2-2) 0 ≤ c_{d,i} ≤ 833.3333 ；0 ≤ q_dis_{d,i} ≤ 750.0000 ；q_em_{d,i} ≥ 0
        （口径丙：并网点侧与电池侧功率同时 ≤ 5000 kW，取更严者，见 (R0b)/§3.2 (PL-2)）
(PL2-3) 0 ≤ s_{d,i} ≤ max(0, PV^{act}_{d,i}·Δt − L_{d,i}·Δt)                  ∀ i（AS05 / D9-B）
(PL2-4) E_{d,i} = E_{d,i−1} + 0.9·c_{d,i} − q_dis_{d,i}/0.9                    ∀ i（不计静置损耗，AS23）
        1200 ≤ E_{d,i} ≤ 10800                                                 ∀ i
(PL2-5) E_{d,0} = E_{d−1,144}（前一日**已提交**末态）；E_{1/1,0} = E_init = 6000 ；
        E_{12/31,144} 自由（无终端约束）
(PL2-6) b_{d,i} ≥ 0（**无上界**，AS06）
(PL2-7) q_em **仅补负载缺口、不得用于储能充电**：q_em 与 c 在同层不同时为正（结构性要求，见 L2′）
```

- **变量保留纪律（AS15）**：`q_em` 与 `α_em·\hat p·q_em` 项**必须保留**，不得因预期恒零而删除（题面要求给出紧急购电结果）。
- **提交**：第 `d` 日提交全天 144 时段的 `(b_{d,i}, c_{d,i}, q_dis_{d,i}, s_{d,i})`；`E` 轨迹随之确定并被下一日继承。
- **与 prob02 的差异（P4-D1，必须披露）**：prob02 的 `D8-A` 为「单一长时域 LP + 价格完全已知」；在 `A8-(b)` 下**不可用**（那需要全年价格信息）。本模型把它替换为逐日递推 + 预测价，**只有状态连续性**（(PL2-5)）保留「长时域」性质。

### 2.3 实际结算层 `(ST2_d)` 与 `q_em ≡ 0` 的定理

结算层给定已提交的 `(b, c, q_dis)` 与附件 2 实际值，令 `q := b`（`4-2` 无调整机制，F-3），则 `q_em ≥ 0`、`s' ∈ [0, PV^{act}·Δt]` 满足

```
(ST2-1) q_{d,i} + q_em_{d,i} + PV^{act}_{d,i}·Δt + q_dis_{d,i}
            = L_{d,i}·Δt + c_{d,i} + s'_{d,i}                                  ∀ i
(ST2-2) q_em_{d,i} ≥ 0 ；0 ≤ s'_{d,i} ≤ PV^{act}_{d,i}·Δt
(ST2-3) 闭式解：记 r_{d,i} := q_{d,i} + q_dis_{d,i} + PV^{act}_{d,i}·Δt − L_{d,i}·Δt − c_{d,i}
        s'_{d,i} = max(0, r_{d,i}) ；q_em_{d,i} = max(0, −r_{d,i})
```

**定理 `4-2-q_em`（⇒ AS16 的分链结论）**：`(PL2_0)` 的**任一最优解**满足 `q_em ≡ 0`，从而结算层 `q_em ≡ 0`、`s' = s`。

*证明*：
1. 设最优解处某时段 `q_em_{d,i} = δ > 0`。构造 `b'_{d,i} = b_{d,i} + δ`、`q_em'_{d,i} = 0`，其余不变。`(PL2-1)` 不变（`b + q_em` 之和不变），(PL2-6) 因 `b` 无上界而仍可行，目标变化 `Δ = \hat p_{d,i}·δ − α_em·\hat p_{d,i}·δ = (1 − 5)·\hat p_{d,i}·δ < 0`（价格非负且 `δ > 0`），与原解最优矛盾（严格改进）。∎
2. 故在最优解处 `(PL2-1)` 以 `q_em = 0` 精确闭合：`b + PV^{act}Δt + q_dis = LΔt + c + s`。由 `(ST2-3)` 的定义与 `q = b` 得 `r = s ≥ 0`（(PL2-3)），故 `q_em = max(0, −r) = 0`、`s' = s`。∎

- **推论（重要）**：`4-2` 的价格不确定性**不产生能量缺口**，其全部后果落在**费用**（即 §2.4 的 `ΔC_price`）。表 3 / `紧急购电量` 工作表在 `4-2` 中**预期全零**，但论文必须给出**机制说明**（不是只报空表）；若实现出现 `q_em > 0`，先怀疑**信息集越界或平衡式写错**（AS16 失效条件）。
- **可行性自动成立**：`(ST2-3)` 的 `s' ≤ PV^{act}·Δt` 由 `(PL2-1)` 与 `(PL2-3)` 直接给出（§5-L4）；供电可靠性（题面 H1）由 `q + q_em + PV^{act}Δt + q_dis − s' = LΔt + c ≥ LΔt` 自动蕴含。

### 2.4 目标、费用分解与「价格预报误差的代价」

**结算口径（主口径，真实支出；一律用附件 4 实际价）**

```
(FC2-1) C_plan^{act} = Σ_{d∈W} Σ_{i} p^{act}_{d,i} · b_{d,i}
(FC2-2) C_em^{act}   = Σ_{d∈W} Σ_{i} α_em · p^{act}_{d,i} · q_em_{d,i}   （= 0，由 §2.3 定理）
(FC2-3) C_total^{act}(4-2) = C_plan^{act} + C_em^{act}                    （**4-2 无 C_adj**）
        W ∈ { D_req（交付期，主报告）, D_full（全期，诊断） }，两窗口**必须分别给出**
```

**决策层信念口径（对照，用于误差代价）**

```
(FC2-4) C_plan^{fc} = Σ_{d,i} \hat p_{d,i} · b_{d,i} ； C_em^{fc} = Σ_{d,i} α_em · \hat p_{d,i} · q_em_{d,i} = 0
(FC2-5) C_total^{fc}(4-2) = C_plan^{fc} + C_em^{fc}
(FC2-6) ΔC_price(4-2) := C_total^{act} − C_total^{fc}
        = Σ_{d,i} ( p^{act}_{d,i} − \hat p_{d,i} ) · b_{d,i}      （分项：ΔC_plan = 同式；ΔC_em = 0）
```

- **纪律（AS09）**：两套口径必须使用**同一组决策量**（只换计价价格，**不重解**模型）；若重解，则它不再是「价格预报误差的代价」而是「方案对比」，必须改名并与 `ΔC_foresight` 分开命名（D5-B）。
- `ΔC_price` 的**符号不可预先断言**：预测误差可能在某些时段「侥幸」有利（见 §5-P3），论文须按实测给出并按分项归因，**不得**预设 `ΔC_price ≥ 0`。

### 2.5 完整模型 `M4-2`（可执行伪码）

```
M4-2:
  E_real ← E_init = 6000
  for d in D_full (2025-01-01 … 2025-12-31):
      # (0) 预测价：只用 H_d（§1.3.4 的回退规则处理 H_d = ∅ 的 1 月 1 日）
      \hat p_{d,·} ← PF-PERSIST(d, H_d)                     # 唯一的决策价来源
      # (1) 当日计划层 LP（用附件 2 实际负载/光伏）

        → b_{d,·}, c_{d,·}, q_dis_{d,·}, s_{d,·}, E_{d,·}, q_em_{d,·}（= 0）
      # (2) 事后结算（附件 4 实际价 + 附件 2 实际值；闭式 (ST2-3)，无需再解 LP）
      r_{d,i} ← b_{d,i} + q_dis_{d,i} + PV^act_{d,i}·Δt − L_{d,i}·Δt − c_{d,i}

      # (3) 状态传递
      E_real ← E_{d,144}
  # (4) 两套计价口径（同一组决策量）
  C_plan^{act}, C_em^{act}, C_total^{act} ← (FC2-1)…(FC2-3)
  C_plan^{fc},  C_em^{fc},  C_total^{fc}  ← (FC2-4)…(FC2-5)
  ΔC_price ← (FC2-6)
  # (5) 报告：D_req 与 D_full 两窗口分别汇总；落盘逐日日志、恒等式残差、输入指纹
```

- **信息集审计要点（sanity L1）**：计划层的输入指纹中**不得**出现任何 `d' ≥ d` 的价格；`4-2` 的结算层是 `p^{act}` 与 `PV^{act}` 的**唯一**入口。
- **求解器调用次数**：`|D_req| = 334`（交付期）/`|D_full| = 365`（全期）次单日 LP + 闭式结算，无 MILP、无 Big-M、无整数间隙（CPU HiGHS）。
- **tie-break**：每个单日 LP 使用 AS21 的字典序——先 `min (PL2-0)`，再在其最优面上 `min Σ_i (c_{d,i} + q_dis_{d,i})`。

### 2.6 `4-2` 的结构恒等式与量级界

```
(I2-1d) Σ_i q_dis_{d,i} = 0.81·Σ_i c_{d,i} − 0.9·( E_{d,144} − E_{d,0} )          （状态转移求和，AS23）
(I2-2d) Σ_i b_{d,i} = N_d + Σ_i s'_{d,i} + 0.19·Σ_i c_{d,i}
                       + 0.9·( E_{d,144} − E_{d,0} ) − Σ_i q_em_{d,i} ，  N_d := Σ_i ( L_{d,i} − PV^{act}_{d,i} )·Δt
(I2-3d) C_total,d = C_plan,d + C_em,d ＝ C_plan,d（q_em ≡ 0）
(I2-4d) 跨日状态闭合： |E_{d,0} − E_{d−1,144}| ≤ 1e-6 ； E_{1/1,0} = 6000
```

### 3.1 建模对象、决策时点与信息结构

- **建模对象**：`4-3` 链在 `D_full` × 144 时段上的**三层顺序向前递推**购电策略：计划层（0:00）→ 调整层（6:00/12:00/18:00）→ 实际结算层（事后闭式）。


- **为何只提交 `D_m`**：`R_m` 的尾部（`i > 6(m+1)`）是**前视**（roll-horizon look-ahead），用于避免段末近视；后继层会重优化，**不进入交付**。

### 3.4 实际结算层 `(ST_d)`（事后闭式）

- **唯一性与可行性**：与 prob03 `L2`/`L3` 同构（§5-L3/L4）；`q_em` 由「支配层预报 vs 实际光伏」的缺口产生（承 prob03 `F2`/`F3`），**价格误差不改变该机制**（只改变费用）。

### 4.2 自建锚点：完全预知下界（`A2-PRE`，D12-A）

```
(A2-PRE) min_{b,c,q_dis,s,E}  Σ_{d∈W} Σ_i p^{act}_{d,i} · b_{d,i}
         s.t.  （PL2-1 去掉 q_em）+（PL2-2）–（PL2-6），PV 用附件 2 实际，价格用 p^{act}
```

- **性质（定理，§5-L6）**：任一 `4-2` 逐日递推策略的决策向量都满足 `(A2-PRE)` 的全部约束（逐时段平衡、设备界、状态转移与跨日连续），故 `(A2-PRE)` 的最优值是 `C^{act}(4-2)` 的**成本下界**：`C^{act}(4-2) ≥ C^{pre}`。
- **用途**：① 作为**实现正确性锚点**（若 `C^{act} < C^{pre} − 1e-6` 相对量级，判实现错误，**不是**机制发现）；② `ablation` 的「价格信息价值」上界；③ 与 `ΔC_foresight = C^{act} − C^{pre}` 一起报告（D5-B，命名与 `ΔC_price` 分开）。
- **注意（`E-F1`）**：本条锚点是**下界**，不是 `assumptions.md` D12 原文所称的「上界锚点」；本文件按成本下界执行。

### 4.3 差额的三分项归因（P4-D5 / D11-A）

```
(AT-1) 桥接口径 `BRIDGE`：把 `4-3` 退化为「无价格误差 + 无光伏误差 + 无偏差惩罚」：
       Π_m[PV] ≡ PV^{act}（∀ m ∈ {0,6,12,18}）、κ_m ≡ 1、
       β_def = β_over = 1（偏差项中性）、结算价 = 决策价
       此时 4-3 与 4-2 逐位同构（§5-P2）
(AT-2) 三项归因（全部按 `D_req` 与 `D_full` 两窗口分别给出）：
       Δ1（价格预报误差的代价） = ΔC_price（§2.4/§3.5），两链分别报告
       Δ2（光伏预报误差的代价） = [4-3 在 κ_m ≡ 1 且 β = 1 时的 C_total]
                                  − [4-3 在 Π_m ≡ PV^act 且 κ_m ≡ 1 且 β = 1 时的 C_total]
       Δ3（偏差结算制度）       = C_total^{act}(4-3)
                                  − [4-3 在 κ_m ≡ 1 且 Π_m ≡ PV^act 且 β = 1 时的 C_total]
       恒等式： C_total(4-3) − C_total(4-2) = Δ1' + Δ2 + Δ3 （Δ1' 为两链价格误差代价之差，
                由 (AT-2) 的三个对照 C_total 与两链的 `C^{fc}` 残差配平；实现必须给出残差 ≤ 1e-6）
(AT-3) 归因数值只能来自 `ablation` 阶段的隔离 task；本文件只固定**定义与配平恒等式**
```

- **禁止**：只报 `C_total(4-3) − C_total(4-2)` 的总差而不做分项（prob03 `R11`/`E8` 的披露纪律）。

## 5. 引理与命题（解析依据）

### L1（决策层 `q_em` 恒不激活；仅 `4-3`）

在 `4-3` 的任一决策层（计划层不含 `q_em`；调整层若把 `q_em` 加入余额），最优解取 `q_em ≡ 0`：`α_em = 5 > β_over = 1.5`，把 `δ > 0` 的 `q_em` 换成等量 `q` 的净目标变化 `≤ −3.5·\hat p·δ < 0`。∎
**推论**：`4-3` 的 `q_em` 只能由**结算层**的预报缺口产生（§3.4），表 3 非零**不是**「购电上限激活」机制（勿与 prob02 `R5` 混淆）。

### L2（`4-2` 的 `q_em ≡ 0`；定理，§2.3）

见 §2.3 的两步证明。**与 prob02 `A17` 的关系（P4-D3）**：结论相同但**前提不同**——prob02 `A17` 的依据是「完全信息 + 无上限」；本问的依据是「计划层使用附件 2 实际（物理信息完全）+ 等式平衡 + `s ≥ 0` 自由处置」，**与价格是否已知无关**。故这是**分链重述 + 新证明**，不是移植。

### L3（结算层唯一确定；两链共用）

给定已提交的 `(q, c, q_dis)` 与实际值，`(ST-1)+(ST-2)` 的解唯一，即 `(ST-3)`：由 `(ST-1)` 得 `s' − q^em = r`（常数），`s', q^em ≥ 0` 且 `s' ≤ PV^{act}·Δt`（L4）；若 `r ≥ 0` 则 `q^em = 0, s' = r`，若 `r < 0` 则 `s' = 0, q^em = −r`。∎

### L4（结算层弃光上界与可行性自动成立；两链共用）

由层内余额与 `s^{[层]} ≤ max(0, PV^{层}·Δt − L·Δt)` 得 `q + q_dis − c ≤ L·Δt`，故 `r ≤ PV^{act}·Δt`，即 `s' ≤ PV^{act}·Δt` 无需额外约束；`(ST-1)` 的右端只含已提交量与参数，故结算层**总是可行**。∎

### L5（分段线性化的 LP 无损性；仅 `4-3`）

`(AD-3)` 对 `u^+, u^−` 的系数均为正（`β_def, β_over > 0`），约束为 `u^+ ≥ b−q`、`u^− ≥ q−b`，故在**任一最优解**处取紧且 `u^+·u^− = 0`；加入二元变量的 MILP 与原 LP **最优值相同**。∎（§9-B4 在小实例上实测 `LP − MILP = 0.0`）

### L6（完全预知下界；两链各自成立）

- `4-2`：任一逐日递推策略的决策向量满足 `(A2-PRE)` 的全部约束（`q_em = 0` 由 L2；其余约束逐项相同），故 `C^{act}(4-2) ≥ C^{pre}(4-2)`。∎
- `4-3`：任一三层策略的决策向量满足「价格完全预知 + 光伏完全信息」的单一长时域 LP（去偏差项或取 `β = 1`）的全部约束，故 `C^{act}(4-3) ≥ C^{pre}(4-3)`。∎
  （证明用**可行域包含**，不依赖层次目标的可合并性——层次结构使联合 LP **不等价**，但联合 LP 的可行域仍包含逐层策略的解。）

### L7（可行性完成引理：各层必可行；两链）

对任意已提交状态 `E ∈ [1200, 10800]` 与任一价格/预报曲线：取 `c = q_dis = 0`、`s = max(0, PV^{层}·Δt − L·Δt)`、`q = max(0, L·Δt − PV^{层}·Δt)`（`4-2` 用 `b`），则余额成立且各界满足；`q`（`b`）无上界保证 `E` 偏低时仍可行。∎
**含义**：若实测出现不可行，应判**实现错误**而非模型不可行。

### P1（信息集单调方向，弱命题）

预期 `C^{pre} ≤ C^{act} ≤ C^{UB-constructive}`，且（`4-3`）`C^{pre}(4-3) ≤ C^{act}(4-3) ≤ C^{act}(M4)`（`M4` = 仅 0:00 计划、无调整，§6.1 候选 D）。**不强称定理**：`M4` 的策略集不是 `4-3` 主口径策略集的子集（层次目标与偏差付款不同），方向须数值验证；若反转，须给机制解释并登记，否则该对照作废。

### P2（退化同构命题，两链桥接的核心）

在 `Π_m[PV] ≡ PV^{act}`（∀ m）且 `κ_m ≡ 1`（即 `\hat p^{(m)} ≡ p^{act}_{d−1}`）下：

1. `4-2` 的计划层问题与 `4-3` 的计划层问题是**同一个优化问题**（目标同为 `min Σ \hat p·b`；平衡式在 `q_em ≡ 0`（L2）下逐项相同；`s` 界同为物理盈余界；跨日与设备约束相同）⇒ 同一 tie-break 下 `b` 逐位相同；
2. 每个调整层 `(AD_{d,m})` 的主目标最小值为 **0**（取 `q = b`、`c = c^{PL}`、`q_dis = q_dis^{PL}` 复现计划轨迹即得 0，且目标非负）⇒ 调整层不会改变 `q`（除非 tie-break 重选轨迹）；
3. 结算层 `(ST-3)` 相同 ⇒ `q^em = 0`、`s' = s`，且 `C_total^{act}(4-3) = C_total^{act}(4-2)`（同一 `b`，`C_adj = C_em = 0`）。

**限定**：`c`/`q_dis` 的**逐点轨迹**可因 LP 退化而不同（调整层的次要目标只覆盖 `R_m`）；若要逐位比较轨迹，必须先按 AS21 统一 tie-break 并声明比较口径。**该命题是结构检查，不是两链数值应相等的理由**（含预报误差与偏差结算时两链必然不同）。
**本动作只读探针（§9-B2）**：小实例上 `b` 与 `q` 逐位相同、`C_total` 差 `0.0`、`q_em` 全零。

### P3（`ΔC_price` 的符号）

**不可预先断言** `ΔC_price ≥ 0`：`ΔC_price = Σ(p^{act} − \hat p)·b`，若预测价在**购电量大的时段**系统性偏高，则该项可为负。论文必须按实测报告其符号与分项，并说明「预测误差的代价」在**期望意义**上非负、在**单次实现**上可正可负。**不得**为凑「代价为正」而改口径。

### P4（`Σq^em` 在 `4-3` 非零）

结算层用实际光伏、决策层用预报 ⇒ 存在 `r < 0` 的时段 ⇒ `Σq^em > 0`。若实测恒零，先查「`Π_m` 被写成 `PV^act`」或「附件 3 未被消费」。**不强称**具体量级。

## 6. 候选建模/求解方案、预注册比较标准与推荐

> 全部利弊与规模在**看到计算结果前**固定（`agents/mathematical-formulator.md` 第 3 条）。两链各自给出候选族。

### 6.1 候选方案（≥3，覆盖精确/启发式/混合）

#### 候选 A：逐日/逐层顺序向前递推 LP（`M4-2` / `M4-3`；精确，**推荐主路径**）

- **核心思想**：§2.5 与 §3.6 的伪码；`4-2` 每天 1 次 LP、`4-3` 每天 4 次 LP；结算层闭式；CPU HiGHS。
- **规模量级**：`4-2` 单日 LP `6 × 144 = 864` 变量 / `288` 等式（含 tie-break 二次求解则 ×2）；`4-3` 单日 `2,232` 变量 / `720` 等式（其中 `q_em` 不出现于决策层，实际略小）；全年 `4-2` `365`（或 `334`）次、`4-3` `1,460`（或 `1,336`）次小 LP。
- **优点**：**唯一同时满足** `A8-(b)` 信息集、题面决策节奏、不回溯与因果性的路线；线性、无 Big-M、无整数间隙；各层可独立审计；对偶界可直接给出。
- **缺点**：层次目标无法合并为单次 LP（承 prob03 `F1`）；实现须显式管理「已提交链」与层间状态传递；滚动近视可能使加密对照非单调（承 prob03 `F4`）。
- **失效条件**：若团队改「决策价 = 当天实际价」（即 `A8-(a)`，已被否）或允许联合求解，本路线的前提失效，须重裁并新建假设版本。
- **适用性**：两链**完全适用**。

#### 候选 B：逐日解耦 + 跨日状态递推（`M4-2b`；精确分解口径）

- **核心思想**：把 `M4-2`/`M4-3` 的「单日/单层」封装为独立函数，`E_{d,0}` 由前一日提交链末态传入。
- **规模量级**：与候选 A 完全相同。
- **优点**：边界清晰、单日可独立调试（本机 `memory_slots = 1`，不得并行以求公平）。
- **缺点**：与候选 A **算法同构**，不是独立实现。
- **失效条件**：与候选 A 同。
- **适用性**：作 `M4-2`/`M4-3` 的**自洽检查**适用；**不得**充当「分解等价性」的独立证据。

#### 候选 C：偏差项互补 MILP 精确化（`M6`；精确 oracle，仅 `4-3`）

- **核心思想**：对 `i ∈ R_m` 引入 `z^+_{d,i}, z^−_{d,i} ∈ {0,1}`，`u^+ ≤ b^{max}·z^+`、`u^− ≤ q^{max}·z^−`、`z^+ + z^− ≤ 1`，其余同 `(AD)`；Big-M **由模型推导**。
- **规模量级**：单日追加 `2 × 144 = 288` 二元（按 `R_m` 计 `2×(108+72+36) = 432`）；只对指定日/少量日做 oracle，**全年 MILP 不可行**。
- **优点**：把 L5 从引理变成硬约束；可作 LP 的独立数值复核。
- **缺点**：全年不可证最优；只作 oracle。
- **失效条件**：Big-M 取大（如 `1e6`）会削弱松弛；设备界变更而未同步 Big-M 会误删可行解。
- **适用性**：作验证 oracle 适用；**不作**主计算路径。

#### 候选 D：完全预知 / 无调整的退化对照族（`M3-ter`、`M4-ter`、`A2-PRE`；精确，仅 `ablation`/`sanity`）

- **核心思想**：`4-2` 的 `A2-PRE`（价格完全预知）；`4-3` 的 `M3`（价格 + 光伏完全预知）与 `M4`（仅 0:00 计划、`q ≡ b`、无调整）。
- **规模量级**：`4-2` 的 `A2-PRE` 可堆叠为单一长时域 LP（`52,560` 时段量级，承 prob02 实测 26.8 s / 113 MB）；`4-3` 的 `M3`/`M4` 与候选 A 同量级。
- **优点**：给出信息价值上界与调整机制价值；`A2-PRE` 同时是 `4-2` 的实现锚点（§4.2）。
- **缺点**：只作对照，不进入主结果（`A8-(b)` 派生 ④）。
- **失效条件**：把 `M3` 的数值写进主表或结论 ⇒ 违反 `B0`。
- **适用性**：**仅 `ablation`/`sanity`**。

#### 候选 E：价格阈值规则式启发式（仅对照）

- **核心思想**：按价格分位划低价/高价段，低价充电、高价放电；调整层按「缺口即补、盈余即弃」生成 `q`。
- **规模量级**：无优化变量，`O(T log T)`，毫秒级。
- **优点**：不依赖求解器、可复现、给出 regret 参考。
- **缺点**：无最优性保证；对阈值/效率敏感；无法表达 `min Σp·b` 的层次结构。
- **失效条件**：附件 4 为实时波动价（非 TOU 型）⇒ regret 显著放大。
- **适用性**：作降级/对照基线；**不得**作为交付口径。

#### 候选 F：时间聚合—降尺度启发式（仅对照）

- **核心思想**：把 144 时段聚合为 24 整点或 6 个 4 小时块求解，再恢复 10 分钟决策并做可行性修复。
- **规模量级**：聚合模型变量降低 6–24 倍。
- **优点**：快、省内存、可直接对照表 2 的 4 小时块口径。
- **缺点**：无最优性保证；组内净负荷符号翻转时修复易破坏 SOC 轨迹。
- **失效条件**：附件 4 的价格日内极差均值 `1.1073` 元/kWh（探针），组内翻转常见 ⇒ 修复失败概率高。
- **适用性**：作降级/对照；**不作**交付口径。

#### 候选 G：两阶段随机 / 鲁棒 / 滚动 MPC（混合；**仅 `ablation`**）

- **核心思想**：按团队预注册的 `S-VAR`（两阶段随机 LP、24 个由历史实际价构造的经验场景）与 `S-RH`（滚动时域/前瞻深度对照）实现；鲁棒优化用价格区间的最坏情况。
- **规模量级**：`S-VAR` = 代表日（12 个）× 24 场景的确定性等价大 LP（第二阶段线性 ⇒ 与 Benders/L-shaped 同解，按团队口径**不实现** Benders）；`S-RH` 与候选 A 同量级 × 前瞻深度。
- **优点**：量化价格不确定性的价值与尾部风险；响应团队预注册要求。
- **缺点**：需要场景/区间构造口径；主口径**不得**使用（`A8-(b)` 派生 ④）。
- **失效条件**：把场景随机或鲁棒结果写进主表/主结论；或凭空设分布（必须用附件 4 历史实际价构造经验场景）。
- **适用性**：**仅 `ablation`**；接口见 §8.8。

### 6.3 推荐与复杂度必要性结论

**推荐候选 A（`M4-2` / `M4-3`）作为两链的主路径与唯一交付口径**：

1. 本问是确定性分层线性问题，候选 A 层内给出全局最优与对偶界，符合 `knowledge/optimization.md` 的「精确优先」规则；
2. `A8-(b)` 与 AS18 明确禁止联合 LP 让决策层看到未来实际值；候选 A 是唯一同时满足信息集、T1 风格层次目标、不回溯与因果性的路线；
3. L7 保证各层**必可行**、L5 保证分段线性化**无损**，`M6` 的必要性降为「独立数值复核」；
4. 规模与预算余量充足（§8.6），复杂方法（DP、聚合、阈值启发式）不带来指标收益，只增加失效面；
5. `S-VAR`/`S-RH`/鲁棒按团队预注册**只进 `ablation`**（`A8-(b)` 派生 ④）。

**复杂方法必要性结论**：
- **MILP（`M6`）不必要但保留为 oracle**：必要性由 L5 判定（LP 无损），不由算法名称决定；
- **DP/聚合/阈值启发式不必要**：精确解成本已可接受，它们只作降级路径与对照基线；
- **随机/鲁棒不进入主口径**：由团队预注册明确置于 `ablation`；场景必须由附件 4 历史实际价构造（禁止凭空设分布）。

## 7. 局限与不适用

1. **确定性主口径（AS12）**：主口径不处理预测误差分布；尾部风险（`PF-PERSIST` 的 P99）由 `ablation` 量化，论文须披露该局限。
2. **`ΔC_price` 的单次实现可正可负（P3）**：不得把「误差代价」当作恒正的会计项。
3. **`4-2` 的 `q_em ≡ 0`**：表 3 与 `紧急购电量` 工作表预期全零，必须给机制说明 + `ablation` 的购电上限灵敏度小表；上限阈值须**按本问分链重新扫描**（R5/E9）。
4. **降尺度不保块内能量（AS19）**：必须显式披露并给出能量偏差统计。
5. **读法 A 的激励结构（AS17）**：主口径下 `q = b` 是费用最优点，调整机制的价值主要在**避免 `5×` 紧急购电**与维持可行性；读法 B/C 的差额必须全量给出。
6. **无购电上限（AS06）**：可能出现工程上不可执行的高购电尖峰，论文须说明。
7. **跨年项丢弃（AS19）**：12-31 的 6:00/12:00/18:00 层分别丢弃 6/12/18 个预报项，须说明「不消费、不截断、不外推」。
8. **LP 退化与 tie-break（AS21）**：层次目标在「可复现上一层轨迹」处多重最优；`C5` 类单调性判据必须先固定 tie-break。sanity 以**约束残差 + 恒等式 + 目标值 + 交付表**为准，**不比对逐点解的唯一性**。
9. **`PF-PERSIST` 的 1 月 1 日缺前一日**：按 (FB) 回退，该日属预热期，不影响交付期指标。
10. **不显式禁止同时充放电（AS23）**：由正的吞吐损失（`1 − 0.81 = 0.19`）在最优解处自然不取同充放；sanity 须统计同充放时段数并期望为 0。
11. **`A2-PRE` 需堆叠全年 LP（`4-2`）**：内存/时间须在 `implementation` 时按 `config/compute.yaml`（`memory_per_worker_gb = 2`）复核；若超出，可降级为「分月堆叠 + 状态衔接」并登记口径差异。
12. **两链费用不可朴素比较**：差额含三项（§4.3），必须分项归因。

### D1 `4-2` 主模型路线（对应 `A-D2` 计划时域组织 / `A-D3` 信息集）

- 备选 A：**逐日单阶段 LP + 闭式结算（`M4-2`，本版推荐）**；规模：单日 `864` 变量 / `288` 等式，全年 `365`（或 `334`）次 LP；优点：唯一同时满足题面「当天计划」、`A8-(b)` 信息集与因果性，实现最简、可审计；缺点：放弃跨日「长时域」的价格解析便利，费用高于完全预知下界；适用条件：`A8-(b)` 成立（已裁）。
- 备选 B：**滚动多日窗 MPC（如 7 天）**；规模：单次 LP ≈ `7 × 864` 变量，全年同次数但单次更大；优点：缓解段末近视，可作 `S-RH` 的对照；缺点：需「未来多日预测价」外推规则（新增待披露参数），与题面「当天计划」的字面读法有距离；适用条件：团队接受 `S-RH` 登记。
- 备选 C：**单一长时域 LP（prob02 `D8-A` 原样）**；规模：`52,560` 时段、`315,360` 变量量级；优点：与 prob02 数值口径同构（但那正是被否的理由）；缺点：需要全年价格信息 ⇒ 与 `A8-(b)` **不相容**；适用条件：**不适用**（仅作 `A2-PRE` 的完全预知对照）。
- **推荐：A**，理由：唯一同时满足题面、`A8-(b)` 与因果性的口径；B 只作 `ablation`/`robustness` 诊断；C 只作 §4.2 的下界锚点。比较标准：`C4` 信息单调（L6/P1）、信息集指纹（sanity L1）、`C8` 交付一致性。

### D2 `4-3` 主模型路线（对应 `A-D1`/`A-D6`/`A-D7`）

- 备选 A：**三层顺序向前递推 LP + 闭式结算（`M4-3`，本版推荐）**；规模：单日合计 `2,232` 变量 / `720` 等式，全年 `1,460` 次小 LP；优点：唯一同时满足 T1 风格层次目标、不回溯、实际光伏只进结算层与 `κ_m` 滚动预测；缺点：层次目标不能合并为单次 LP，须显式管理层间提交链；适用条件：`A8-(b)` + AS18。
- 备选 B：**单次联合 LP**（把四层合成一个 LP，`b` 与 `q` 同层决策）；规模：单日 `≈ 2,232` 变量一次求解；优点：求解快、变量少；缺点：**让计划层看到后验值**（违反 AS18/AS07），结论无效；适用条件：**不适用**（仅可用于 `M3-ter`/`M4-ter` 的完全信息对照）。
- 备选 C：**调整层偏差项互补 MILP 精确化（`M6`）**；规模：单日追加 `432` 二元；优点：把 `L5` 从引理变硬约束，作独立 oracle；缺点：全年不可证最优，只作指定日 oracle；适用条件：作 `ablation` oracle。
- **推荐：A**，理由：层次结构是题面「计划—调整—紧急」的自然落地，且 L5 已证明 LP 无损、L7 证明各层必可行；B 只有在「完全信息对照」语境下合法；C 保留为 oracle。比较标准：`C1` 基线、`C3`（`M8` 独立实现）、`C6`（LP 无损）、`C7`（口径对照全量落盘）。

### D3 主价格预测器的函数级实现（对应 `A-D1`）

- 备选 A：**`PF-PERSIST` 直接取前一日 144 点向量（本版推荐）**；规模：`O(144)`/日，无参数估计；优点：零超参数、口径最简、易审计；缺点：尾部较重（P90/P99 = `0.2294/0.3773`）；适用条件：按 `(BT-5)` 的预注册规则。
- 备选 B：**`PF-PERSIST` + 平滑（如 3 日同时段中位数）**；规模：`O(3×144)`/日；优点：可能降低尾部误差；缺点：引入未预注册的窗口参数，须重跑回测并按 `(BT-5)` 重新裁定；适用条件：团队替换须新建假设版本。
- 备选 C：**`PF-DUAL` 为主口径**；规模：需要形状与水平两组估计（`O(|H_d|×144)`）；优点：RMSE 与 P90/P99 更优、偏置更小；缺点：MAE 高 `10.5%`，与预注册规则冲突，且 `κ_m` 的定义须同步改写；适用条件：团队裁定替换（`A-D1` 备选 B）。
- **推荐：A**，理由：预注册规则在其自身证据下唯一指向 A；B/C 只作 `PF-ALT` 的 `ablation` 对照。比较标准：`D_req` MAE 为主、MAPE/RMSE/bias/分位数同时报；预测器选择敏感性 `ΔC_total`（>1% 须披露）。

### D4 `4-3` 调整层 `κ_m` 的估计窗口（对应 `A-D6`）

- 备选 A：**当日已实现全段 `i ≤ 6m` 的均值比 `A_m/B_m`（本版推荐，AS11 原式）**；规模：`O(6m)`/层、一个标量；优点：与 AS11 逐字一致、样本随 `m` 增大、可审计；缺点：只校正水平、不校正日内形状。
- 备选 B：**最近 `N` 段（如 `N = 6`，即最近 1 小时）的均值比**；规模：`O(N)`/层；优点：对最新价格更敏感；缺点：`m = 6` 时样本极小、噪声放大，且引入未登记参数；适用条件：团队裁定。
- 备选 C：**不更新（`κ_m ≡ 1`）**；规模：无；优点：实现最简、与主预测器完全一致；缺点：浪费当日已实现价格信息，`A8-(b)` 派生 ③ 的增量价值为 0；适用条件：作 `κ1` 的 `ablation` 对照。
- **推荐：A**，理由：AS11 已冻结，且样本量随 `m` 单调增大；C 作 `ablation` 对照。比较标准：`κ_m` 的截断触发次数（须为 0 或逐个登记）、`κ1` 的费用差、信息集一致性（`i > 6m` 不得使用当日实际价）。

### D5 tie-break 的实现方式（对应 `A-D`/AS21，承 prob03 `T7-1`/`T9`）

- 备选 A：**两阶段逐层重解（先层主目标、再 `min Σ(c + q_dis)`，本版推荐）**；规模：每层 LP 求解次数 ×2；优点：与 AS21 字面一致、可复现、与上游 prob03 口径统一；缺点：求解时间约 ×2（本问规模下可忽略）。
- 备选 B：**字面 ε 加权目标 `min (主目标 + ε·Σ(c + q_dis))`**；规模：单次求解；优点：快；缺点：`ε` 无标定依据，可能改变主目标；适用条件：**只作逐层诊断**（落盘 `t7_tiebreak.json`），不得作为提交解规则。
- 备选 C：**不固定 tie-break（取求解器默认解）**；规模：单次求解；优点：无；缺点：不可复现，跨层/跨日初值传播使链级费用漂移（prob03 实测约 `1e-4` 相对量级）；适用条件：**不适用**。
- **推荐：A**，理由：所有层、所有对照模型必须使用同一规则；`C5`/`R-TIE` 的敏感性必须在该规则下实测。比较标准：`C5` 单调性、`R-TIE` 量级、`M8` 与主模型的目标同值性。

### D6 两套计价口径的实现方式（对应 `A-D5`）

- 备选 A：**同一组决策量、只换价格向量复算（本版推荐）**；规模：`O(52,560)` 的向量点积，可忽略；优点：差额唯一归因于价格误差，可复算；缺点：`C^{fc}` 不是真实支出，须在论文标注；适用条件：团队派生 ② 的字面要求。
- 备选 B：**与「完全预知决策」对照（`ΔC_foresight = C^{act}(预测决策) − C^{pre}(完全预知)`）**；规模：多跑一个 `A2-PRE`/`M3-ter`；优点：给出信息价值的完整上界，经济含义强；缺点：属反事实对照，须与 `ΔC_price` 分开命名；适用条件：作 `ablation` 对照（与 A 并用，不互相替代）。
- 备选 C：**只报主口径 `C^{act}`**；规模：无；优点：最省；缺点：无法回答「预测误差值多少钱」，不满足团队派生 ②；适用条件：**不适用**（主表可只报 `C^{act}`，但报告必须同时给 `C^{fc}` 与 `ΔC_price`）。
- **推荐：A + B（命名分开）**，理由：A 是团队强制项、B 是文献支撑的信息价值上界；两者互补。比较标准：恒等式 `C_total^{act} = Σ分项^{act}` 残差 ≤1e-6；`ΔC_price` 的符号按实测（P3），不得预设为正。

### D7 退化同构检查的比较口径（对应 `A-D11`/`A-D12`）

- 备选 A：**在统一 tie-break 下比较 `b`/`q`/`q^em`/`C_total`（本版推荐）**；规模：需额外跑 `BRIDGE`（`Π_m ≡ PV^act`、`κ_m ≡ 1`）的一条 `4-3` 链；优点：可判定实现是否把预报误差或口径污染掺入；缺点：`c`/`q_dis` 的逐点轨迹仍可能因退化而不同，须声明比较口径；适用条件：`sanity`/`ablation` 结构检查。
- 备选 B：**比较全部逐点轨迹（含 `c`/`q_dis`/`E`）**；规模：同 A；优点：最严；缺点：LP 退化使该比较**不是**模型的必然结论，可能产生假失败（P2 限定）；适用条件：须先在两层使用**同一时域**的 tie-break，否则不适用。
- 备选 C：**不做退化对照**；规模：无；优点：省；缺点：无法发现「口径污染/预报误用」类实现错误；适用条件：**不适用**（D12-C 已否）。
- **推荐：A**，理由：`b`/`q`/`q^em`/`C_total` 是 P2 保证的量；逐点轨迹比较须额外条件。比较标准：`C_total` 相对差 ≤1e-9、`b` 逐位差 ≤1e-9、`q_em ≡ 0`。

### D8 `4-2` 实现锚点的使用方式（对应 `A-D12`）

- 备选 A：**`A2-PRE` 作硬下界门（`C^{act} ≥ C^{pre} − δ`，本版推荐）**；规模：`52,560` 时段单一 LP（须复核内存，§8.6）；优点：定理级（L6），可独立发现「量级正确但模型错」的实现错误；缺点：需额外跑一个大 LP；适用条件：`sanity`（`D_req` 窗口）。
- 备选 B：**`A2-PRE` 只作软参考（不设门）**；规模：同 A；优点：不引入失败面；缺点：失去唯一的自建锚点（prob02/prob03 数值不可用，P4-D2）；适用条件：内存不足时的降级（须登记）。
- 备选 C：**引用 prob02 的 `12,233,050.83` 元作锚点**；规模：无；优点：省事；缺点：**错误**（价格情景不同），违反 P4-D2；适用条件：**不适用**。
- **推荐：A**，理由：在无可比跨问锚点的前提下，退化下界 + 结构恒等式是本问唯一可自洽的验证路径；B 仅在内存受限时降级并登记。比较标准：`C^{act} ≥ C^{pre}`（相对容差 `1e-6`）、四条恒等式残差 ≤1e-6、量级自检。
