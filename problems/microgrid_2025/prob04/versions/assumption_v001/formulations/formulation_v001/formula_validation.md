## 6. 极限行为（V6）

1. **`κ_0 ≡ 1`**：`m = 0` 层退化为 `PF-PERSIST` ⇒ 两链计划层使用同一预测器（`A8-(b)` 派生 ⑥）。探针 C 验证 `κ_0 = 1.0`。
2. **`Π_m ≡ PV^act`（∀ m）**：`4-3` 的预报缺口消失，`q^em` 的**预报驱动**来源归零；结合 `κ_m ≡ 1` 与「`b` 已提交」得退化同构（P2/V9）。
3. **`β_def = β_over = 1`**：偏差项中性（成本 = `Σp|b−q|` 在 `q = b` 处取 0）⇒ 调整层不改变 `q`。
4. **`α_em → ∞`**：`q_em` 更加不可能激活（L1/L2 加强）；`α_em = 1` 时 `4-2` 的 `q_em` 仍不被激活（`b` 与 `q_em` 在余额中同系数、`b` 无上界 ⇒ 严格更优），故 `4-2` 的 `q_em ≡ 0` **对任意 `α_em > 1` 成立**。
5. **`η → 1`、无损耗**：`0.19Σc` 项消失，`(I2-2d)` 退化为纯净负荷账；不影响信息集结论。
6. **单日 `L ≤ PV^act`（全天盈余）**：`b = 0`、`s' = 盈余`、`C_plan = 0`；`q_em = 0`（L2）。此为下界锚点的一个特例。
7. **`d = 2025-01-01`（`H_d = ∅`）**：按 (FB) 回退，属预热期，不影响交付期指标。
8. **`m = 18` 的 `R_18 = {109..144}`**：`κ_18` 用 `i ≤ 108` 的均值比（样本量最大），是调整层中信息最充分的一层。

## 7. 数值可解性与条件（V7）

- **`L7`（可行性完成引理）**：对任意已提交状态与任一价格/预报曲线，各层 LP 必可行（构造解 `c = q_dis = 0`、`s = 余量`、`b/q = 缺额`）。⇒ 实测不可行应判**实现错误**。
- **结算层是闭式映射**（L3），无需调用求解器；`s' ≤ PV^act·Δt` 自动成立（L4）。
- **无 Big-M**：主口径不含整数变量（`M6` 的 Big-M 由模型界推导，仅 oracle）。
- **规模**：`4-2` 单日 `864` 变量 / `288` 等式；`4-3` 单日合计 `2,232` 变量 / `720` 等式；全年 `365`（`4-2`）+ `1,460`（`4-3`）次小 LP；内存需求远低于 `memory_per_worker_gb = 2`（prob03 同类结构实测数秒完成 14 天 × 6 链）。
- **数值条件**：HiGHS 默认容差；变量/约束尺度同一量级（`1e2–1e4`），无需缩放；tie-break 二次求解的容差用 `1e-9·max(1,|obj|)`。
- **`A2-PRE` 的规模风险**：单一长时域 LP（`52,560` 时段）在 prob02 实测 26.8 s / 113 MB，属可接受；若内存告警，按 §D8 备选 B 降级为「分月堆叠 + 状态衔接」并登记口径差异。

## 8. 解结构与互补性（V8）

- **`q_em ⊥ s'`**：由 `(ST-3)` 的闭式结构，同一时段至多一个为正（`r ≥ 0 ⇒ s' = r, q^em = 0`；`r < 0 ⇒ s' = 0, q^em = −r`）。探针 B1 实测 `4-2` 全时段 `q_em = 0`、`s' = s ≥ 0`。
- **`q_em` 不用于充电**：`q^em > 0` 的时段必有 `r < 0`，且 `c` 在余额中为减项 ⇒ 同层 `c` 与 `q^em` 同为正会同时恶化余额与成本；sanity 须统计「`q^em > 0` 且 `c > 0`」的时段数并期望为 0。
- **`b` 与 `q_em` 不同时为正**（`4-2`）：由 L2 的替换论证更强——最优解处 `q_em ≡ 0`。
- **不同时充放电**：不显式禁止（AS23）；由正的吞吐损失 `1 − η² = 0.19` 在最优解处自然不取；sanity 统计并期望为 0。
- **LP 多重最优**：层次目标在「复现上一层轨迹」处多重最优（AS21/D5）；故 sanity 以**约束残差 + 恒等式 + 目标值 + 交付表**为准，**不比对逐点解的唯一性**（承 prob01/02/03 纪律）。

## 9. 退化/等价条件的验证（V9）+ 两条链的桥接

**命题 P2（`4-3` → `4-2` 退化）**：在 `Π_m[PV] ≡ PV^act`（∀ m）且 `κ_m ≡ 1` 下：
① 两链计划层是同一优化问题（`q_em ≡ 0` 使平衡式逐项相同）⇒ 同一 tie-break 下 `b` 逐位相同；
② 各调整层主目标最小值为 0（取 `q = b` 复现计划轨迹）⇒ `q ≡ b`；
③ 结算层相同 ⇒ `q^em = 0`、`s' = s`、`C_total` 相同。

**探针 B2（`T = 4`、2 层小实例，统一 AS21 tie-break）实测**：

| 检查 | 值 |
|---|---|
| `b` 逐位相同 | `True`（`max_abs_diff = 0.0`） |
| `q ≡ b`（`4-3`） | `True` |
| `c` / `q_dis` 逐位相同（统一 tie-break 下） | `True` / `True` |
| `C_total(4-3) − C_total(4-2)` | `0.0` |
| `q^em` 全零（两链） | `True` |

**限定与风险（必读）**：`c`/`q_dis` 的逐点一致性**不是**模型的必然结论——调整层的次要目标只覆盖 `R_m = {6m < i ≤ 144}`，时域短于计划层，故轨迹可能因退化而不同。**逐点比较必须先声明比较口径**（§D7-A/B）；`b`/`q`/`q^em`/`C_total` 是 P2 保证的量。
**该命题是结构检查，不是两链数值应相等的理由**（含预报误差与偏差结算时两链必然不同）。

## 10. 结构发现：`4-2` 的 `q_em ≡ 0` 是定理而非实测巧合

- **证明路径**（§2.3）：替换论证（`α_em = 5 > 1`、`b` 无上界）⇒ 计划层 `q_em ≡ 0`；再由等式平衡精确闭合 ⇒ `r = s ≥ 0` ⇒ 结算层 `q_em = 0`。
- **对价格是否已知不敏感**：证明只用「附件 2 实际（物理信息完全）+ 等式平衡 + `s ≥ 0`」，与 `A8-(b)` 无关。
- **与 prob02 `A17` 的关系**：结论相同、前提不同（P4-D3），**不得**宣称「移植 prob02 结论」。
- **后果**：`4-2` 表 3 与 `紧急购电量` 工作表预期全零 ⇒ 论文必须给机制说明 + `ablation` 的购电上限灵敏度小表（阈值按本问分链重新扫描，禁止引用 prob02 的 `(4218.75, 4375.00] kW` 或 prob03 的 `[4375.0, 5000.0] kW`）。
- **反向诊断**：若实现出现 `q_em > 0`，先查「信息集越界」或「平衡式写错」（例如把预测光伏写进结算层平衡），**不得**当作新机制发布。

## 14. 失败类型与回退路由（供实现/计算阶段复用）

| 现象 | 失败类型 | 路由 |
|---|---|---|
| 交付期 `C_total` 落入 `10^6`（×1/6）或 `10^8` 量级 | `code_runtime`（量纲硬错误） | 回 `implementation` 查 `Δt` 误乘 |
| `4-2` 出现 `q_em > 0` | `code_runtime`（平衡式/信息集错误） | 回 `implementation`；**不得**当作新机制 |
| `4-3` 的 `Σq^em ≡ 0` | `code_runtime`（`Π_m` 误写为 `PV^act` 或附件 3 未消费） | 回 `implementation` |
| `C^{act}(4-2) < A2-PRE − 1e-6` | `code_runtime`（可行域被放宽或口径污染） | 回 `implementation`；**不得**解释为「机制发现」（`E-F1`） |
| `4-3` 的 `i ≤ 6m` 被回溯修改 / 决策层用了 `i > 6m` 的当日实际价 | `harness_invariant`（信息集越界） | `sanity` L1 判失败，回 `implementation` |
| 各层余额残差 > `1e-8` 或结算平衡 > `1e-6` | `code_runtime` | 回 `implementation` |
| 某层 LP 不可行 | `code_runtime`（`L7` 保证可行） | 回 `implementation` |
| 形式回测与假设探针的 `D_req` MAE 相对差 > 5% | `quality_warning` | 先查相位/前向填充/日期切片，**不得**先改预测器 |
| `κ_m` 触发截断 | `quality_warning` | 逐个登记（日期、`m`、`A_m`、`B_m`、原值、截断值、原因） |
| 模型计算层面的瞬时故障（worker 中断、SMTP） | `infrastructure_transient` | 按 `config/compute.yaml` 重试，不人工阻塞 |
