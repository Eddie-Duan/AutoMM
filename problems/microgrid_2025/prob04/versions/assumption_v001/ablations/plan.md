## 1. 被检验的核心结论（实验前固定）

- **K1（实现正确性）**：把 `4-3` 的价格整体替换为附件 1 的单日曲线（365 天重复、`PF-PERSIST` 精确）后，
  `4-3` 链必须**逐位复现** prob03 accepted `run003` 的 `M1`（`E-F4` 的 `C-ANCHOR-P03`）。
- **K2（价格预报误差可计价）**：主口径（`PF-PERSIST` 点预测 + 确定性 LP）的真实支出与
  「价格预报误差的代价」`ΔC_price` 在两条链上同号可复核；`ΔC_price` 的**符号按实测**，不预设为正
  （两链 `run002` 实测均为**正**：`4-2` +520,790.84 元、`4-3` +258,485.47 元，`D_req` 口径）。
- **K3（主口径不依赖模型族）**：`S-VAR`（24 场景两阶段随机）与 `S-RH`（`H>1` 前瞻）**只能**在主口径
  最优费用之下或之上给出**可解释的偏移**；`H = 1` **必须逐位等于**主口径（否则判实现错误）。
- **K4（两链结论分别成立）**：`4-2` 与 `4-3` 的对照结论**必须分链给出**；共享同一预测器与结算口径，
  差异只能来自「`4-3` 的调整层 + `0.5×`/`1.5×` 分段结算 + 附件 3 预报误差」。
- **K5（结构项有可量化/可证零贡献的边界）**：`s` 的收紧界（`D9-B`）**不改变最优目标值**（须给数值证据）；
  `κ_m` 水平校正（`AS11`）的贡献可量化；`5000 kW` 上限作用侧与 `η` 作用位置的分工须与
  `robustness` 的 `eta_placement` 族**口径对照**（不得混写）。

### 3.2 `S-VAR`（价格场景两阶段随机，团队 `R-1`）

#### 3.2.1 场景构造（**必须用附件 4 的历史实际价格**）

- **场景池**：对代表日 `d`，池 = `{d' < d}` 中**同型日**（`d' mod 7 == d mod 7`，近似同星期型）；
  若池内 `< 24`，按「**确定性等距 + 有放回**」在池内抽出 24 个（保证 2025-02/03 的代表日也能跑），
  并在 `summary.json.scenario_pool` 落盘 `pool_size`、`with_replacement`、`lookahead_free: true`。
- **场景**：`s = 1..24`，`p^{(s)} = p^{act}_{d', ·}`（144 点向量），**等概率** `1/24`。
- **禁止**：凭空设分布（承 prob03 `E4` 与本版本 §4 的文献边界）；使用 `≥ d` 的实际价。
- **披露**：`scenario_pool_scope_note` 明确「该经验分布只是**对照口径**，不是对真实价格分布的估计，
  且较晚的代表日其池与主口径 0:00 的信息集（仅 `d−1` 一天）宽严不一」。

#### 3.2.2 两阶段结构与变量

- **第一阶段（here-and-now，全场景共用）**：`b ∈ R^{144}`（计划购电量）。
- **第二阶段（`s` 场景内追索）**：
  - 链 `4-2`：`c^{(s)}, q_dis^{(s)}, s^{(s)}, E^{(s)}, q_em^{(s)}`（`q^{(s)} = b`，无调整机制）；
  - 链 `4-3`：`q^{(s)}, c^{(s)}, q_dis^{(s)}, s^{(s)}, E^{(s)}, u^{+(s)}, u^{-(s)}, q_em^{(s)}`
    （`b` 为参数，只提交一次）。
- **约束**：与主口径**逐条一致**（`E ∈ [1200,10800]`、`c ≤ 833.3333`、`q_dis ≤ 750.0000`、
  `E_{d,0} = E_{d−1,144}` 由代表日的前一日已提交链末态给出、终端自由）；层内弃光界用该层的物理盈余界；
  `u^± ≥ max(±(b − q), 0)`（分段线性化，LP 无损）。

#### 3.2.3 目标（**团队「必须的改写」**）

```
(S-VAR)  min_{b} Σ_s (1/24) · [ C_plan^{(s)}(b) + C_adj^{(s)}(b,·) + C_em^{(s)}(b,·) ]
         C_plan^{(s)} = Σ_i p^{(s)}_i · b_i                 ← 计划购电账单**场景相关**（数量共用、费用进场景）
         C_adj^{(s)}  = Σ_i p^{(s)}_i (β_def·u^{+}_{i} + β_over·u^{-}_{i})     （仅 4-3）
         C_em^{(s)}   = Σ_i 5 · p^{(s)}_i · q_em^{(s)}_i
```

> **明示**：本式**不含** `c^base·P_plan` 项（`R-1` 的「必须的改写」）。
> **结算一律用附件 4（此处为场景内的经验实际价）**，决策价不进入 S-VAR 的计价（S-VAR 检的是
> 「若 0:00 用场景分布对冲、事后按实际价结算」的期望账单）。

#### 3.2.4 报告四项（团队要求）

1. **期望费用相对主口径「点预测 + 确定性」的下降幅度**（12 代表日窗口，两链各一份）；
2. **首阶段 `b` 的形状差异**：给出 `mean_s` 无关的 `b^{S-VAR}` 与主口径 `b^{BASE}` 的**逐时段差**
   在哪些时段最大（`top` 幅度时段 + 分时段块和），并说明对冲发生在高价时段还是低价时段；
3. **计算成本**：LP 变量/等式规模、`linprog` 调用数、墙钟秒数与主口径的比值（证明裁剪必要）；
4. 与 **「价格预报误差的代价」`ΔC_price`** 的并置披露（同窗口）。

### 3.3 `S-RH`（滚动时域，团队 `R-2`）

#### 3.3.1 决策时刻与承诺规则

- 链 `4-2`：每天 `t = 0:00` 决策一次；链 `4-3`：每天 `0:00` + `6:00/12:00/18:00`。
- **每次决策在 `[t, t+H]` 上求解，只提交属于「当天（当层）」的决策**，时钟前进后以更新状态重解
  ⇒ 非预期性（`AS07`/`AS11`）自动满足：窗口内的未来变量**只用于优化、不进入承诺**。

#### 3.3.2 窗口结构与粒度（冻结前的口径选择，须披露）

- **当天剩余时段**：保持主口径的 **144 时段 10 分钟粒度**，用该链已登记的决策价
  （`4-2`：`PF-PERSIST`；`4-3`：该层 `\hat p^{(m)}`）与**该链已登记的当日光伏**
  （`4-2`：附件 2 实际；`4-3`：附件 3 的 `Π_m` 降尺度）。
- **未来日（`d+1 … d+H−1`）**：以 **1 小时块粒度**（每块 = 6 个 10 分钟时段，决策变量为块平均功率对应的电量）
  优化，块内平衡式与状态转移按「1 小时 1 步」聚合；`E` 在块间连续。
  该粗粒度是本对照的**方法学设定**（不是主口径），用于在有限预算下使 `H = 14` 可行；已登记于
  `summary.json.window_granularity`。
- **`H = 1` 时未来日块为空** ⇒ 窗口恰好等于当日的剩余时段 ⇒ **必须逐位复现主口径**（判据 `C3`）。

#### 3.3.3 超 24 h 的预期（**强制登记**，团队 `R-2`）

- **价格**：未来日一律用 `PF-PERSIST`（只用 `≤ d−1` 的历史）⇒ `\hat p_{d+k,·} = p^{act}_{d−1,·}`。
- **负荷 / 光伏**（第一口径，主）：附件 2 的**同月历史均值**（只用 `≤ d−1` 的日子）；
- **第二口径（敏感性）**：**最近 7 天实测均值**（同样只用 `≤ d−1`）。
- **禁止**声称获得了超过 24 h 的预报。本节的登记即该新增假设的正式落点（`assumption_v001` 已 accepted ⇒
  按 `AGENTS.md`/`E-F4` 走**团队勘误追加**，不改既有口径；本文件与 `report.md` 承担登记义务）。
- **末窗**（窗口越过 `12-31`）按**终端自由**处理并登记：未来日不存在 ⇒ 窗口截断到 `12-31`。

#### 3.3.4 `4-3` 链的显式边界（**冻结**，见 §0.4 `A-5`）

- 深度 `H` 只作用于**计划层**的窗口；`6:00/12:00/18:00` 调整层仍**只支配当天**（其「滚动」是横向的
  信息更新，不是纵向的日跨度）。`H = 1` 时 `4-3` 退化为 `M1`（当日前瞻 36 时段）。
- 因此 `4-3` 的 `S-RH` 结论表述为：「**计划层的跨日前瞻**」的效果，而不是「`4-3` 整体滚动时域」的效果。

#### 3.3.5 报告三项与三条判据

- 报告：(a) `D_full`/`D_req` 费用差；(b) **日边界储电量行为** —— `Σ_d |E_{d,144} − 1200|`、
  `E_{d,144}` 的均值与唯一取值数（**直接回应 prob03 `E8`/`R18`**）；(c) 每层与总求解时间。
- 判据：`C3`（`H=1` 逐位复现）、`C4`（`4-2` 单调性方向）、末窗终端自由登记。

## 6. 失败处理

- 单 case 不可行 / 超时 / 非零返回：保留在 `raw/` 并计入失败计数，**不删除、不静默替换**；
  在 `comparison.json` 中该格写「不可行/未执行 + 原因」，并按 `allow_pass_with_warning` 登记技术债。
- `C1`/`C2`/`C3` 任一失败：**整批中止**（exit 4），按 `needs_revision` 路由，**不引用**任何对照数值。
- 输出含 NaN/Inf：`allow_nan=False` 直接失败，不落盘。
- 计算必须经隔离 task、独立输出目录与 supervised worker；本 Agent **不自行代跑**、不调用 `start_queued`。
- **`E-F6` 纪律**：本地任务处于 `running` 时**禁止** `RESUME`/`reconcile_tasks()`；解除暂停前须先确认无运行中任务。
- 代码修复只允许在新 attempt + 新 `output_directory` 下重跑，不覆盖既有结果。
