  确定性等距抽 24 个、**等概率 `1/24`**；实测首个代表日（2025-03-20）`pool_size = 78`、`with_replacement = false`。
- **场景价**：`p^{(s)} = p^{act}_{d′,·}`（附件 4 的 144 点实际价向量）。
- **目标（团队「必须的改写」）**：`min_b Σ_s (1/24)[ C_plan^{(s)}(b) + C_adj^{(s)} + C_em^{(s)} ]`，
  其中 `C_plan^{(s)} = Σ_i p^{(s)}_i · b_i` —— 计划购电账单**场景相关**（数量共用、费用进场景），

- **披露**：`scenario_pool_scope_note` 明确「该经验分布**只是对照口径**，不是对真实价格分布的估计」；
  较晚代表日的池与主口径 0:00 信息集（仅 `d−1` 一天）宽严不一。

## 10. 结论（回答 `plan_v001` §7 三问）

### ① 核心结论是否依赖模型族？

**部分依赖，且依赖点已精确定位。**

- **不依赖**（两链皆成立）：
  - **费用水平**：所有模型族对照对 `D_req` 的改变 ≤ **0.28%**（`4-2`）/ **0.15%**（`4-3`）；
    `S-RH` 与 `PF-AR` 的方向一致（更省），无方向反转；
  - **`4-2` 的 `Σq^em` 机制级恒零**：`PF-AR`、三条 `S-RH`、`S-ABL-TIEBREAK` 下 `Σq^em` 仍 ≤ `1.5e-10` kWh；
  - **`4-3` 的 `Σq^em` 非零量级**：`S-RH(H>1)` 下 393,906 kWh（相对主口径 394,026 kWh 仅 −0.03%）；
  - **`ΔC_price` 为正**（价格预报误差使实际支出更高）在 `PF-AR`、`S-RH`、`κ_m≡1` 下**同号**。
- **依赖**：**「日边界不跨日携带电量」（`E_{d,144} = 1200`）**只在「逐日 0:00 决策 + 终端自由」这一结构内成立；
  允许跨日前瞻（`H ≥ 3`）后，日边界抬到 ≈5,330 kWh、贴下限日数由 365/364 降到 30/365（§5.2）。
  ⇒ prob03 `E8`/`R18` 的答案**必须限定结构**给出。
- **退化项须单独表述**：`S-VAR(4-3)` 因自由追索与 `S-VAR(4-2)` 逐位同解，不构成 `4-3` 的独立模型族证据。

### ② 被消融项的经济贡献

按 `D_req` 口径的贡献排序（两链分列）：

1. **价格预报误差的代价** `ΔC_price`：**+520,790.84 元（4-2）/ +258,485.47 元（4-3）**（另一基数 573,883.11 元）——**第一位**；
2. **`η` 作用位置**（定义变体，非经济项）：−4.3086% / −3.1604% / −1.9880%（`4-2`）；
3. **`PF-AR` 预测器替换**（`4-2`）：−35,404.05 元（−0.2722%）；
4. **跨日前瞻 `S-RH(H>1)`**：−23,220.12 元（`4-2`）/ −22,811.97 元（`4-3`），且 `H=3` 后饱和；
5. **弃光界收紧（`D9-B`）**：`4-2` **≡ 0**、`4-3` **+7,879.47 元**（+0.0515%，`C6` 判不通过，须披露）；
6. **`κ_m ≡ 1`**：`ΔC^act = 1.49e-8` 元（≈0），但改变 `C^fc` 口径的 `ΔC_price`（计价口径项，非经济项）；
7. **`AS21` tie-break 字面化**（`4-2`）：**+0.1107 元**（`D_req`）——**近乎零贡献**，字典序解与字面 `ε` 解在经济上等价。

### ③ 论文主表推荐采用的模型及理由（两链分别）

- **链 `4-2`**：**推荐主口径（`PF-PERSIST` 点预测 + 确定性 LP）不变**。理由：① 所有模型族对照对其费用结论的改变 ≤ 0.28%，
  且无方向反转 ⇒ 主口径**不因模型族选择而失稳**；② `PF-AR` 在 `D_req` MAE 上更优（0.080664 vs 0.084326），
  但按 `AS08` 属 ablation 对照，主口径选择由团队冻结；③ `S-RH(H>1)` 虽更省（−0.1785%），
  但改变日边界语义、且收益在 `H=3` 后饱和，**不宜作为交付口径**。
- **链 `4-3`**：**推荐主口径（`PF-PERSIST` + `κ_m` 滚动更新 + `0.5×/1.5×` 分段结算）不变**。理由：
  ① `C-ANCHOR-P03` 六项逐位复现 prob03 `M1`（≤ `4.9e-13`）⇒ 实现正确性有硬证据；
  ② `κ_m` 的**实际结算贡献 ≈ 0**（1.49e-8 元），说明主口径的费用结构不由 `κ_m` 支撑，但 `κ_m` 影响预报误差计价；
  ③ `S-RH(H>1)` 同样只带来 −0.1492%、且不改变交付值；
  ④ `S-VAR(4-3)` 因自由追索退化，**不能**作为「应改用随机优化」的论据 ⇒ 与 `AGENTS.md`
  「随机规划/鲁棒优化必须由问题结构与预算证明必要性」一致，**本问不需要改主口径**。
- **论文应如何引用 ablation**：作为**主口径稳健性证据**（模型族不改变费用结论）+ **一条结构性限制**
  （日边界结论依赖决策视野）+ **一条计价结论**（价格预报误差是第一位不确定性来源）。
