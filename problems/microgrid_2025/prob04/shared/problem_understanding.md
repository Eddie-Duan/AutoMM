- 归属：`microgrid_2025` / `prob04`；阶段：`problem_understanding`

## 1. 题面要求（原文要点）

实际上，外网的电价也是实时波动的。请针对波动电价，建立微网当天购电策略的数学模型。

根据附件 2 的小区负载和光伏发电、附件 3 的光伏发电预报和附件 4 的电价数据，在波动电价下**重新计算问题 2 和问题 3**，并交付：

- `result4-2.xlsx`（对应问题 2 的全部结果，模板与 `result2.xlsx` 相同）；
- `result4-3.xlsx`（对应问题 3 的全部结果，模板与 `result3.xlsx` 相同）；
- 论文中给出相应计算结果。

## 2. 输入

| 输入 | 用途 | 口径 |
|---|---|---|
| `data/附件4.xlsx` | 实时波动电价（元/kWh） | 2025-01-01～12-31，144 点/天；取值 ∈ [0.0076, 1.7936] |
| `data/附件2.xlsx` | 小区负载、光伏发电实际功率（kW） | 同 prob02 |
| `data/附件3.xlsx` | 光伏预报（0:00/6:00/12:00/18:00 × 24 点，kW） | 同 prob03 |
| 附录 1（题面） | 储能参数 | 同 prob01 |
| `data/附件5/result4-2.xlsx`、`result4-3.xlsx` | 交付模板 | 分别与 result2、result3 模板逐字节相同 |

不使用附件 1（其电价被附件 4 取代）。

## 3. 预期输出

1. 波动电价下的数学模型（问题 2 版本与问题 3 版本）：
   - 4-2：逐日计划购电 + 5 倍价紧急购电，价格用 `price_{d,t}`（附件 4）；
   - 4-3：0:00 计划 + 6:00/12:00/18:00 调整，含 0.5× 违约与 1.5× 超出结算，价格用附件 4。
2. 数值结果（2025-02-01～12-31）：计划购电量、调整购电量（4-3）、充/放电量与储电量、紧急购电量及时段、费用分解。
3. `result4-2.xlsx`、`result4-3.xlsx`（按各自模板完整填写）。
4. 与问题 2/3（固定电价，附件 1）结果的对比（费用、紧急购电、充放电行为差异）。

## 4. 使用的前问结论（软依赖 `prob01 → prob04`、`prob02 → prob04`、`prob03 → prob04`）

- `prob01`：基础微网-储能-外网联合模型结构；
- `prob02`：紧急购电机制、逐日数据口径、结果表结构（4-2 复用）；
- `prob03`：计划/调整双轨与违约/超出结算框架、多时刻预报使用方式、"是否引入其他预报时刻"的结论（4-3 复用）。

- `problem_understanding`：本文件；

## 6. 待研究问题（不得在本阶段固定）

- **A8（高优先）**：0:00 制定计划时实时电价的已知程度。候选：(a) 全天实时电价已知（完全信息确定性优化）；(b) 仅知历史，需价格预测并承担预测误差；(c) 实时滚动观测（临近时刻才知价格）。三种解读给出不同模型与结果，**必须裁定**（可能需文献支持）。
- **A2**：逐日独立性与日初储电量口径（与 prob02/03 一致）。
- **A6 / A7**：预报语义与降尺度、调整与违约结算口径（沿用 prob03 裁定）。
- **A5**：紧急购电与充电的口径；弃光处理。
- 问题 4 是否需要"价格预测"环节以及预测误差如何进入费用（若采用 (b)）。
