### AS05 附件 3 预报语义、10 分钟降尺度与年末边界（A6，**key**）

  右端点或小时平均语义，锚定误差上升约 3.8 倍。

### AS07 计划层 / 调整层 / 实际结算层的三层结构与不回溯（**key**）

- **精确陈述**：模型分三层——**计划层**（0:00，按 0:00 预报对 `D_full` 全天可行：`b + PVfc0·Δt + q_dis^pl = L·Δt + c^pl + s^pl`，
  含计划储电量轨迹与跨日衔接）；**调整层**（6:00/12:00/18:00，按各自时刻预报、以实际已实现状态为初值，顺序重优化其支配的剩余
  时段，得到最终购电量 `q` 与最终充放电/储电量轨迹）；**实际结算层**（用附件 2 实际光伏闭合实际平衡
  `q + q_em + PVact·Δt + q_dis = L·Δt + c + s`）。`q_t` 取支配该时段的**最后一个**决策时刻的取值（替代量、不回溯），
  `t ≤ 36` 时 `q_t = b_t`。**纪律**：单一确定性路径下，「各时刻只用该时刻已发布信息」必须由**顺序滚动求解**实现，
  **不得**用一次性联合 LP 让计划层/调整层看到未来实际值。
- **依据**：文献支撑两阶段随机规划 + 滚动时域（`ref-li-2016-two-stage-rhc`）、多阶段逐阶段依新信息调整
  （`ref-bhattacharya-2018-multistage-storage`）、含调整/回素的多阶段 MILP（`ref-fusco-2023-multistage-uc`）与微网 EMS 的
  滚动/MPC 实现（`ref-elkazaz-2020-convex-mpc-rhc`）；题面 H10/H11 规定四个决策时刻且各时刻只用已发布信息。
- **适用边界**：prob03 全部求解与可追溯性设计；prob04-3 沿用。计划层/调整层的具体变量分层、目标与初始状态传递由 formulation 落地。
- **偏差方向**：若用一次性联合 LP，计划层会「看到」实际值，等价于完全信息，`C_adj` 被系统性压低（趋近 0），本问的调整机制与
  A9 的答案失真。
- **验证**：sanity L1 复核决策层时序（计划层不含实际值、调整层不含发布时刻之后的实际值）；L3 复核 `q` 与 `b` 的支配关系；
  implementation 须保存各层求解日志与输入指纹。

### AS08 供电可靠性与紧急购电的作用位置（A5，**key**）

- **精确陈述**：实际结算层满足等式电量平衡 `q + q_em + PVact·Δt + q_dis = L·Δt + c + s`，且 `0 ≤ s ≤ PVact·Δt`、`q_em ≥ 0`，
  故供给 `q + q_em + q_dis + (PVact·Δt − s) = L·Δt + c ≥ L·Δt` 自动成立，题面「微网提供的电能不可低于小区负载」得到保证，
  充电不与负载竞争。`q_em` 仅用于补足负载缺口、**不得用于储能充电**（该限制在本题最优解处不改变结果，但变量与触发保留）；
  单价为 `alpha_em·p = 5p`。**不采用**「净供给 ≥ 负载」弱口径，也不把 `q_em` 降级为事后派生量。
- **依据**：题面 H1 与问题 3 的总费用构成（含紧急购电费用）；prob01 accepted AS04 / prob02 AS06 的等式平衡口径
  （团队裁定 D3/D4-A）；A5 在 prob03 仍是「推荐口径」而非团队已裁定项，故按推荐登记并保留决策点 D7。文献只支撑「把不平衡量
  显式建模并配独立价格、滚动 EMS 与可靠性约束兼容」的形式（`ref-shang-2017-emergency-pricing`、
  `ref-li-2024-energy-purchase-strategy`、`ref-elkazaz-2020-convex-mpc-rhc`），不裁定 `q_em` 是否可用于充电。

- **验证**：sanity L1/L2 逐时段平衡残差（含 `q_em` 与 `s`）≤ 1e-6、统计 `q_em` 与 `c` 同为正的时段数；L4 检查供给 ≥ 负载。

### AS09 计划 / 调整的双向分段结算（A7，**key**）

- **精确陈述**：`C_adj = Σ_{d,t} [ beta_def·p_t·(b_{d,t} − q_{d,t})^+ + beta_over·p_t·(q_{d,t} − b_{d,t})^+ ]`，
  `beta_def = 0.5`、`beta_over = 1.5`；**两段均为成本项**（`beta_def` 段为违约金，**不是退款**）。比较基准为当天 0:00 计划 `b`：
  以最终量 `q` 对计划做**单次**结算，不逐次链式重复计费。该分段函数可用非负辅助变量线性化（目标为 min 且两段系数为正，
  辅助变量在最优解处取紧）。
- **依据**：题面「计划购电量高于调整购电量的部分，违约电价是交易时刻电价的 50%；调整购电量高于计划购电量的部分，超出部分的
  电价是交易时刻电价的 1.5 倍」；`beta_def`/`beta_over` 为题面硬参数。文献支撑「计划—实际偏差按价格因子结算」
  （`ref-zhang-2020-eds-retailers`）、「区分欠/超两方向分别计价」（`ref-chauhan-2024-dsm-over-under`）、「是否/如何对不平衡量
  施加惩罚是显式设计变量、结算基准可取自日前价」（`ref-matsumoto-2022-imbalance-design`）、两结算框架
  （`ref-munhoz-2021-two-settlement`）与「偏差 → 显式成本惩罚项」（`ref-asgarpoor-1995-deviation-penalty`）、
  「日内再调度会改变成本、平衡阶段纠正预报误差有成本」（`ref-danti-2019-intraday-rescheduling`）；均属框架/机制级，

- **适用边界**：prob03 全部日期；prob04-3 在波动电价下沿用（`p` 换附件 4）。
- **偏差方向**：若把 `beta_def` 段当退款（`C = C_plan − 0.5p(b−q)^+ + 1.5p(q−b)^+`），在计划量可自由选择时会诱导
  「高报计划」的非物理激励；若用链式结算，同一时段多次调整会重复计费并与「调整购电量」单值列结构不相容。两种读法均在
  决策点 D2 中给出备选与利弊。
- **验证**：sanity L3 复核 `C_adj` 的逐时段分解与辅助变量紧性（互补残差）；L4 复核费用方向与量级（单日 10⁴ 元、交付期 10⁷ 元）；
  ablation 以结算口径对照（本版推荐 vs 备选 B 的「实际交付计价」）作结构比较。

- **实际结算**（不属于任何决策时刻，而是事后闭合）：用 `PVact`、`L` 与实际执行到的最终轨迹计算 `q_em`、`s'` 与三项费用。
- 跨年预报项（`b > 24`）不进入任何决策，见 AS05 第 4 条。

### 5.3 模型骨架（三层 + 结算层；均为线性，可一行 LP 求解）

```
计划层（0:00 预报；全天可行，不入目标成本，只决定 b）
  b_{d,t} + PVfc0_{d,t}·Δt + q_dis^pl_{d,t} = L_{d,t}·Δt + c^pl_{d,t} + s^pl_{d,t}
  0 ≤ c^pl ≤ 833.3333,  0 ≤ q_dis^pl ≤ 750.0000,  0 ≤ s^pl_{d,t} ≤ PVfc0_{d,t}·Δt
  E^pl_{d,t} = E^pl_{d,t−1} + 0.9·c^pl − q_dis^pl/0.9,  1200 ≤ E^pl ≤ 10800
  E^pl_{d,0} = E_{d−1,144}（实际末状态）,  E^pl_{1/1,0} = 6000,  E^pl_{12/31,144} 自由

调整层（m ∈ {6:00, 12:00, 18:00}，顺序求解；对其支配时段用该时刻预报）
  q_{d,t} + PVfc_{d,m(t),t}·Δt + q_dis_{d,t} = L_{d,t}·Δt + c_{d,t} + s_{d,t}
  初始状态 = 已执行到的真实 E；t ≤ 36 时 q_t = b_t
  （每层目标为该层剩余时段的偏差结算 + 紧急购电成本，不含已沉没的计划成本）

实际结算层（附件 2 实际值）
  q_{d,t} + q_em_{d,t} + PVact_{d,t}·Δt + q_dis_{d,t} = L_{d,t}·Δt + c_{d,t} + s'_{d,t}
  0 ≤ s'_{d,t} ≤ PVact_{d,t}·Δt,  q_em_{d,t} ≥ 0

目标与结算（不带 Δt）
  C_plan = Σ p_t·b_{d,t}
  C_adj  = Σ [ 0.5·p_t·(b_{d,t} − q_{d,t})^+ + 1.5·p_t·(q_{d,t} − b_{d,t})^+ ]
  C_em   = Σ 5·p_t·q_em_{d,t}
  min C_total = C_plan + C_em + C_adj
```

> **禁止**把三层写成一次性联合 LP 后让计划层/调整层「看到」实际值（AS07 纪律）；顺序求解的中间状态、输入指纹与各层目标值
> 必须落盘，供 sanity L1 审计信息集。目标中**没有** `·Δt`；若单日费用落到 10³ 元量级即说明误乘 Δt（硬错误）。

### D1 逐时刻信息集口径（A19，高优先）
- 备选 A：**预报驱动 + 实际结算**（多阶段、不回溯）。定义：4 个决策时刻；各时刻只用已发布预报；计划按 0:00 预报、调整按各时刻预报；实际结算用附件 2 实际光伏，缺口 → `q_em`（5×）、盈余 → 弃光。依据：题面明文要求「根据 0:00 预报制定计划、根据其他时刻预报调整」，且附件 2 是实际值、附件 3 是预报。影响：调整机制与表 3 有意义；`q_em` 可能非零；模型为多阶段 LP（计算量约为 prob02 的 2–3 倍）。优点：唯一同时用上附件 2 与附件 3、与题面完全一致。缺点：需显式声明「负载视为已知」「实际结算以光伏误差为唯一不确定性来源」。
- 备选 B：**完全信息**（0:00 即知全天附件 2 实际值）。定义：单阶段确定性最优，计划即最终；调整无信息增益；`q_em ≡ 0`。依据：与 prob02 A17 同构。影响：附件 3 不被使用，调整机制退化，表 3 全零，与题面「根据附件 3 的预报…调整」相悖。优点：模型最简、可作「完全信息上界」对照。缺点：与题面要求冲突，A9 的答案退化为「不需要其他时刻」。
- 备选 C：**混合口径**（负载不确定，或引入预报误差分布做随机/鲁棒优化）。定义：对负载或光伏误差建概率模型。依据：文献支持随机/鲁棒框架。影响：需新增误差分布假设与样本，规模与数据接口都缺。优点：更贴近现实。缺点：本问无负载预报数据、无误差分布来源，属越界（AS16 为确定性口径）。
- **推荐：A**。理由：只有 A 同时满足「使用附件 3」「调整机制有意义」「`q_em` 保留为变量」三项；B 仅作完全信息上界对照（可在 ablation 中作为一条对照记录），C 需新增无依据的分布假设。

### D2 计划/调整的结算关系与 0.5× 的方向（A7，高优先）
- 备选 A：**计划全额计价 + 双向偏差成本项**：`C_total = Σp·b + Σ[0.5p(b−q)^+ + 1.5p(q−b)^+] + C_em`；`beta_def` 段为违约金（成本）。依据：题面「总费用包括计划购电费用、紧急购电费用和调整购电量的相关费用」的字面。影响：低估/超额的边际成本分别约为 1.5p/0.5p（相对计划），调整的收益主要来自减少 5p 的 `q_em`。优点：与题面三项分解完全对应、可审计。缺点：计划量若可自由选择会出现「向 q 靠拢」的倾向（本问由 AS07 的计划层可行性约束固定 b，抑制该倾向）。
- 备选 B：**实际交付量计价 + 违约费**：`C_total = Σ[p·min(b,q) + 0.5p(b−q)^+ + 1.5p(q−b)^+] + C_em`。定义：只按最终交付量计价，计划未履约部分另付 0.5p 违约费。依据：把「违约电价 = 50%」解释为该部分电量本身的结算价。影响：低估/超额的边际成本分别约为 1.5p/0.5p（相对计划量），但与 A 的绝对费用不同（差额为 `p·(b−q)^+`）。优点：避免为未使用的计划电量付全价，物理上更自然。缺点：与「包括计划购电费用」的字面不完全吻合。
- 备选 C：**0.5× 为退款/冲抵**：`C = Σp·b − 0.5p(b−q)^+ + 1.5p(q−b)^+ + C_em`。依据：把「违约电价 50%」理解为下调部分按 50% 返还。影响：计划量的边际成本变为 ±0.5p，若 b 可自由选择会诱导「高报计划」，模型退化。优点：形式上对称。缺点：非物理激励明显，须团队明确后方可采用。
- **推荐：A**。理由：与题面三项分解逐字对应、可审计；B 作为 `ablation` 的口径结构对照（只改结算一项，其余不变）；C 因非物理激励不建议采用。

### D3 计划与调整的关系、比较基准与作用时段（A7/A20）
- 备选 A：**替代量 + 单次结算 + 不回溯**：`q` 为最终购电量；每时段由最后一个支配时刻取值；`C_adj` 以当天 0:00 计划为基准单次结算；调整只作用于发布时刻之后的时段。依据：模板两工作表为同结构向量；题面「计划购电量高于调整购电量的部分」把两者作为可比向量。影响：无重复计费；`result3.xlsx` 每格唯一。优点：可审计、与模板兼容。缺点：同一时段多次调整只体现最终结果（中间修订不可见，须在报告附轨迹）。
- 备选 B：**链式结算**：每次调整与上一次调整比较并各自结算。依据：把「其他预报时刻」视为独立结算事件。影响：同一时段可能被多次计费；需在多张表或单表多列中保存各阶段量。优点：能体现每次修订的成本。缺点：与模板单值列不相容，且可能重复计费。

### D5 附件 3 预报语义与 10 分钟降尺度规则（A6，高优先）
- 备选 A：**整点点值 + 以整点为锚的线性插值**（本版推荐）。依据：本动作探针实测整点锚定 RMSE 269.50 kW（±1 h 为 1038.88/1041.88 kW）；线性插值 per-period RMSE 303.92 kW，优于前向保持 580.62 kW。影响：预报曲线平滑、更贴近实际逐 10 分钟出力；块内能量由插值积分给出（不强制等于点值 × 1 h），实现需显式写插值公式。优点：数据拟合最好、与「整点预报」语义一致。缺点：块内不保能量，须在论文说明能量口径。
- 备选 B：**整点点值 + 分段常数（前向保持）**。依据：实现最简、块内能量严格等于「点值 × 1 h」，便于与题面「整点功率 × 时间」的直观解释对齐。影响：per-period RMSE 升至 580.62 kW（含偏置 −50.48 kW），逐 10 分钟出力被高估的时段偏多。优点：能量守恒、实现与审计最简。缺点：对快速波动与日出/日落过渡段的刻画差。
- 备选 C：**小时平均语义**（把「预报 k 小时」解释为第 k 个小时的平均功率，块内常数）。依据：部分文献用小时平均。影响：探针显示预报值与实际整点值的贴合度（269.50 kW）显著优于与块均值的贴合度（501.77 kW），故该语义与实际数据不符。优点：能量语义最直接。缺点：与附件 3 数据特征不符，拟合最差。
- **推荐：A**。理由：本问的数据事实（整点锚定 + 插值最优）明确支持 A；若团队更看重「块内能量守恒 + 实现最简」，可替换为 B，但**必须**在下一版用同一判据重算并披露 RMSE 与费用差异。C 因与数据不符不推荐。

### D6 年末边界与跨年预报的消费规则（A6 子项，高优先）
- 备选 A：**不回溯 + 跨年项不消费**（本版推荐）。定义：发布时刻 `m` 只支配 `t ≥ 6m+1`；`b = m+k > 24` 的跨年项（6:00 的 k = 19…24、12:00 的 k = 13…24、18:00 的 k = 7…24）不被使用。依据：题面「可获得未来 24 小时整点预报」但附件 2/4 无 2026 数据；「其他预报时刻调整」的自然含义是修订当天剩余时段。影响：12-31 18:00 的调整只用 k = 1…6（18:10–24:10）；无需外推或截断。优点：完全在数据范围内闭合、可复现。缺点：放弃 12-31 晚间的部分预报信息（但那部分指向 2026，本问不需要）。
- 备选 B：**允许滚动 24 h 窗越日**，把跨年项用于 2026-01-01 的时段。依据：字面「未来 24 小时」。影响：需要 2026-01-01 的负载/实际光伏数据（附件 2/4 无），或需新增外推假设；结算范围也须扩展到 2026。优点：用满预报信息。缺点：数据缺失、交付范围（2/1–12/31）之外，属越界。
- 备选 C：**外推**（把 12-31 18:00 的跨年项按最后有效值/周期性外推到当日末）。依据：无。影响：引入无依据的数值，污染 12-31 的调整与结算。优点：形式上门闭合。缺点：伪造数据。
- **推荐：A**。理由：在题面与数据范围内唯一自洽；B 受数据缺失阻断，C 无依据。

### D7 紧急购电的作用位置与能否用于储能充电（A5）
- 备选 A：**等式平衡 + `q_em` 仅补足负载缺口**（本版推荐）：`q + q_em + PVact·Δt + q_dis = L·Δt + c + s`，`q_em ≥ 0`；声明 `q_em` 不用于储能充电（在最优解处不改变结果，但变量与触发保留，sanity 统计 `q_em` 与 `c` 同为正的时段数）。依据：prob01 accepted AS04 / 团队裁定 D3；题面 H1。影响：模型闭合、可与实际结算残差对照。优点：与上游一致、可审计。缺点：`q_em` 的「不用于充电」在 LP 中只能靠声明 + 事后统计。
- 备选 B：**弱口径「净供给 ≥ 负载」**。依据：部分文献用净供给。影响：把充电算作供给，放松可行性、可能制造账面套利，费用被系统性低估。优点：形式更简。缺点：prob01 D3 已否决。
- 备选 C：**`q_em` 作为事后派生量**（先定计划，缺口才紧急购电），不进入优化。依据：字面「如果低于负载，需向外网紧急购电」。影响：无法与计划/调整协同优化，且与「保留为变量」的要求冲突。优点：语义最直白。缺点：与三层结构不相容。
- **推荐：A**。理由：与上游一致且可闭合检验；B/C 分别有可行性放松与结构冲突问题。

### D8 表 1「全天购电费」口径与 4 小时块（A10/A11）

### D9 弃光/盈余变量 `s` 的界（A13）
- 备选 A：**按各层 PV 上界、目标系数 0**（本版推荐）：计划/调整层 `0 ≤ s ≤ PVfc·Δt`，结算层 `0 ≤ s ≤ PVact·Δt`；无售电收益。依据：prob01 accepted AS08 / prob02 AS09；题面无售电渠道。影响：`s` 只用于闭合盈余，不进目标。优点：与上游一致、无需新参数。缺点：若未来引入售电，该界不够紧。

### T7 对 **F4** 的裁定：**统一冻结 tie-breaking 规则**（新增裁定，效力高于 B4-`C5` 的初版措辞）

团队确认 F4 是**真问题**，且**影响面大于对照项**：由于 `M1` 是「前一日已提交轨迹 → 次日计划层初值」的**向前递推**，
计划层的最优面选择（同一 `b` 下 `c`/`q_dis`/`s` 的分解不唯一）会**传播到后续层与后续日的初值**，
使 `C_adj`/`C_em` 乃至主结果**随求解器返回的最优基而变**——即**主口径当前不保证可复现**。

- **T7-1（冻结规则）**：**所有层、所有模型（`M1`–`M8`）**一律使用同一次目标：
  `min [ 该层主目标 ] + ε · Σ_t ( c_{d,t} + q_dis_{d,t} )`，即**在最优解中优先选择储能吞吐量最小者**
  （物理含义：减少循环、降低损耗；`ε = 1e-6 × 主目标尺度`，取足够小以保证不改变主目标最优值）。
- **T7-2（不变性验证）**：实现必须落盘「加入次目标前后，主目标相对变化 ≤ `1e-9`」的逐层验证；
  若不成立则说明 `ε` 过大，必须调小后重跑。
- **T7-3（可选性说明）**：若某层在 `ε·吞吐` 下仍存在多个最优轨迹，实现必须**报告**该层的退化维度与影响的上游量，
  不得静默取一个解。
- **T7-4（`C5` 的更正）**：在 T7-1 的规则下重跑 A9 对照后：
  - 若 `C(M5,每1小时) ≤ C(M5,每3小时) ≤ C(M1)` 成立 ⇒ `C5` 原样通过；
  - **若不成立，不得强行制造单调性**（禁止调 `ε`、禁止换 tie-break 规则去凑结论）。必须按 F4 的机制
    （**近视滚动 + LP 退化**）如实报告，并登记为**结构性发现**；此时 `C5` 的判定改为「单调性或其反例机制二者之一必须可复现」。
- **T7-5（公平性）**：`M8`（独立第二实现）**只允许**在求解器设置（如 `presolve`、消元顺序）上不同；
  **tie-breaking 规则必须与 `M1` 完全一致**，否则 `M8 ≡ M1` 的比较失去意义（B5 公平性纪律的细化）。
- **T7-6（新增；主结果对 tie-break 的敏感性必须登记并披露）**：`implementation` 实测（14 天窗）**链级 `C_total` 在加入 T7-1 前后
  从 `761,150.711525` 变为 `761,322.475606` 元（相对差 `2.2566e-4`，+171.76 元）** —— 机制正是 T7 的理由本身：
  主目标（费用）不变，但最优点（轨迹）改变，经**跨层/跨日初值传播**后链级总费用改变。
  **要求**：① `computation`/`sanity`/`ablation` 必须把该敏感性作为**已知口径敏感性**登记（不是缺陷）；
  ② 论文与 `robustness` 须披露「主结果对 tie-break 选择的量级敏感性约为 `10⁻⁴` 相对量级」；
  ③ **不得**用不同 tie-break 的结果互相比对（B4 公平性）——所有模型与所有 run 一律用 T7-1 的同一规则；
  ④ 由 T7-1 带来的**吞吐量下降**（14 天 `−14,853.09 kWh`）与**同时充放电时段数归零**（原 `N1`：13/2016 与 19/4896）须一并在报告中体现。

### T8 对 **F6** 的裁定：`C2` 降级为回归检查，`M2a` 保留
