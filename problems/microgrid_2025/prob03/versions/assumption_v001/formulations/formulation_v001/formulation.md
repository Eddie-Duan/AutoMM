### 0.4 本动作对 accepted 假设的**新发现**（须由团队确认，不得静默沿用旧登记）

> 以下 F1–F8 均由独立只读探针（§8）或解析推导得到，**不修改** `assumptions.md` 的正文与 B1 清单，仅在决策点请求确认。

- **F1（结构性：三层不能合并为单次联合 LP）**：`AS07` 要求计划层目标 `min Σp·b`（T1）与调整层目标（偏差结算）**分属不同目标**，
  且第 `d` 天计划层初值 `E^PL_{d,0} = E_{d−1,144}` 由**前一日已提交轨迹**给出，故 `M1` 是**带层次目标的向前递推**，
  不存在等价的单次 LP：写成一次联合 LP 会同时（i）让计划层看到后验预报/实际值（违反 `AS07`/H11），（ii）把两个不可加权的目标合并。
  **结论**：`M1` 必须按 §3.10 的顺序算法实现；`M2a` 与 `M1` 在算法上是**同一递推**（见 F6）。
- **F2（结构性：实际光伏只进结算层）**：因决策层的余额由**各层预报**闭合、物理状态链只由 `c`/`q_dis` 决定，
  **附件 2 实际光伏不改变任何决策量与 SOC 轨迹**，只改变结算层的 `q_em`、`s'` 与 `C_em`。
  **含义**：`E_{d,0} = E_{d−1,144}` 与「已实现状态」无需依赖实际光伏即可确定；`AS07` 的非预期性由构造直接满足。
  **探针**：把结算用实际光伏整体缩放 0.5 倍后，14 天链的 `C_plan`/`C_adj` 逐日**逐位不变**（仅 `C_em` 改变）。
- **F3（结构性：`q_em` 在决策层恒不激活）**：任一决策层的 LP 含等式余额与 `s ≥ 0`，故该层内 `q_em ≡ 0`；
  `q_em` 只在**结算层**由「该时段支配层预报 vs 附件 2 实际值」的缺口产生。即便把 `q_em` 作为变量加入决策层，
  因 `α_em = 5 > β_over = 1.5` 且 `q` 无上界，替换 `q_em → q` 严格更省，最优解仍取 `q_em = 0`（§3.9 L1）。
  **含义**：表 3 的非零完全由**预报误差**驱动，不是「购电上限激活」机制（勿与 prob02 R5 混淆）。
- **F4（判据可反转：`C5` 的单调性需要 tie-breaking）**：在同一发布集下加密决策时刻（`M5`），
  **每 3 小时与 `M1` 逐位同值**（额外时刻可复现 `M1` 轨迹），但**每 1 小时反而更贵**（14 天窗口 `+83.4747 元`）。
  机制：调整层只最小化偏差（reading A），目标在「可复现计划轨迹」处**退化**（`u^+ = u^− = 0` 多重最优），
  求解器返回的另一组零偏差解改变了后续状态，使后续层无法再保持零偏差；属**滚动近视 + LP 退化**，不是实现错误。
  **处理**：不改 `C5` 阈值，在决策点 **D3** 请求团队先固定 tie-breaking 规则。
- **F5（对照项退化：`PLAN-EXP` 的同信息集可实施性）**：`T1` 主口径为 `min Σp·b`；`PLAN-EXP` 要求「计划层目标 = 该层期望总费用，含偏差项与紧急购电项的预报期望」，
  且 B7-1 要求两者**信息集一致**（只能用 0:00 预报）。在 `AS15`/`AS16` 的**确定性、无预报误差分布**口径下，
  计划层对未来的唯一无偏代理就是 0:00 预报本身，于是 `q = b`、`q_em = 0`、偏差项为 0，**`PLAN-EXP` 退化为 `min Σp·b`**。
  要得到非退化的 `PLAN-EXP`，必须先给出预报误差分布（与 `AS16` 冲突，需团队批准为诊断性 sensitivity）**或**允许计划层使用后验预报（违反 `AS07`）。
  本文件在 **§3.3（PL-0b）写出两种可执行形式**，并在 **D4** 请求裁定。
- **F6（`C2` 的语义澄清）**：`M2a`（逐日解耦 + 状态递推）与 `M1` 描述的是**同一向前递推**（见 F1），
  因此 `C2`（`M2a ≡ M1`，≤1e-8）是**结构性恒等式**而非「分解等价性」的独立证据；**实现级独立证据应由 `C3`（`M8`）承担**。
  本文件不修改 `C2` 阈值，只在 §5.1/D2 声明其适用范围。
- **F7（跨问解析锚点：`M3` ≡ prob02 `(P2)`）**：`M3`（完全信息、`q ≡ b`、`q_em ≡ 0`、单阶段）在
  `D_full`、`E_init = 6000`、终端自由、无购电上限、同设备约束下与 prob02 accepted `formulation_v001` 的 `(P2)`（令 `q_em ≡ 0`）**逐项相同**
  （§3.9 L6），故 `M3` 的最优值应等于 prob02 accepted computation 的**全期 13,758,182.573724 元 / 交付期 12,233,050.830708 元**（相对差 ≤1e-6，求解器容差内）。
  这是**跨问独立锚点**：`ablation`/`sanity` 可据此校验 `M3`（引用的上游数值为只读 accepted 产物）。
- **F8（`M6` 的紧 Big-M 可推导）**：偏差辅助量存在**由模型推导的紧上界**：`u^+ ≤ b_{d,i}`（因 `q ≥ 0`）、

  Big-M 逐时段可算。探针：单层 LP 与 72 二元 MILP 目标同值（`mip_gap = 0`，相对差 `9.1e-13`）。

## 3. 逐步推导

### 3.1 时间离散与全局索引（AS01/AS02/AS09）

附件 2/3 的 10 分钟粒度给出

```
(R0)  Δt = 24 h / 144 = 1/6 h ；位置 i 代表区间 [10(i−1), 10i) 分钟（左端点口径，计划窗 0:10 → 24:10）
      功率→电量换算 X·Δt（X ∈ {L, PV^act, Π_m[PV]}）；决策变量 b/q/c/q_dis/s/q_em 直接以 kWh 表示（已含 Δt）
      b(i) = ⌈i/6⌉ ∈ {1…24} ； j(i) = i − 6(b(i)−1) ∈ {1…6}
```

因决策变量本身是 kWh，**目标与平衡式不再对决策变量乘 Δt**（`AS10`/团队 D9 量纲纪律）。

### 3.2 AS05 降尺度算子 `Π_m`（整点点值 + 整点锚定线性插值）

设 `A_{d,m,k} = PV^{fc}_{d,m,k}`（`k = 1…24`，即 `(m+k):00` 的功率点值）。时段 `i` 的块 `b = b(i)`、块内位置 `j = j(i)`，
预报时效为 `k = b − m`（因 `b = m + k`）。定义

```
(R1a) k = b(i) − m
      Π_m[PV]_{d,i} = A_{d,m,1}                                    若 k = 1   （无 P(m)，前向保持）
(R1b) Π_m[PV]_{d,i} = (1 − j/6)·A_{d,m,k−1} + (j/6)·A_{d,m,k}     若 2 ≤ k ≤ 24 （P((b−1):00) → P(b:00) 线性插值）
(R1c) 未定义（不消费）：k < 1（该时段早于发布时刻，已过去）或 b > 24（跨年至 2026-01-01）
```

- **权重来源**：时段 `i` 的左端点 `tau_i = (b−1) + j/6`（小时），落在小时区间 `[b−1, b)`，故权重 `(1−j/6, j/6)` 作用于
  `P(b−1)` 与 `P(b)`；`j = 6` 时恰取右端点 `P(b)`。**注意**：`j = 6` 的左端点数值上等于 `b:00`，按严格小时区间应属 `[b, b+1)`；
  本文件按 `AS05` 第 3 条的**块位置映射**（块 `b = m+k` = 时段 `6(b−1)+1 … 6b`）处理，属模板固有相位的一部分（§7.3）。
- **块能量闭式（T3 强制披露）**：块 `b` 的 6 个时段求和

```
      Σ_{i ∈ block b} Π_m[PV]_{d,i}·Δt = Δt·[ Σ_{j=1..6}(1−j/6)·A_{d,m,k−1} + Σ_{j=1..6}(j/6)·A_{d,m,k} ]
                                        = (2.5·A_{d,m,k−1} + 3.5·A_{d,m,k}) / 6      （kWh，k ≥ 2）
                                        = A_{d,m,1}·1 h                              （kWh，k = 1，前向保持）
```

  一般地 `≠ A_{d,m,k}·1 h`：**线性插值口径不保块内能量守恒**（能量由插值曲线积分给出），
  该事实必须在论文与图注中显式披露（团队 `T3`），并给出「插值口径 vs 分段常数口径」的**实际光伏能量偏差统计**（`M7·D5-B`）。
- **支配关系与不回溯**：发布时刻 `m` 只支配 `i ≥ 6m+1`（`Π_m` 在 `i ≤ 6m` 未定义）；每时段只被**唯一**支配时刻控制

```
(R2)  ν(i) = 6·⌊(i−1)/36⌋ ∈ {0, 6, 12, 18} ；D_m = { i : ν(i) = m } ；|D_0| = |D_6| = |D_12| = |D_18| = 36
      i ≤ 36 → m = 0 ；37 ≤ i ≤ 72 → m = 6 ；73 ≤ i ≤ 108 → m = 12 ；109 ≤ i ≤ 144 → m = 18
```

  `ν` 由「`m` 是最后一个满足 `6m < i` 的决策时刻」唯一确定，**无需离散选择变量**，模型保持 LP。
- **跨年项清单（B7-5）**：`b = m + k > 24` 的预报项**不被消费**（不截断、不外推、不使用 2026 数据）：

| 发布时刻 `m` | 被消费的 `k` | 被丢弃的 `k` | 对应块 `b` | 落点 |
|---|---|---|---|---|
| `0:00` | `1…24` | 无 | `1…24` | `i = 1…144` 全覆盖 |
| `6:00` | `1…18` | **`19…24`** | `7…24` 消费；`25…30` 丢弃 | `k = 19…24` → 2026-01-01 01:00–06:00 |
| `12:00` | `1…12` | **`13…24`** | `13…24` 消费；`25…36` 丢弃 | `k = 13…24` → 2026-01-01 01:00–12:00 |
| `18:00` | `1…6` | **`7…24`** | `19…24` 消费；`25…42` 丢弃 | `k = 7…24` → 2026-01-01 01:00–18:00 |

  合计丢弃 36 个预报项（`6 + 12 + 18`），与 `AS05` 第 4 条逐项一致（探针 G2b 实测）。
- 文献（**框架级/机制级，只到摘要/元数据级**）：小时分辨率不足以表征 PV 短时波动、必须显式降尺度且不能默认常数
  （`ref-almpantis-2024-minute-downscaling`、`ref-grantham-2017-5min-from-hourly`、`ref-martins-2021-1min-irradiance`、
  `ref-barbieri-2017-very-short-term-pv`），低分辨率会平滑波动并给储能指标带来系统性偏差（`ref-stenzel-2016-temporal-resolution`，方向性），
  预报的「使用方式」与预报本身同等重要（`ref-sweeney-2020-forecasting-future`）。
  **文献不裁定取哪条降尺度规则**；「整点点值 + 线性插值」的采用依据是 `assumptions.md` §6 的**数据事实**（RMSE 269.50 / 303.92 vs 580.62 kW），
  该数值**不得**作为论文/sanity 的交付数值。

### 3.3 计划层 `(PL_d)`（0:00，B7-1/B7-2）

```
(PL-0a) 主口径（T1）： min_{b, c^PL, q^dis,PL, s^PL, E^PL}  Σ_{i=1..144} p_i · b_{d,i}
(PL-0b) PLAN-EXP 对照： min  Σ_i p_i·b_i
        + E[ Σ_i ( β_def·p_i·(b_i − q_i)^+ + β_over·p_i·(q_i − b_i)^+ ) + Σ_i α_em·p_i·q^em_i ]
        其中 E[·] 取「该层信息集（仅 0:00 预报 + E_{d−1,144} + L + p）」下的期望；
        在无预报误差分布时退化为 (PL-0a)（见 §0.4 F5 / D4）

(PL-1)  b_{d,i} + Π_0[PV]_{d,i}·Δt + q^dis,PL_{d,i} = L_{d,i}·Δt + c^PL_{d,i} + s^PL_{d,i}            ∀i
(PL-2)  0 ≤ c^PL_{d,i} ≤ 833.3333 ； 0 ≤ q^dis,PL_{d,i} ≤ 750.0000                                    ∀i
(PL-3)  0 ≤ s^PL_{d,i} ≤ Π_0[PV]_{d,i}·Δt                                                            ∀i
(PL-4)  E^PL_{d,i} = E^PL_{d,i−1} + 0.9·c^PL_{d,i} − q^dis,PL_{d,i}/0.9                              ∀i
(PL-5)  E^PL_{d,0} = E_{d−1,144}（前一日**已提交链**末态）； E^PL_{1/1,0} = E_init = 6000
(PL-6)  1200 ≤ E^PL_{d,i} ≤ 10800（∀i）； E^PL_{12/31,144} 自由（AS04，无终端约束）
(PL-7)  b_{d,i} ≥ 0（无上界，AS14）
```

- **计划层是「全天可行 + 最小计划购电费」的层**：`b` 在 `(PL-1)` 中以全天 144 时段定义（0:00 预报覆盖全天），
  其可行性由 `(PL-1)–(PL-7)` 保证；**仅 `D_0` 的 `c/q_dis` 被提交**（其余为计划轨迹，被后续层替代）。
- **T1 的必要性（团队强制更正）**：若计划层目标缺失或写「不入目标成本」，`b` 在同一可行多面体上不唯一，`C_plan` 与 `C_adj` 不可复现；
  故 `(PL-0a)` **必须**显式给出（B7-1）。
- **信息集一致性（B7-1）**：`(PL-0a)` 与 `(PL-0b)` 都只用「0:00 预报 `Π_0` + `E_{d−1,144}` + `L_{d,·}` + `p_{·}`」，二者信息集**完全相同**；
  `(PL-0b)` 的非退化形式需要额外误差模型（F5/D4）。

### 3.4 调整层 `(AD_{d,m})`，`m ∈ {6, 12, 18}`（B7-2/B7-3/B7-7）

```
(AD-1)  提交量（替代量口径，D3-A）：∀i ∈ D_m， q_{d,i} = q^{[m]}_{d,i} 、 c_{d,i} = c^{[m]}_{d,i} 、 q_dis_{d,i} = q^dis,[m]_{d,i}
        已提交时段固定：∀i ≤ 6m， q_{d,i}、c_{d,i}、q_dis_{d,i} 取先前层提交值（i ≤ 36 时 q = b）
(AD-2)  决策变量：{ q^{[m]}, c^{[m]}, q^dis,[m], s^{[m]}, E^{[m]} } 定义在剩余时段 R_m = { i : 6m < i ≤ 144 }
(AD-3)  目标（该层剩余时段的偏差结算；紧急购电项在该层恒为 0，见 L1）：
        min  Σ_{i ∈ R_m} [ β_def·p_i·u^+_{d,i} + β_over·p_i·u^−_{d,i} ] ,  β_def = 0.5、β_over = 1.5
(AD-4)  q^{[m]}_{d,i} + Π_m[PV]_{d,i}·Δt + q^dis,[m]_{d,i} = L_{d,i}·Δt + c^{[m]}_{d,i} + s^{[m]}_{d,i}      ∀i ∈ R_m
        0 ≤ c^{[m]} ≤ 833.3333 ； 0 ≤ q^dis,[m] ≤ 750.0000 ； 0 ≤ s^{[m]}_{d,i} ≤ Π_m[PV]_{d,i}·Δt ； q^{[m]} ≥ 0
        E^{[m]}_{d,i} = E^{[m]}_{d,i−1} + 0.9·c^{[m]}_{d,i} − q^dis,[m]_{d,i}/0.9 ,  1200 ≤ E^{[m]} ≤ 10800
        E^{[m]}_{d,6m} = E_{d,6m}（上一已提交链末态）
(AD-5)  分段线性化（LP 无损，§3.9 L5）：u^+_{d,i} ≥ b_{d,i} − q_{d,i} ， u^−_{d,i} ≥ q_{d,i} − b_{d,i} ， u^+, u^− ≥ 0
```

- **为何只提交 `D_m`**：`R_m` 的尾部（`i > 6(m+1)`）是**前视**（roll-horizon look-ahead），用于避免「段末近视」；
  它在后继层会被重优化，**不进入交付**（`AS11` 的「最终量由最后支配时刻取值」）。
- **`q_em` 为什么不在本层**：本层余额已由 `s ≥ 0` 闭合，`q_em ≡ 0`；更强地，把 `q_em` 加入本层变量也不会被启用（§3.9 L1）。
  实际结算层的 `q_em` 由**预报误差**产生（§3.5）。
- **调整层目标为何是偏差而非总费用**：`T1` 把 `C_plan = Σp·b` 固化在计划层（`b` 已定），
  本层能影响的只有 `C_adj` 与（通过 `q` 影响结算的）`C_em`；在确定性口径下本层预报即最优代理、`q_em` 的预报期望为 0，
  故 `(AD-3)` 即「该层剩余时段的偏差结算 + 紧急购电成本（=0）」的落地（与 `assumptions.md` §5.3 一致）。
  **副产物**：reading A 下该层**没有**「用更新预报少买电」的动机（`q = b` 是费用最优点），
  这正是团队 `T2` 要求用 `M7·D2-B`/`M7·D2-C` 量化题面歧义的原因（§4.2、§6 局限 3）。

### 3.5 实际结算层 `(ST_d)`（AS08，事后闭式）

给定已提交的 `q, c, q_dis` 与附件 2 实际值，结算层保留 `q^em ≥ 0` 与 `s' ∈ [0, PV^act·Δt]` 作为变量，满足

```
(ST-1)  q_{d,i} + q^em_{d,i} + PV^act_{d,i}·Δt + q_dis_{d,i} = L_{d,i}·Δt + c_{d,i} + s'_{d,i}        ∀i
(ST-2)  q^em_{d,i} ≥ 0 ； 0 ≤ s'_{d,i} ≤ PV^act_{d,i}·Δt
```

`(ST-1)` 的右端只含已提交量与参数，故该系统有**唯一解**（互补结构）：

```
(ST-3)  记 r_{d,i} = q_{d,i} + q_dis_{d,i} + PV^act_{d,i}·Δt − L_{d,i}·Δt − c_{d,i}
        s'_{d,i} = max(0, r_{d,i}) ； q^em_{d,i} = max(0, −r_{d,i})
```

- **可行性（`s' ≤ PV^act·Δt`）自动成立**：由本层提交时的层内余额与 `s^{[ν(i)]} ≤ Π_{ν(i)}[PV]·Δt` 得
  `q + q_dis ≤ L·Δt + c`，故 `r_{d,i} ≤ PV^act·Δt`（§3.9 L3；探针 14 天最大越界 `6.8e-13`）。
- **供电可靠性（题面 H1）自动蕴含**：`q + q_em + q_dis + (PV^act·Δt − s') = L·Δt + c ≥ L·Δt`（因 `c ≥ 0`），
  **微网供给 ≥ 负载**恒成立，无需另加不等式；不采用「净供给 ≥ 负载」弱口径（`AS08` 备选 B 已否）。
- **`q_em` 仅补足缺口、不用于充电**：`(ST-3)` 中 `q_em > 0` 的时段必有 `r < 0`，且同层 `s' = 0`；
  在最优解处 `c` 与 `q_em` 同为正的时段数应由 sanity 统计并期望为 0（`AS08` 备选 A 的落地）。

### 3.6 目标函数与量纲（B7-1）

```
(R6a)  C_plan = Σ_{d,i} p_i · b_{d,i}
(R6b)  C_adj  = Σ_{d,i} [ β_def·p_i·(b_{d,i} − q_{d,i})^+ + β_over·p_i·(q_{d,i} − b_{d,i})^+ ] ,  β_def = 0.5、β_over = 1.5
(R6c)  C_em   = Σ_{d,i} α_em · p_i · q^em_{d,i} ,  α_em = 5
(R6d)  C_total = C_plan + C_em + C_adj        （T1 主口径；三项可分别审计）
```

量纲：`[元/kWh] × [kWh] = 元`。因 `b/q/q_em` 已是 kWh（§3.1），**全文禁止出现 `p·b·Δt`、`α_em·p·q_em·Δt`、`β·p·Δq·Δt`**
（prob01 v001 曾出现的 `p·b·Δt` 口径对本问失效，团队 D9）。误乘 Δt 会使费用整体偏离 6 倍：交付期应为 `10^7 元`、单日 `10^4 元`；
单日落入 `10^3 元` 即硬错误信号（`B3-5`、§3.12）。

### 3.7 储能状态转移与两侧功率约束（AS12 + D10 口径丙 + 勘误 E1）

```
(R7a)  充电：并网点侧 c/Δt ≤ P_max ；电池侧 η_ch·c/Δt ≤ P_max
       ⇒ 0 ≤ c ≤ min(P_max·Δt, P_max·Δt/η_ch) = min(833.3333, 925.9259) = 833.3333 kWh
(R7b)  放电：并网点侧 q_dis/Δt ≤ P_max ；电池侧 q_dis/(η_dis·Δt) ≤ P_max
       ⇒ 0 ≤ q_dis ≤ min(P_max·Δt, P_max·Δt·η_dis) = min(833.3333, 750.0000) = 750.0000 kWh
(R7c)  无自放电（AS17）： E_i = E_{i−1} + η_ch·c_i − q_dis_i/η_dis
```

偏差方向：只取「并网点侧」（`q_dis ≤ 833.33`）会让电池侧放电功率达 `833.33/0.9/Δt = 5555.56 kW`（超题面 11.1%）；
只取「电池侧」（`c ≤ 925.93`）会让并网点充电功率超限。取交集后两侧均 ≤ 5000 kW；sanity 须**同时换算两侧功率**核对（E1 沿用纪律）。
「5000 kW 作用侧」是 `team_decision`（D10 口径丙），**三个文献池均无一条涉及，不得包装为文献支持**（C4）。

### 3.8 结构恒等式（B3-3，逐日 + 全期两口径）

对第 `d` 天，记 `N_d = Σ_i (L_{d,i} − PV^act_{d,i})·Δt`（实际净负荷电量）。对 `(R7c)` 求和并代入 `(ST-1)`：

```
(I1d)  Σ_i q_dis_{d,i} = η_ch·η_dis·Σ_i c_{d,i} − η_dis·(E_{d,144} − E_{d,0})
(I2d)  Σ_i q_{d,i} = N_d + Σ_i s'_{d,i} + (1 − η_ch·η_dis)·Σ_i c_{d,i}
                     + η_dis·(E_{d,144} − E_{d,0}) − Σ_i q^em_{d,i}
(I3d)  费用分解： C_total,d = C_plan,d + C_adj,d + C_em,d ，且 C_adj,d = 0.5·Σp(b−q)^+ + 1.5·Σp(q−b)^+ 两段分别可复算
(I4d)  跨日状态闭合： E_{d,0} = E_{d−1,144}（逐位，≤1e-6）； E_{1/1,0} = 6000
(I5d)  状态转移闭合： |E_{d,i} − E_{d,i−1} − 0.9·c_{d,i} + q_dis_{d,i}/0.9| ≤ 1e-6
(I6d)  结算平衡： |q + q^em + PV^act·Δt + q_dis − L·Δt − c − s'| ≤ 1e-6
```

全期/交付期切片：对 `d` 求和时逐日状态项望远镜相消，

```
(I2req) Σ_{D_req, i} q = N_req + Σ_{D_req} s' + 0.19·Σ_{D_req} c + η_dis·(E_{12/31,144} − E_{2/1,0}) − Σ_{D_req} q^em
```

`(I1d)–(I6d)` 与 §3.9 的 L1–L6 共同构成**不依赖求解器**的结构性检验；`D_req` 与 `D_full` 的统计**必须分别给出**（B3-4），
**禁止**把两个口径的数混用或只报其一（承接 prob02 勘误 R1 的口径纪律）。
（注：`(I2d)` 用**最终量 `q`**，而 `(I1d)` 的状态链只由提交的 `c/q_dis` 决定；两者均由 §3.10 的算法给出，与 §3.9 F2 一致。）

### 3.9 引理与命题（解析依据）

#### L1（决策层 `q_em` 恒不激活）

设 `α_em = 5 > β_over = 1.5`、`q` 无上界。任一决策层（计划层无 `q_em`；调整层把 `q_em` 加入余额时）的最优解都取 `q^em ≡ 0`。
**证明**：若某层某时段有 `q^em = δ > 0`，构造 `q' = q + δ`、`q'^em = 0`，其余不变：层内余额不变，`q' ≥ 0`；
目标变化为偏差项最多 `+β_over·p·δ = 1.5pδ` 而紧急项减少 `5pδ`，净变化 `≤ −3.5pδ < 0`，严格改进。∎
**推论**：`q_em` 只能由**结算层**的预报误差产生（§3.5）；表 3 非零不是「购电上限激活」机制（勿与 prob02 R5 混淆）。

#### L2（结算层唯一确定）

给定 `q, c, q_dis` 与实际值，`(ST-1)+(ST-2)` 的解唯一，即 `(ST-3)`。
**证明**：`(ST-1)` 给出 `s' − q^em = r`（常数）；`s', q^em ≥ 0` 且 `s' ≤ PV^act·Δt`（由 L3）。
若 `r ≥ 0` 则 `q^em = 0`、`s' = r`；若 `r < 0` 则 `s' = 0`、`q^em = −r`。∎
**含义**：`M1` 的结算层是**闭式映射**而非独立优化；实现无需在此调用求解器。

#### L3（结算层弃光上界自动成立）

由 `(AD-4)` 与 `s^{[ν(i)]} ≤ Π_{ν(i)}[PV]·Δt` 得 `q_{d,i} + q_dis_{d,i} ≤ L_{d,i}Δt + c_{d,i}`，故
`r_{d,i} = q + q_dis + PV^act·Δt − LΔt − c ≤ PV^act·Δt`，即 `s' ≤ PV^act·Δt` **无需额外约束**。∎
（探针 14 天最大越界 `6.8e-13 kWh`，属浮点噪声。）

#### L4（可行性完成引理：任何层都可行）

对任意已提交状态 `E ∈ [1200, 10800]` 与任一预报曲线，调整层 `(AD_{d,m})` 总可行（`q` 无上界、`s` 只吸收盈余）。
**构造**：取 `c = 0`、`q_dis = 0`、`s = max(0, PV·Δt − LΔt)`、`q = max(0, LΔt − PV·Δt)`，则 `(AD-4)` 余额成立；
若该步 `E` 低于 `E_min`（无充电时不会，因 `E` 只减不增）可令 `c > 0` 并用 `q` 吸收，`q ≥ 0` 无上界保证可行。∎
**含义**：`M1` 的四次求解**不会**出现不可行；若实测不可行，应判为实现错误而非模型不可行。

#### L5（分段线性化 LP 无损）

`(AD-3)` 的目标对 `u^+`、`u^−` 的系数均为正（`β_def, β_over > 0`），约束为 `u^+ ≥ b−q`、`u^− ≥ q−b`。故在**任一最优解**处
`u^+ = (b−q)^+`、`u^− = (q−b)^+`（取紧），且 `u^+·u^− = 0`。加二元变量的 `M6` 与原 LP **最优值相同**。∎
（探针：单层 36 时段 LP 与 72 二元 MILP 目标相对差 `9.1e-13`，`mip_gap = 0`，辅助量紧性残差 `0`。）

#### L6（完全信息下界 = prob02 模型，跨问锚点）

`M3`（0:00 已知全天附件 2 实际值、`q ≡ b`、`q_em ≡ 0`、单阶段）在 `D_full`、`E_init = 6000`、终端自由、无购电上限、
同设备约束下的可行域与目标与 prob02 accepted `formulation_v001` 的 `(P2)`（取 `q_em ≡ 0`）**逐项相同**；
由 prob02 定理 T1（`q_em ≡ 0` 在最优解成立）两者**最优值相同**。
故 `M3` 应复现 prob02 accepted computation 的**全期 13,758,182.573724 元 / 交付期 12,233,050.830708 元**（相对差 ≤1e-6）。∎
**含义**：`M3` 是**跨问独立锚点**（`C4` 的「信息价值」对照），`ablation`/`sanity` 可据此校验实现，而不必把上游数值当作本问交付值。

#### P1（`C_total(M1)` 对信息集单调）

预期 `C_total(M3) ≤ C_total(M1) ≤ C_total(M4)`（`C4` 预注册）。**不强称定理**：
`M1` 的可行策略集不是 `M3` 可行集的子集（目标中含偏差支付），故方向需数值验证；
`M4 ⊆ M1`（`M1` 可取「所有调整层维持 `q = b` 且复现计划轨迹」，但受层内余额与 SOC 约束限制，并非总能复现）。
**探针（14 天窗口，非交付值）**：`M3 711,975.8724 ≤ M1 761,150.7115 ≤ M4 780,077.2562 元`，首日
`59,614.2541 ≤ 62,349.8024 ≤ 65,647.8610 元`，**累计前缀口径处处成立**。
**注意**：三条链的状态在首日后分叉，**跨链逐日增量不可比**，比较必须用同一起点或累计口径（否则会误判方向）。
若正式结果方向反转，按 `C4` 要求给出机制解释并登记，否则该对照作废。

### 3.10 完整模型 `M1`（三层顺序向前递推；可执行伪码）

```
M1:
  E_real ← E_init = 6000
  for d in D_full (2025-01-01 … 12-31):
      # (1) 计划层：用 Π_0（全天）与 E_{d−1,144}
      solve (PL_d) with Π_0[PV]_{d,·}, E^PL_{d,0} = E_real  →  b_{d,·}, c^PL, q^dis,PL, s^PL, E^PL
      for i in D_0:  q_{d,i} ← b_{d,i} ; c_{d,i} ← c^PL_{d,i} ; q_dis_{d,i} ← q^dis,PL_{d,i} ; E_{d,i} ← E^PL_{d,i}
      # (2) 三个调整层：用 Π_m 与上一提交链末态；b 已固定；对 R_m 前视、只提交 D_m
      for m in (6, 12, 18):
          solve (AD_{d,m}) with Π_m[PV]_{d,·}, E^{[m]}_{d,6m} = E_{d,6m}  →  q^{[m]}, c^{[m]}, q^dis,[m], s^{[m]}, E^{[m]}
          for i in D_m:  q_{d,i} ← q^{[m]}_{d,i} ; c_{d,i} ← c^{[m]}_{d,i} ; q_dis_{d,i} ← q^dis,[m]_{d,i} ; E_{d,i} ← E^{[m]}_{d,i}
      # (3) 实际结算：闭式 (ST-3)（用 PV^act、L）
      r_{d,i} ← q_{d,i} + q_dis_{d,i} + PV^act_{d,i}·Δt − L_{d,i}·Δt − c_{d,i}      ∀i
      s'_{d,i} ← max(0, r_{d,i}) ; q^em_{d,i} ← max(0, −r_{d,i})                      ∀i
      E_real ← E_{d,144}
  C_plan, C_adj, C_em ← (R6a)/(R6b)/(R6c) ； C_total ← (R6d)
  报告： D_req 与 D_full 两口径分别汇总（B3-4）
```

**信息集审计要点（sanity L1）**：计划层输入只含 `Π_0`、不含 `PV^act`；`AD_{d,m}` 输入只含 `Π_m` 与已提交状态、
不含 `i > 6m` 的实际值；结算层是唯一的 `PV^act` 入口（F2）。**各层输入指纹与层目标值必须落盘**。

### 3.12 量级自检与构造界（B3-5）

- **下界（交付期）**：由 `(I2req)` 与 `p ≥ p_min`（附件 1 电价 ∈ [0.3713, 1.3952] 元/kWh）：


  `C_total ≥ 0.3713 × [17,939,189.4950 + 0.9×(1200 − 7950)] = 0.3713 × 17,933,114.5 ≈ 6.66×10^6 元`（量级 `10^6–10^7`）。

  得 `C_total ≤ C_plan = Σp·max(0, (L − PV^act)Δt)`（**计划即实际、无偏差、无紧急**），量级 `10^7 元`。

  与 `assumptions.md` §6 的支配预报 deficit/surplus 量级上界一致。

## 4. 候选建模/求解方案与 `M1`–`M8` 定义

### 4.1 候选方案（≥3，覆盖精确/启发式/混合；规模与利弊在**看到计算结果前**固定）

> 以下规模均为 §3.11 的量级；利弊在跑数前固定，不随后续结果调整。

#### 候选 A：三层顺序向前递推 LP（`M1`；精确，**推荐主路径**）

- **核心思想**：按 §3.10 逐日向前递推，天内 4 次 LP（计划 + 3 调整）+ 闭式结算；全部用 CPU HiGHS。
- **规模量级**：单次 LP ≤ 756 变量 / ≤ 288 等式；全年 1,460 次调用；内存 < 100 MB。
- **优点**：**唯一同时满足** T1（计划层目标）、AS07 非预期性与不回溯、AS06 四个决策时刻；线性、无 Big-M、无整数间隙；各层可审计。
- **缺点**：层次目标无法合并为单次 LP（F1），实现须显式管理「已提交链」与层间状态传递；滚动近视可能使加密对照非单调（F4）。
- **失效条件**：若团队改「计划 = 最终」（`M3`/`M4` 口径）或允许联合求解，本路线的信息结构前提失效，须重裁。
- **适用/不适用**：本问**完全适用**；prob04-3（波动电价）在价格可观测性（A8）裁定后沿用同一递推。

#### 候选 B：逐日解耦 + 跨日状态递推（`M2a`；精确分解口径）

- **核心思想**：把 §3.10 的一天四层独立封装，`E_{d,0}` 由前一日提交链末态传入。
- **规模量级**：与候选 A 完全相同（365 × 4 次 LP）。
- **优点**：实现边界清晰、单日可独立调试（本机 `memory_slots = 1`，不得并行以保 B5 公平）。
- **缺点**：与候选 A **算法同构**（§0.4 F1/F6），不是独立实现；`C2` 因此只是自洽检查。
- **失效条件**：与候选 A 同。
- **适用/不适用**：作为 `M1` 的**自洽/结构检查**适用；**不得**充当「分解等价性」的独立证据（D2）。

#### 候选 C：偏差项的互补 MILP 精确化（`M6`；精确 oracle）

- **核心思想**：对 `i ∈ R_m` 引入 `z^+_{d,i}, z^−_{d,i} ∈ {0,1}`，`u^+ ≤ b·z^+`、`u^− ≤ q^max·z^−`、`z^+ + z^− ≤ 1`，其余同 `(AD)`。
- **规模量级**：单日追加 432 二元；4 个指定日 oracle 为 `2,232 + 432` 变量的日尺度 MILP；全年 MILP 若做则 1,460 层 × 二元不可行，须降级。
- **优点**：把 `L5` 从引理变成硬约束，作为 LP 的独立复核；Big-M **由模型推导**（§0.4 F8），无「足够大的数」。
- **缺点**：全年 MILP 在 60 s 内不可能证明最优；只作 oracle，不作主路径。
- **失效条件**：Big-M 取大（如 1e6）会削弱松弛；`η`/`P_max`/`E` 界变更而未同步 Big-M 会误删可行解。
- **适用/不适用**：作验证 oracle 适用；**不作**主计算路径（`B2` 允许降级为「4 天 oracle + 全年 LP 损失界」，须登记）。

#### 候选 D：SOC 离散化动态规划（DP；混合）

- **核心思想**：把 `E` 按步长 `ΔE` 离散，逐时段递推转移代价（每段解析求最优 `c/q_dis/s/q`），得网格受限下的精确最优。
- **规模量级**：状态数 `(E_max−E_min)/ΔE + 1`；144 时段 × 状态数 × 转移枚举；无求解器调用。
- **优点**：不依赖 LP 求解器；可作为**独立数值复核**（网格越细越接近 LP）；可解释（值函数）。
- **缺点**：`M1` 的层次目标（计划层与调整层目标不同）使 DP 的状态值函数**难以表达**「先计划后调整」的层次结构；跨层状态耦合使实现复杂。
- **失效条件**：`ΔE` 过粗会使偏差 >1%；层次目标需额外层级 DP/嵌套。
- **适用/不适用**：**不适合**作为主路径；只在剔除层次目标的单层口径（如 `M3`/`M4`）下作交叉校验（prob01 ablation 的 DP 经验可复用，但须注明口径差异）。

#### 候选 E：价格阈值规则式调整启发式（启发式）

- **核心思想**：按电价分位划低价/高价段，低价充电、高价放电；调整层按「缺口即补、盈余即弃」规则生成 `q`。
- **规模量级**：无优化变量；`O(T log T)` + `O(T)`，毫秒级。
- **优点**：不依赖求解器、可复现、给出可解释基线与 regret 参考。
- **缺点**：无最优性保证；对阈值、初值与效率敏感；无法处理 `(PL-0a)` 的「全天最小购电费」结构。
- **失效条件**：价格曲线非 TOU 型（prob04 实时电价）时 regret 显著放大。
- **适用/不适用**：作为**降级/对照基线**适用；不得作为交付口径。

#### 候选 F：时间聚合—降尺度启发式（aggregation/disaggregation；启发式）

- **核心思想**：把 144 个 10 分钟时段聚合为 24 个整点或 6 个 4 小时块求解，再按组内规则恢复 10 分钟决策并做可行性修复。
- **规模量级**：聚合模型变量降低 6–24 倍；恢复与修复 `O(T)`。
- **优点**：求解快、内存省；可直接对照表 2 的 4 小时块口径。
- **缺点**：无最优性保证；组内净负荷符号翻转（`PV > L` 与 `PV < L` 混在同一组）时修复易破坏 SOC 轨迹。
- **失效条件**：本数据 `PV^act ∈ [0, 10216.20] kW`、日内波动剧烈，组内翻转常见 → 修复失败概率高。
- **适用/不适用**：作为降级/对照适用；不作交付口径。

#### 候选 G：两阶段随机 / 滚动 MPC（混合；**本问不适用**）

- **核心思想**：对预报误差建概率模型，做两阶段随机规划或 MPC 滚动。
- **规模量级**：场景数 × 时段数（场景爆炸）。
- **优点**：更贴近现实、可给风险度量。
- **缺点**：**本问无预报误差分布来源**（`AS15`/`AS16` 为确定性口径；附件 2 是实际值、附件 3 是预报，无误差样本接口）；
  引入分布属越界（`AS06` 备选 C 已否）。
- **失效条件**：需要团队提供误差分布并修改 `AS16`。
- **适用/不适用**：**本问不采用**；仅在 D4 若要非退化 `PLAN-EXP` 时作为团队裁定的前置条件。

## 6. 局限与不适用

1. **确定性口径（AS15/AS16）**：不处理预报误差分布；`PLAN-EXP` 在同信息集下退化为 `min Σp·b`（F5/D4）；`C_em` 只由实际值事后产生。
2. **降尺度不保块内能量（T3）**：`(R1a/R1b)` 的块能量为 `(2.5A_{k−1} + 3.5A_k)/6 ≠ A_k·1 h`；论文与图注**必须显式披露**，
   并给出对 `M7·D5-B` 的能量偏差统计。探针 RMSE（269.50 / 303.92 vs 580.62 kW）**只作假设裁定诊断，不得作交付数值**。
3. **reading A 的激励结构（T2）**：主口径下 `C_plan` 按 `b` 全额计价，调整层只最小化偏差，
   故调整**不会**因更新预报而少买电（`q = b` 是费用最优点）；调整的真实价值在于**避免 5p 的紧急购电**与维持可行性。
   读法 B/C 的差额必须由 `M7·D2-B`/`M7·D2-C` 全量给出并在论文披露（`C7`）。**不得**只报主口径就宣称稳健。
4. **无购电上限（AS14）**：可能出现高购电尖峰；若团队引入上限，须登记数值来源并按 `β ∈ (4218.75, 4375.00] kW` 表述，
   **不得**移植 prob02 的 A17 结论（R5）。
5. **弃光界 `s ≤ Π_m[PV]·Δt` 偏松**：本问 `s` 只用于闭合盈余，不构成套利；prob04 若引入售电，**必须先收紧为物理盈余**（prob02 A-DR5 的非物理售电前车之鉴）。
6. **跨年项丢弃（AS05 第 4 条）**：12-31 的 6:00/12:00/18:00 层分别丢弃 6/12/18 个预报项；论文须说明「不消费、不截断、不外推」。
7. **`M5` 的数据接口限制**：附件 3 只在 0/6/12/18 发布，故「加密决策时刻」只能用**最近一次已发布预报**（无新信息）；
   「加密发布」需构造不存在的数据 → 不作（D5）。
8. **LP 退化与 tie-breaking**：调整层目标在「可复现计划轨迹」处多重最优，可使 `M5` 每 1 小时反而更贵（F4，14 天 +83.47 元）；
   `C5` 的单调性须先固定 tie-breaking 规则（D3）。同理 `M1` 的最优**轨迹**可能不唯一，sanity 以**约束残差 + 恒等式 + 目标值 + 交付表**为准，
   **不比对逐点解的唯一性**（承接 prob01/prob02 纪律）。
9. **跨链逐日增量不可比**：`M1`/`M3`/`M4` 的状态链在首日后分叉，`C4` 的比较必须用同一起点或累计口径（P1 附注）。
10. **`M2a` 不是独立实现（F6）**：`C2` 是结构性恒等式；实现级独立证据由 `M8`（`C3`）承担（D2）。
11. **不显式禁止同时充放电（AS07 简化）**：由正的吞吐成本（`1 − η_ch·η_dis = 0.19`）可知最优解不取同充放，
    sanity 须统计同充放时段数并期望为 0。
12. **1 月预热期的口径依赖**：交付期首日 `E_{2/1,0}` 由模型在全年轨迹上给出（prob02 实测 7950.00 kWh），不是 6000；
    论文须说明 1 月为预热期，且与 prob01 的「单日周期端点恒 6000」显式区分（勘误 R1）。

## 待团队选定的决策点

### D1 求解路线（主口径）
- 备选 A：三层顺序向前递推 LP（`M1`，HiGHS）。规模：单次 ≤ 756 变量 / ≤ 288 等式，全年 1,460 次 LP。优点：唯一同时满足 T1、`AS07` 非预期性与不回溯；层内全局最优 + 对偶界；无 Big-M/整数间隙。缺点：需显式管理已提交链与层间状态；层次目标不可合并。适用条件：本问及一切确定性分层线性口径。
- 备选 B：逐日解耦 + 跨日状态递推（`M2a`）。规模：与 A 相同。优点：实现边界清晰、单日可独立调试。缺点：与 A 算法同构，不构成独立证据（F6）。适用条件：作为自洽检查或降级路径。
- 备选 C：三层联合 LP（把计划层与调整层并为一次 LP，用后验预报或实际值）。规模：单日 ≈1,000–2,000 变量。优点：实现最简。缺点：**违反 `AS07`/H11**（计划层看到后验信息），且两个层次目标不可加权。适用条件：**不采用**，仅作理论上界讨论。
- 备选 D：SOC 离散化 DP。规模：状态数 × 144。优点：不依赖求解器、可解释。缺点：难以表达「先计划后调整」的层次目标。适用条件：仅作单层口径的交叉校验。
- **推荐：A**。理由：本问分层线性、规模小，A 给出层内全局最优且是唯一满足信息结构的路线；`L4`/`L5` 消解了「不可行」与「需要二元变量」的疑虑。比较标准：信息结构合规性（硬）> 最优性保证 > 硬约束满足度 > 运行预算 > 解释性 > 鲁棒性。
