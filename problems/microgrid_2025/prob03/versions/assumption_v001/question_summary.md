## 1. 问题与目标

在题面给定的**确定性**数据下，为小区微网 + 储能系统制定 2025 年逐 10 分钟的**购电与充放电策略**，使总购电费用最小：

- **输入（本问只用）**：`data/附件1.xlsx` 的**电价列**（逐日重复的 144 点曲线）；`data/附件2.xlsx` 的小区负载与光伏**实际**功率；
  `data/附件3.xlsx` 的**整点光伏预报**（发布时刻 0:00/6:00/12:00/18:00，提前量 1–24 h）；`data/附件5/result3.xlsx` 模板（只读）。
- **决策结构（题面要求）**：0:00 依据当日 0:00 预报制定**全天计划购电量 `b`**；6:00/12:00/18:00 依据各自时刻的预报**调整**购电量，
  得到最终购电量 `q`（替代量口径）；实际执行时若供电不足，向外网**紧急购电** `q_em`（电价的 5 倍）。
- **费用口径**：`C_total = C_plan + C_em + C_adj`，其中
  `C_plan = Σ p·b`、`C_em = Σ 5p·q_em`、
  `C_adj = Σ [0.5·p·(b−q)⁺ + 1.5·p·(q−b)⁺]`（双向分段，两段**均为成本项**）。
- **输出**：表 1（4 个指定日期 × 六个 10 分钟时段：最终购电量、全天购电量、全天购电费＝`C_total`，另给三项分项）、
  表 2（6 个 4 小时块的最终充电量与放电量、0:00/24:00 储电量）、表 3（各指定日紧急购电区间与电量），
  以及完整交付件 `results/…_run003/result3.xlsx` 的四个工作表。
- **范围**：`D_full = 2025-01-01…12-31`（365 天，1 月为储能预热期）；交付与报告口径
  `D_req = 2025-02-01…12-31`（334 天）。两个口径**必须分别给出**（团队 B3-4），论文主表用 `D_req`。

## 4. 模型、公式与算法

完整推导见 `formulations/formulation_v001/formulation.md`；方法学细节与实现映射见 `implementation.md`。核心如下。

**索引与单位**：`Δt = 1/6 h`；`i = 1…144`（10 分钟时段，左端点口径）；`m ∈ {0,6,12,18}`；
`ν(i) = 6·⌊(i−1)/36⌋` 给出**唯一**支配决策时刻（无需离散选择变量，模型保持 LP）。
决策变量 `b, q, q_em, c, q_dis, s, s'` 与状态 `E` 均为 kWh，故目标与平衡式**不再乘 `Δt`**。

**三层顺序向前递推（`M1`）**

```
计划层（0:00，用 Π_0 全天预报；团队 T1 主口径）
  min Σ_i p_i·b_{d,i}
  s.t. b + Π_0[PV]·Δt + q_dis^PL = L·Δt + c^PL + s^PL
       0 ≤ c^PL ≤ 833.3333, 0 ≤ q_dis^PL ≤ 750.0000, 0 ≤ s^PL ≤ Π_0[PV]·Δt
       E^PL_i = E^PL_{i−1} + 0.9·c^PL − q_dis^PL/0.9,  1200 ≤ E^PL ≤ 10800
       E^PL_{d,0} = E_{d−1,144}（前一日已提交链末态）；E^PL_{1/1,0} = 6000；E^PL_{12/31,144} 自由
调整层（m = 6:00/12:00/18:00，顺序求解；只提交 D_m，其余为前视）
  min Σ_{i∈R_m} [0.5·p_i·u⁺_i + 1.5·p_i·u⁻_i]
  s.t. q^{[m]} + Π_m[PV]·Δt + q_dis^{[m]} = L·Δt + c^{[m]} + s^{[m]}
       u⁺ ≥ b − q,  u⁻ ≥ q − b,  u⁺,u⁻ ≥ 0 ；E^{[m]}_{d,6m} = E_{d,6m}
实际结算层（事后闭式，唯一解）
  r = q + q_dis + PV^act·Δt − L·Δt − c ；s' = max(0, r) ；q_em = max(0, −r)
目标
  C_plan = Σ p·b ；C_adj = Σ[0.5p(b−q)⁺ + 1.5p(q−b)⁺] ；C_em = Σ 5p·q_em ；C_total = 三者之和
```

**储能与两侧功率约束（D10 口径丙）**：并网点侧与电池侧**同时** ≤ 5000 kW ⇒
`0 ≤ c ≤ min(5000·Δt, 5000·Δt/η_ch) = 833.3333 kWh`、`0 ≤ q_dis ≤ min(5000·Δt, 5000·Δt·η_dis) = 750.0000 kWh`；
`E_i = E_{i−1} + 0.9·c − q_dis/0.9`，`E ∈ [1200, 10800]`，终端自由，不计自放电。

**解析依据（引理，`formulation` §3.9）**

- **L1**：`α_em = 5 > β_over = 1.5` 且 `q` 无上界 ⇒ **`q_em` 在决策层恒不激活**，`q_em` 只能由**结算层的预报误差**产生
  （**不得**与本问的「购电上限激活」混为一谈，承接 prob02 R5 纪律）。
- **L2/L3**：结算层为闭式、`s' ≤ PV^act·Δt` 自动成立，供电可靠性 `q + q_em + q_dis + (PV^act·Δt − s') = L·Δt + c ≥ L·Δt` 自动蕴含。
- **L4/L5**：各层**必可行**；分段线性化 `u⁺/u⁻` 在正系数下取紧 ⇒ **LP 松弛无损**（`M6` 的 MILP oracle 实测最大相对差 3e-12）。
- **L6**：`M3`（完全信息）与 prob02 accepted `(P2)` **逐项相同** ⇒ 跨问独立锚点（团队 F7）。

**tie-breaking（团队 T7/T9，提交解口径）**：所有层、所有模型 `M1–M8` 一律先取**主目标最优**，再在其最优面上取
`min Σ_t (c + q_dis)`（**字典序**实现，即 T7-1 在 `ε→0⁺` 的精确形式）；字面加权式只作逐层诊断对照（`t7_tiebreak.json`）。

**求解**：`scipy.optimize.linprog(method='highs')`，CPU，全年 **1,460 次小 LP**（每天 4 层），单层 ≤ 756 变量；
**本问不涉及 GPU**（`gpu_required = false`）。

### 6.4 机制解释（结果不能只报数字）

- **紧急购电非零的成因（F2/F3/L1）**：决策层只用附件 3 预报、结算层用附件 2 **实际**光伏，预报误差必然造成缺口 ⇒
  `Σq_em = 391,274.49 kWh`（交付期）。**不得**写成「购电上限激活了紧急购电」（本问无购电上限，R5 不触发）。
- **`q_em` 与 `c` 同为正的时段数 = 5,070（9.6461%）不违反 D7-A（团队勘误 R12）**：`c` 由普通购电 `q` 支付、`q_em` 只补负载缺口；
  最小可复现示例 = **2025-01-01 6:20–6:30**（period_index 37）。该机制恒等式 `q_em = Π − 预报余额 − PV^act + s` 在 52,560 时段全部成立（max 4.55e-13）。
- **日边界储电量恒为下限 1200 kWh（E8 / R18，365/365 命中，唯一取值数 = 1）**：源于「计划层单日 LP + 目标 `min Σp·b` + 终端自由
  ⇒ 跨日库存边际价值为 0」，是**结构性涌现结果**，**不是题面要求**（「0:00 与 24:00 储电量相同」只出现在问题 1）、**也不是缺陷**；
