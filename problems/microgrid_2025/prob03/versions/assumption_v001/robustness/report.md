### 4.1 S4 失败的精确归因（**判据不事后修改**）

- **事实**：S4 的六项子判据中，五项通过，唯一违反的是**跨族均值一致性**；
  该违反**完全由 σ=10% 的 `noise_white_10` 与三个 σ=5% 族并列比较造成**：
  - 含 σ=10% 的族间均值差 = `(16,172,668.76 − 15,111,994.80) / 14,540,616.34` = **7.2946% > 3%**；
  - 仅比较三个 **同为 σ=5%** 的族 = `(15,121,308.69 − 15,111,994.80) / 14,540,616.34` = **0.0641% ≪ 3%**。
- **性质**：预注册的 S4/K4 把「**族内离散度**（std/CI/`z`）」与「**跨 σ 档的族间均值一致性**」放在同一条判据里，
  但四族的设计扰动幅度本就不同（σ=5% vs σ=10%）且扰动结构不同（白噪声 vs 按日持续），
  因此「均值差 ≤ 3%」在**设计上必然随 σ 档位拉开**（§3.2 的偏差机制）。这是一条**判据口径设计债**，
  不是模型脆弱性的证据。
- **处置**：判据**不修改、不重算**；S4 的 FAIL 与 `stability_grade = 条件稳定` **原样**进入论文与
  后续 `sanity_check` Level 6（同 prob02 的 D-R1 纪律）。论文引用时：
  ① 不得据此表述「模型对噪声不稳定」；② 应表述为「**族内离散度 < 1%，但期望费用随预测偏差幅度系统性上移
  （σ=5% 约 +3.9%、σ=10% 约 +11.2%）**」；③ 若引「均值差 7.29%」，必须同时给出**同 σ 子集 0.0641%**，
  否则会被读成族间矛盾。见 §8 的 **DR-1**。

## 5. 稳定性结论

1. **费用量级与分解稳定**：全部 144 个受判样本交付期 `C_total ∈ [1.371e7, 1.625e7]` 元（`10^7` 量级），
   `C_plan + C_adj + C_em = C_total` 恒成立（残差 0.0）。
2. **机制定性稳定**：`Σq_em > 0`（最小 364,259 kWh）、`q = b`（`i ≤ 36`）、同充放 = 0、
   `q_em&c` 占比 ≤ 10.69% —— 在参数、求解器、噪声三族中**无一例外**。
3. **参数方向稳定**：六组 OAT 单调方向（含 `≤ 1e-6` 相对容差）在诊断区间内**全部不反转**；
   影响最大者为 `η`（±11%/+10% 档全期 ±1.78M 元），最小者为 `E_init`（交付期恒 0.0）。
4. **输入噪声**：族内离散度极小（相对标准差 ≤ 0.92%、95% CI 半宽 ≤ 0.36%、`|z| ≤ 2.55`），
   但**期望费用有系统性上移**（σ=5% ≈ +3.9%、σ=10% ≈ +11.2%），方向与机制（预报误差 + 无对冲）一致。
5. **求解器/最优面**：链级差异 ≤ 0.135%（`highs-ipm`），≤ 0.011%（`presolve=False`）；
   属团队 T7-6 已登记的口径敏感性，**不是**实现缺陷。
6. **结构情景**：决策层可行上界夹逼 `(4375, 5000] kW`；终端 = 6000 kWh 仅 +0.0229%。

**适用边界（论文/后续阶段的适用范围声明）**：

- 本阶段的稳定性判定适用于**本问参数网格**：`η ∈ [0.72, 0.99]`、`α_em ∈ [4, 6]`、
  `β_def/β_over` 同比例 ±20%、`P_max ∈ [4000, 6000] kW`、`E ∈ [960, 12000] kWh`、
  `E_init ∈ [4800, 7200] kWh`；**外推超出网格须重算**。
- 噪声结论适用于**实现值相对预报的乘性偏差 ≤ 10%**（白噪声与按日持续两种结构）；
  **不构成真实预测误差的概率分布**（σ 来自诊断设定，非题面事实，也非文献标定），
  故「95% CI」只用于外推边界，**不得包装为真实误差分布的分位数**。
- **不覆盖**：自放电/静置损耗（`AS17`，改变状态转移需新建假设版本，本阶段只登记）；
  多日弃光变量 `s` 的更紧界（`A13`，本问无售电收益故非套利路径）；
  拟合/预报误差分布假设（`R11④` 的「量化对冲收益」属 `ablation`）。
- 结构族（`buy_cap` / `terminal`）属**结构发现**，其数值不得当作主口径费用，也不得与 `ablation`
  的 `M6`/`M6'` 数值互替（团队 `B5`/`D8-A`）；若两者对同一物理量的结论不一致，须在双方报告中显式登记冲突。
- **本阶段不改变 `M1` 的任何主结果**；`run003` 仍是唯一交付口径。
