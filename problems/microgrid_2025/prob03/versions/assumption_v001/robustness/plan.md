## 0. 适用性决定（先判定「哪类扰动适用、哪类不适用及理由」）

| 扰动类别 | 适用性 | 判定与理由 |
|---|---|---|
| 参数扰动（设备/经济参数） | **适用** | 确定性 LP 的全部系数都是题面硬参数或团队裁定值（`η`、`E` 界、`E_init`、`α_em`、`β_def/β_over`、`P_max`），可直接 OAT 扰动并给出数值区间。 |
| 输入扰动（负载/光伏/电价噪声） | **适用** | 附件 2 实际值只进结算层（formulation §0.4 F2），附件 1 电价、附件 2 负载同时进决策层；三类输入都应做随机扰动。 |
| 求解器压力 | **适用** | 团队 B5/T7-5 只允许 `M8` 在求解器设置上不同；本阶段用 `highs-ds`/`highs-ipm`/`presolve=False` 量化该差异的**链级量级**并与 T7-6 的 `1e-4` 口径敏感性对照。 |
| 结构约束压力（情景分析） | **适用** | 终端储电量（AS04）、外网购电上限（AS14）都是题面/团队口径的结构选择，用离散情景量化（结构变化不强行编码为百分比）。 |
| 初值扰动 | **适用（并入参数族）** | `E_init` 只出现在 2025-01-01 0:00；作为参数扰动 ±5/10/20% 处理。 |
| 随机初始化 | **不适用** | 模型为确定性 LP，求解器无随机源；不存在「偶然初始化」子类（`knowledge/robustness-ablation.md` 允许记录不适用）。 |
| Sobol / Morris 全局方差分解 | **不适用** | 本问**没有输入分布证据**（无负载/光伏误差分布接口，AS16 为确定性口径），Sobol 需独立输入分布与足够样本；强行赋分布属越界（同 D1-C 的否决理由）。 |

| `M7·D2-B/D2-C/D5-B`（口径读法对照） | **不在本阶段** | 团队 T2/T3 把结算读法与降尺度口径对比指派给 ablation（`M7` 族）；robustness 不重复，只引用。 |
| `M2b`（日初复位）/`M3`（完全信息） | **不在本阶段** | `M2b` 的跨日携带价值与 `M3` 的完全信息上界属团队 B2 的模型对照（ablation/sanity 已出数），robustness 不重跑。 |

> 结论：**本阶段不返回 `skipped`**，在适用的四类（参数、输入噪声、求解器、结构情景）中全部产出数值结果。

## 1. 与团队裁定/勘误的接口（效力高于本文默认做法）

1. **B6 边界**：本阶段只做参数扰动、输入噪声、求解器压力、结构约束压力；模型族与口径选择（B0–B5）不在本阶段重复。
2. **T7-1/T7-5/T7-6（tie-breaking）**：所有情景一律使用团队冻结的同一 tie-breaking 规则。本实验的**提交解**取
   T7 字典序实现（主目标最优面上吞吐量最小）；`--mode compact` 只跳过 T7 的 ② 字面加权式与 ④ 退化探测两个
   **诊断**环节（每层 LP 调用由 4 次降到 2 次，整批预算可控），提交解的定义与 `prob03_model._solve_with_tiebreak`
   的 ③ 逐位同解。**对账要求**：`baseline_full` 情景用未修改的四段式跑全年，与 `run003` 的
   `run_manifest.json` + `tables.json` + `t7_tiebreak.json` 逐项对账；`baseline`（compact）与 `run003` 的 9 项总量
   相对差须 ≤ `1e-6`。不满足则整批判失败（`EXIT_BASELINE_GATE_FAILED`）。
3. **T7-6 ③**：不得用不同 tie-break 的结果互相比对；本阶段的求解器族与全部噪声族共用同一规则，差异只来自
   求解器设置（B5 允许的唯一差异面）。
4. **R11–R13 披露义务**：`Σq_em>0`（R11/R12 的机制）、`periods_with_q_em_and_charge` 占比（R12）、跨问初始状态
   不可直接互比（R13）在本阶段作为**稳定性监控量**记录；R11 的「+18.863% 预报误差代价」方向在 S2 中受判。
5. **E6 口径**：本阶段同时输出**全期 `D_full`（365 天）**与**交付期 `D_req`（334 天）**两套口径，并逐项标注；
   `Σq`（最终购电量）与 `Σb`（计划购电量）分别列示，不混用。
6. **E7/T7-3**：`layers_with_unknown_multiplicity = 1`（2025-10-12 hour 18）为已登记的技术债边界；compact 模式下
   ④ 退化探测不跑，故 `probe_coverage < 1` 时退化类指标一律标注为「未探测」，**不得**把 compact 的 `0` 当作结论。
7. **AS04**：终端自由；`terminal_e_6000` 情景是 AS04 的验证建议，其差额在 prob03 的多日滚动结构下**重新实测**，
   不得沿用 prob02 的 `+2,217.08 元 / +0.018%`。
8. **AS14 / R5**：本问主口径**无购电上限**，R5 的 `β ∈ (4218.75, 4375.00] kW` 是 prob02 的 **`q_em` 激活阈值**登记，
   在 prob03 **不触发**。本阶段 `buy_cap` 扫掠给出的是**决策层可行/不可行分界**（不同口径），两者**不得混用**；
   若分界区间与 R5 区间不重叠，只**登记冲突点**，不判失败。
9. **AS17**：静置损耗/自放电未建模。本阶段**不新增**自放电情景（改变状态转移方程属建模口径变更，须新建假设版本），

## 2. 预注册核心结论 K1–K6（跑数前冻结）

> 主结果只出自 `M1`（B0）；robustness 不改变任何主结果，只判定「结论是否依赖脆弱参数、输入噪声或偶然初始化」。

- **K1（费用量级与口径）**：交付期 `C_total` 与 prob02 的 `10^7 元` 同阶；`C_total = C_plan + C_em + C_adj` 恒成立；
  所有受判样本的交付期 `C_total ∈ [3e6, 5e7] 元`（B3-5 量级带），单日费用为 `10^4` 元量级。
- **K2（紧急购电机制）**：`Σq_em > 0` 由「决策层用预报 / 结算层用实际」的缺口驱动（F2/F3、R11/R12）；全部受判样本
  满足 `q = b`（`i ≤ 36`，替代量口径）、同充放时段数 = 0、`q_em` 与 `c` 同时为正的时段占比 ≤ 15%。
- **K3（参数方向）**：`η` 上升不增费、`α_em` 上升不降费、`P_max` 上升不增费、`E_min` 上升（收紧）不降费、
  `E_max` 上升（放松）不增费、`β_def/β_over` 上升不降费；相对容差 `1e-6`。
- **K4（输入噪声）**：四族噪声（逐时段白噪声 σ=5%/10%、按日持续 σ=5%、按日持续含电价 σ=5%）下交付期 `C_total`
  的 95% 置信区间半宽 ≤ 5%，且族间均值差 ≤ 3%。
- **K5（求解器与实现）**：`highs-ds`（= scipy `highs` 默认）、`highs-ipm`、`presolve=False` 三种设置下模型仍可行、
  四条恒等式在容差内；链级费用差异**如实登记**为 LP 最优面选择 + 跨日初值传播的口径敏感性（T7-6 同机制），
  相对量级 ≤ 1%。
- **K6（结构情景）**：外网购电上限扫掠给出决策层可行/不可行分界（若无分界则如实登记全域可行/不可行）；
  终端 = 6000 kWh 情景的差额如实登记为结构性发现（AS04），不判为实现缺陷。

## 3. 预注册稳定性判据 S1–S6（跑数前冻结，事后不得修改）

> **受判子集**：`{baseline, param, solver, noise}`（结构族按 prob02 同级纪律**不计入** S1/S4，单独由 S6 判定）。
> **容差来源**：等式/不等式残差沿用 `prob03_model.TOL = LAYER_TOL = 1e-6`、相对 `LAYER_TOL_RELATIVE = 1e-8`。

| 判据 | 内容（阈值） | 失败后果 |
|---|---|---|
| **S1** | 受判样本**可行率 = 100%**：每层 LP `status=0`、层等式/不等式残差 ≤ `1e-6`（相对 ≤ `1e-8`）、变量界越界 ≤ `1e-6`、结算平衡/状态转移/跨日连续残差 ≤ `1e-6`、费用分解残差 ≤ `1e-6`。失败样本**保留并计入可行率**。 | 硬失败 → 稳定性分级「脆弱」，必须缩小适用范围或回退口径 |
| **S2** | 受判样本全部满足：`Σq_em > 0`、`max|q−b|(i≤36) ≤ 1e-6`、同充放时段数 = 0、交付期 `C_total ∈ [3e6, 5e7]`、`q_em&c` 占比 ≤ 15% | 方向反转须给机制解释并登记，否则该对照作废 → 分级降级 |
| **S3** | K3 的六组单调方向在 OAT 端点对上**不反转**（相对容差 `1e-6`） | 记录反转对并降级；不得为凑单调调整 `ε` 或 tie-break（T7-4 纪律） |
| **S4** | 每个噪声族 `n ≥ 25`、交付期 `C_total` 的**相对标准差 ≤ 5%**、**95% CI 半宽 ≤ 5%**、`max|z| ≤ 4`、**族间均值差 ≤ 3%**、**无失败样本** | 超阈值即登记该族为「不稳健」，分级降级；不得删除不利样本 |
| **S5** | 三种求解器设置**全部可行**且残差合格；链级费用最大相对差 **≤ 1%**（`> 1e-3` 时登记 warning 并与 T7-6 的 `1e-4` 对照） | 任一设置不可行或 > 1% → 判脆弱并建议回退 `M1` 默认设置 |
| **S6** | `buy_cap` 扫掠全档均产出状态（可行或不可行）并给出分界或「全域可行/不可行」结论；`terminal_e_6000` 情景产出数值。与 R5 的区间不重叠时只登记冲突点 | 缺项 → 判未完成并降级 |

**分级规则（预注册）**：S1–S6 全 PASS → **稳定**；恰有 1 项非 PASS 且 S1 PASS → **条件稳定（需给出适用边界）**；
S1 非 PASS 或 ≥ 2 项非 PASS → **脆弱（须缩小适用范围或回退）**；样本/计算不足（预算耗尽）→ **未决**。

### 4.2 输入噪声（4 族 × 25 = 100 个样本，满足「随机实验 ≥ 100 次」默认）

| 族 | 扰动 | σ |
|---|---|---|
| `noise_white_5` | 负载与光伏实际功率逐时段独立乘性白噪声 | 5% |
| `noise_white_10` | 同上 | 10% |
| `noise_day_5` | 负载与光伏按日持续（每日一个乘性因子，覆盖 144 时段） | 5% |

### 4.5 批次规模与预算

- 情景总数 **156**：`baseline` 1 + `baseline_full` 1 + 参数 39 + 求解器 3 + 结构 12 + 噪声 100。

  full 实测 `34.9–35.1 s`。整批预计 **≈ 45–50 min**（≈ 2,800 s），`timeout_seconds = 7200`、

- 输出目录：`robustness/results/prob03_v001_robust_run001/`（提交前不存在，不覆盖任何既有产物）。

### 4.6 失败处理（预注册）

- 求解器不可行/未达最优（`LayerFailure`）与未捕获异常均**保留样本**、写入 `raw_samples.jsonl` 与

- 若 `baseline`（compact，未扰动、默认参数）与 `run003` 的 9 项总量相对差 > `1e-6`，或 `baseline_full` 的
  `tables.json` 表 1 六时段/四日期对账超差，则整批判失败（`exit 4`），按 `code_runtime` 路由修复后
  以**新 attempt + 新 output_directory** 重跑。
- 若整批以 `timed_out`/非零退出结束，须用新 attempt + 新 output_directory（`..._robust_run002`）重跑并登记新 `task_id`。
