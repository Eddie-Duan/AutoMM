### 1 问题描述与建模口径

问题 1 要求在电价、小区负载逐日相同且已知单日光伏预测的前提下，于每天 0:00 制定当天计划购电策略：微网提供的电能不得低于小区负载，储能设备 0:00 与 24:00 储电量相同，目标为全天购电费最小。

本问采用的建模口径逐条对应假设编号：

| 口径 | 取值 | 依据 |
|---|---|---|
| 时间离散与对齐 | $\Delta t = 1/6$ h，144 个时段；附件时间戳为区间**左端点**，计划窗 0:10→24:10 | AS01 / AS09（团队裁定 D1） |
| 功率平衡 | 等式 $b_t + PV_t\Delta t + q_t = L_t\Delta t + c_t + s_t$，$0 \le s_t \le PV_t\Delta t$ 为弃光量 | AS04 / AS08（D3 / D4） |
| 储能动态 | $E_t = E_{t-1} + \eta c_t - q_t/\eta$，$\eta = 0.9$（充放两侧，往返 0.81） | AS05（D2） |
| 容量与功率 | $1200 \le E_t \le 10800$ kWh；$c_t \le 833.33$ kWh；$q_t \le 750.00$ kWh | AS06（D10 取两侧更严者） |
| 日周期 | $E_0 = E_{144} = 6000$ kWh | AS10 / AS11（D5） |
| 目标口径 | $\min \sum_t p_t b_t$（元，**不乘** $\Delta t$） | AS03a（D9） |
| 模型族 | 单日确定性 LP（不引入互补二元变量） | AS07 / AS12（D6） |

「微网提供的电能不可低于小区负载」在等式平衡下自动成立：实际供给 $b_t + q_t + (PV_t\Delta t - s_t) = L_t\Delta t + c_t \ge L_t\Delta t$，即充电不挤占负载。该形式化与文献一致：微网并网储能系统的 24 小时成本最小 MILP 普遍显式包含 SOC 约束与充放电动态 [@ref-alguhi-2025-bess-operation]；分时电价下"低价充电、高价放电"的套利是光伏-储能经济优化的核心机制 [@ref-lin-2024-tou-industrial]；储能逐时段成本最小调度属成熟的标准优化问题族 [@ref-olivieri-2020-residential-bess]。目标函数按题面仅计购电费、不纳入电池折旧，属显式项目假设——日前微网调度文献常把折旧成本纳入目标，故该取舍必须显式声明而非默认事实 [@ref-zhang-2015-dayahead-degradation]。恒效率 0.9 为附录 1 给定的题面硬参数，文献仅说明效率随 SOC 与退化变化、恒效率属工程简化 [@ref-vykhodtsev-2022-bess-review]。

### 2 数学模型

完整推导见 `formulation_v001` §3.1–§3.10（§3.8 给出完整模型）。决策变量 $b_t, c_t, q_t, s_t$（kWh，不带时间因子）与状态量 $E_t$（时段末储电量，kWh）：

$$
\min \sum_{t=1}^{144} p_t\, b_t
$$

$$
\begin{aligned}
\text{s.t.}\quad & b_t + PV_t\Delta t + q_t = L_t\Delta t + c_t + s_t, & 0 \le s_t \le PV_t\Delta t \\
& E_t = E_{t-1} + \eta c_t - q_t/\eta, & \eta = 0.9 \\
& 1200 \le E_t \le 10800, & 0 \le c_t \le 5000\Delta t = 833.33 \\
& 0 \le q_t \le 5000\Delta t\,\eta = 750.00, & E_0 = E_{144} = 6000 \\
& b_t \ge 0 &
\end{aligned}
$$

模型规模：720 个变量、288 条等式、720 个变量界，$A_{eq}$ 非零元 1151、目标非零元 144（`formulation_v001` §3.8，sanity 阶段独立实测一致）。

**为什么不需要二元变量**（§3.10 互补性引理）：$\eta^2 = 0.81 < 1$ 且 $p_t > 0$，同一时段同时充放电被"少充少放"严格支配，故 LP 松弛无损；该结论由本问的 MILP 对照实测确认（见 §6）。求解采用 HiGHS 直接求解纯 LP（`scipy.optimize.linprog(method="highs")`），规模很小，无需分解或启发式（§5.3）。

三点结论：

1. **核心结论不依赖模型族**：MILP（显式互补二元）与 LP 目标值完全相同（`mip_gap = 0.0`，1 节点），说明 AS07 的 LP 松弛无损，无需付出 144 个二元变量与约 4.3 倍耗时的代价；SOC 离散化 DP 的四档粒度目标值恒不低于 $C^*$ 且随粒度加密单调收敛（h = 50 时 +0.791%，在预注册阈值 1% 以内），差异纯属离散化代价而非模型结构差异；
2. **日周期约束的经济价值为 2217.083333 元（$C^*$ 的 6.312%）**：去掉 $E_0 = E_{144}$ 后最优解在末时段放空至下界 1200 kWh，等价于把日初存量电能当日变现；**弃光变量本日贡献为 0**（$\sum_t s_t = 0$，其上界 $PV_t\Delta t$ 在最优解处不紧），但变量必须保留以在光伏盈余超出储能吸收能力时闭合功率平衡；
3. **口径敏感性**：accepted 的"两侧效率 0.9"是四种口径中最保守者，其余口径会低估费用 958.34–1710.42 元（$-2.728\% \sim -4.869\%$）。

### 7 结论

1. 问题 1 的最优计划购电策略对应全天购电费 $C^* = 35126.948589$ 元、全天购电量 59482.698998 kWh，策略呈"低价充电、高价放电"的典型 TOU 套利形态，全日无弃光、无同时充放电，日周期精确闭合；
2. 表 1、表 2 与交付文件 `result1.xlsx` 三者逐项一致，可直接作为论文表格与结果文件；
3. 模型族对照证明结论稳健：MILP 同解、DP 收敛至同一最优值附近（偏差 $\le 0.8\%$），本问无需引入二元变量或启发式；
4. 结论对效率参数最敏感（$\eta$ 由 0.9 降至 0.8 时费用 $+8.88\%$），对初值几乎不敏感；
5. 供后续小问承接的口径：单日功率平衡形式、储能状态转移与容量/功率约束、日购电费用目标结构（登记于 `dependency_graph.yaml` 的 `propagates` 字段）。

## 4 模型、公式与算法

### 4.1 完整模型（M1，`formulation_v001` §3）

决策变量（均为 kWh，**本身已含 Δt**，故目标与平衡式中不再乘 Δt，量纲纪律 D9）：`b`（计划购电量，无上界）、`q^em`（紧急购电量）、`c`（充电量）、`q^dis`（放电量）、`s`（弃光/盈余）；状态量 `E`（时段末储电量）。

$$
\begin{aligned}
(P2)\quad \min_{b,\,q^{\mathrm{em}},\,c,\,q^{\mathrm{dis}},\,s,\,E}\quad
& C_{\mathrm{total}}=\sum_{\tau=1}^{T}\Bigl(p_{\tau}\,b_{\tau}+\alpha_{\mathrm{em}}\,p_{\tau}\,q^{\mathrm{em}}_{\tau}\Bigr),
\qquad \alpha_{\mathrm{em}}=5,\quad T=52560,\quad \Delta t=\tfrac{1}{6}\,\mathrm{h}\\[2pt]
\text{s.t.}\quad
& b_{\tau}+q^{\mathrm{em}}_{\tau}+PV_{\tau}\,\Delta t+q^{\mathrm{dis}}_{\tau}
   =L_{\tau}\,\Delta t+c_{\tau}+s_{\tau}, && \forall\tau \tag{R1}\\
& 0\le c_{\tau}\le 833.3333, && \forall\tau \tag{R7a}\\
& 0\le q^{\mathrm{dis}}_{\tau}\le 750.0000, && \forall\tau \tag{R7b}\\
& 0\le s_{\tau}\le PV_{\tau}\,\Delta t, && \forall\tau \tag{R3s}\\
& E_{\tau}=E_{\tau-1}+\eta_{\mathrm{ch}}\,c_{\tau}-\frac{q^{\mathrm{dis}}_{\tau}}{\eta_{\mathrm{dis}}},
   \qquad \eta_{\mathrm{ch}}=\eta_{\mathrm{dis}}=0.9, && \tau=1,\dots,T \tag{R2}\\
& E_{\min}\le E_{\tau}\le E_{\max},\quad E_{\min}=1200,\ E_{\max}=10800, && \forall\tau \tag{R5}\\
& E_{0}=E_{\mathrm{init}}=6000, && \tag{R4}\\
& E_{T}\ \text{free (only bounded by (R5))}, && \tag{R6t}\\
& b_{\tau}\ge 0\ (\text{no upper bound}),\quad q^{\mathrm{em}}_{\tau}\ge 0,\quad
  c_{\tau}\ge 0,\quad q^{\mathrm{dis}}_{\tau}\ge 0,\quad s_{\tau}\ge 0. && \forall\tau
\end{aligned}
$$

- 跨日衔接 `E_{d,0}=E_{d−1,144}` 就是 (R2) 在 `τ=144(d−1)` 处的一次转移，**不另加约束**；**不得**施加 prob01 的日周期约束 `E_{d,0}=E_{d,144}`。
- 可靠性（题面 H1）自动蕴含：`b+q_em+q_dis+(PV·Δt−s)=L·Δt+c ≥ L·Δt`，无需另加不等式。
- 功率上界为**两侧交集**：并网点侧与电池侧均 ≤5000 kW ⇒ `c ≤ min(833.333, 925.926)=833.3333`、`q_dis ≤ min(833.333, 750.000)=750.0000` kWh（D10 口径丙 + 勘误 E1）。
- 模型规模：变量 `6×52560 = 315,360`；等式约束 `2×52560 = 105,120`；变量界 315,360；非零元 `9T−1 = 473,039`；整数变量 **0**（纯 LP；稠密矩阵约 265 GB，实现用 `scipy.sparse` CSR）。

### 4.2 关键结论（定理/引理/命题）

- **引理 L1（LP 松弛无损）**：`p_τ>0` 且 `η_ch·η_dis=0.81<1` 时，同时充放电被「少充少放」严格支配，故 (P2) **存在**互补最优解 ⇒ MILP（M3）最优值等于 LP 最优值，**不需要二元变量**（解析结论，不依赖 MILP 是否跑到最优）。
- **定理 T1（`q_em ≡ 0`）**：前提为 ① `p_τ>0`、② `α_em=5>1`、③ `b` 无上界。三条同时成立时，任何 `q_em>0` 都能用等量计划购电以更低费用替代 ⇒ 存在最优解使 `q_em ≡ 0`。**这是本问模型内的数学推论，不是实测断言、不是文献结论**；`q_em` 仍必须保留为变量与约束。
- **定理 T2（阈值结构）**：非绑定阈值 `B_peak = 10,325.33 kW`（`B ≥ B_peak` 时上限无效）≠ 强制阈值 `θ` ≠ 激活阈值 `β`；解析必要下界 `β ≥ θ ≥ max_τ(L_τ−PV_τ) − 5000·η_dis = 3,478.8849 kW`；实测 `β ∈ (4218.75, 4375.00] kW`。
- **命题 P1（逐日决策 ≡ 全期求解）**：完全信息下，「每天 0:00 制定当天计划」与「对 365 天一次性求解」等价 ⇒ 本问**不需要**滚动时域近似、预测误差模型或鲁棒优化；若改取不完美信息或购电上限（AS07 备选 B/C），该等价性失效、必须重新裁定。
- **结构恒等式**（sanity 与解析界的核心，实测残差 0.0）：

$$
\begin{aligned}
(I1)\quad & \sum_{\tau} q^{\mathrm{dis}}_{\tau}=\eta_{\mathrm{ch}}\eta_{\mathrm{dis}}\sum_{\tau} c_{\tau}-\eta_{\mathrm{dis}}\,(E_{T}-E_{0})\\
(I2)\quad & \sum_{\tau} b_{\tau}=N+\sum_{\tau} s_{\tau}+\bigl(1-\eta_{\mathrm{ch}}\eta_{\mathrm{dis}}\bigr)\sum_{\tau} c_{\tau}
  +\eta_{\mathrm{dis}}\,(E_{T}-E_{0})-\sum_{\tau} q^{\mathrm{em}}_{\tau},\quad N=\sum_{\tau}(L_{\tau}-PV_{\tau})\Delta t
\end{aligned}
$$

## 4. 模型、公式与算法

完整推导见 `formulations/formulation_v001/formulation.md`；方法学细节与实现映射见 `implementation.md`。核心如下。

**索引与单位**：`Δt = 1/6 h`；`i = 1…144`（10 分钟时段，左端点口径）；`m ∈ {0,6,12,18}`；
`ν(i) = 6·⌊(i−1)/36⌋` 给出**唯一**支配决策时刻（无需离散选择变量，模型保持 LP）。
决策变量 `b, q, q_em, c, q_dis, s, s'` 与状态 `E` 均为 kWh，故目标与平衡式**不再乘 `Δt`**。

**三层顺序向前递推（`M1`）**

```
计划层（0:00，用 Π_0 全天预报；团队 T1 主口径）
  min Σ_i p_i·b_{d,i}
  s.t. b + Π_0[PV]·Δt + q_dis^PL = L·Δt + c^PL + s^PL
       0 ≤ c^PL ≤ 833.3333, 0 ≤ q_dis^PL ≤ 750.0000, 0 ≤ s^PL ≤ Π_0[PV]·Δt
       E^PL_i = E^PL_{i−1} + 0.9·c^PL − q_dis^PL/0.9,  1200 ≤ E^PL ≤ 10800
       E^PL_{d,0} = E_{d−1,144}（前一日已提交链末态）；E^PL_{1/1,0} = 6000；E^PL_{12/31,144} 自由
调整层（m = 6:00/12:00/18:00，顺序求解；只提交 D_m，其余为前视）
  min Σ_{i∈R_m} [0.5·p_i·u⁺_i + 1.5·p_i·u⁻_i]
  s.t. q^{[m]} + Π_m[PV]·Δt + q_dis^{[m]} = L·Δt + c^{[m]} + s^{[m]}
       u⁺ ≥ b − q,  u⁻ ≥ q − b,  u⁺,u⁻ ≥ 0 ；E^{[m]}_{d,6m} = E_{d,6m}
实际结算层（事后闭式，唯一解）
  r = q + q_dis + PV^act·Δt − L·Δt − c ；s' = max(0, r) ；q_em = max(0, −r)
目标
  C_plan = Σ p·b ；C_adj = Σ[0.5p(b−q)⁺ + 1.5p(q−b)⁺] ；C_em = Σ 5p·q_em ；C_total = 三者之和
```

**储能与两侧功率约束（D10 口径丙）**：并网点侧与电池侧**同时** ≤ 5000 kW ⇒
`0 ≤ c ≤ min(5000·Δt, 5000·Δt/η_ch) = 833.3333 kWh`、`0 ≤ q_dis ≤ min(5000·Δt, 5000·Δt·η_dis) = 750.0000 kWh`；
`E_i = E_{i−1} + 0.9·c − q_dis/0.9`，`E ∈ [1200, 10800]`，终端自由，不计自放电。

**解析依据（引理，`formulation` §3.9）**

- **L1**：`α_em = 5 > β_over = 1.5` 且 `q` 无上界 ⇒ **`q_em` 在决策层恒不激活**，`q_em` 只能由**结算层的预报误差**产生
  （**不得**与本问的「购电上限激活」混为一谈，承接 prob02 R5 纪律）。
- **L2/L3**：结算层为闭式、`s' ≤ PV^act·Δt` 自动成立，供电可靠性 `q + q_em + q_dis + (PV^act·Δt − s') = L·Δt + c ≥ L·Δt` 自动蕴含。
- **L4/L5**：各层**必可行**；分段线性化 `u⁺/u⁻` 在正系数下取紧 ⇒ **LP 松弛无损**（`M6` 的 MILP oracle 实测最大相对差 3e-12）。
- **L6**：`M3`（完全信息）与 prob02 accepted `(P2)` **逐项相同** ⇒ 跨问独立锚点（团队 F7）。

**tie-breaking（团队 T7/T9，提交解口径）**：所有层、所有模型 `M1–M8` 一律先取**主目标最优**，再在其最优面上取
`min Σ_t (c + q_dis)`（**字典序**实现，即 T7-1 在 `ε→0⁺` 的精确形式）；字面加权式只作逐层诊断对照（`t7_tiebreak.json`）。

**求解**：`scipy.optimize.linprog(method='highs')`，CPU，全年 **1,460 次小 LP**（每天 4 层），单层 ≤ 756 变量；
**本问不涉及 GPU**（`gpu_required = false`）。

## 4 模型、公式与算法

完整推导、引理与伪码见 `formulations/formulation_v001`（§1 两链共用、§2 `4-2`、§3 `4-3`、§5 引理 L1–L7/P1–P4、§8 实现接口）。核心口径（局部符号：`p^{act}`=附件 4 实际价，`\hat p^{(m)}`=层 `m` 预测价，`\kappa_m`=水平校正因子）：

**共用结构**（两链逐项相同）

```
E_i = E_{i−1} + 0.9·c_i − q_dis_i/0.9        1200 ≤ E_i ≤ 10800
0 ≤ c_i ≤ 5000·Δt = 833.33… kWh             0 ≤ q_dis_i ≤ 750.0000 kWh（口径丙：两侧功率 ≤ 5000 kW，取更严者）
0 ≤ s_i ≤ max(0, PV^{层}_i·Δt − L_i·Δt)       （AS05 / D9-B 物理盈余界）
E_{d,0} = E_{d−1,144}、E_{1/1,0} = 6000、E_{12/31,144} 自由；外购电量无上界
结算层闭式：r = q + q^em + PV^act·Δt + q_dis − L·Δt − c；s' = max(0,r)、q^em = max(0,−r)
```

- **价格预测（AS08/AS11）**：计划层 `\hat p_{d,i} = p^{act}_{d−1,i}`（`PF-PERSIST`，两链共用）；`4-3` 调整层 `\hat p^{(m)}_{d,i} = p^{act}_{d,i}`（`i ≤ 6m`，已实现）/ `\kappa_m·p^{act}_{d−1,i}`（`i > 6m`），`ν(i) = 6⌊(i−1)/36⌋` 为支配时刻，`\kappa_0 ≡ 1`。
- **`4-3` 预报降尺度 `Π_m`**：整点点值 + `k=1` 前向保持 + `2 ≤ k ≤ 24` 整点锚定线性插值；**块内能量不守恒须披露**（块和 = `(2.5A_{k−1} + 3.5A_k)/6`，一般 ≠ `A_k·1 h`）；`m = 6/12/18` 的跨年项分别丢弃 `k=19..24 / 13..24 / 7..24`（合计 36 项，**不消费、不截断、不外推**）。
- **tie-break（AS21，两链所有层统一）**：先优化该层主目标，再在其最优面上取 `min Σ(c + q_dis)` 的**字典序**解（字面 `ε` 加权式只作诊断）；实测主目标相对变化 `≤ 5.0001249e-10`（≤ `1e-9`）、`total_shrinks = 0`。

**`4-2` 模型 `M4-2`**（逐日递推）

```
min_{b,c,q_dis,s,E,q_em} Σ_i \hat p_{d,i}·b_{d,i} + Σ_i α_em·\hat p_{d,i}·q^em_{d,i}
s.t. b_i + q^em_i + PV^act_i·Δt + q_dis_i = L_i·Δt + c_i + s_i
⇒ 结算层 q := b，q^em ≡ 0（定理：若 q^em = δ > 0，改取 b' = b + δ 可降 α_em·\hat p·δ − \hat p·δ > 0 改进，与最优矛盾）
```

`4-2` 的价格不确定性**不产生能量缺口**，其后果**全部落在费用**（`ΔC_price`）。表 3 / `紧急购电量` 全零是**机制级结论**，论文必须给机制说明而不是只报空表。

**`4-3` 模型 `M4-3`**（三层）

```
计划层 (PL_d)：min Σ_i \hat p^{(0)}_{d,i}·b_i，用 Π_0[PV]，不含 q^em；只提交 D_0 = {1..36}
调整层 (AD_{d,m}) m ∈ {6,12,18}：b 全天为参数；min Σ_{i∈R_m}[β_def·\hat p^{(m)}_i·u⁺_i + β_over·\hat p^{(m)}_i·u⁻_i]
             u⁺ ≥ b − q、u⁻ ≥ q − b、u^± ≥ 0（分段线性化 LP 无损）；只提交 D_m = {6m+1 .. 6m+36}
结算层 (ST-3)：事后闭式，PV^act 的**唯一**入口
```

**规模**（与 `formulation §8.6`、`implementation §2.2` 逐项一致）：`4-2` 单日 864 变量 / 288 等式 / 0 不等式；`4-3` 单日 2,232 变量 / 720 等式 / 432 不等式；全年名义 LP 分别为 1,460 与 5,840 次；**整数变量 0**（纯 LP，无 Big-M）。
